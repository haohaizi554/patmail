## 调用顺序

| 步骤 | 页面 | 作用 |
|---|---|---|
| 1 | `Forms/customer/customerlist.aspx` | 按名称查出客户，行上有 `customer_id` |
| 2 | `forms/customer/Addcustomer.aspx?customer_id=` | 打开该客户。`log_pagename=Addcustomer.aspx` |

```text

```

| 列 | 页面用途 |
|---|---|
| sn | 序号 |
| case_type | 案件类型显示名 |
| demand_type | 要求类型 |
| file_name | 附件名 |
| demand_name | 标题 |
| demand_desc | 描述。单元格用 `RenderDemandDetail` 去掉 HTML 标签后展示；点击后 `ShowDemandDetail` 对原文做 `HTMLDecode` 再铺开 |

`structMySheetData` 读顶层 `TableRows` 和 `TableRowsCount`。`TableRows == null` 时这一页不画行。行对象挂在 `tr.data("row")` 上，描述弹层读的就是这个对象里的 `demand_desc`，所以列表响应里要有描述原文，不必再打详情接口。

这次响应 4776 字节。同页只有 `ClientInfo` 的请求是 180–210 字节，这一页带回了表格数据。总条数和是否还有第 2 页，正文未保存，不能写。

`demand_desc` 在编辑页按 HTML 保存，读的时候要 `HTMLDecode`。列表单元格会再去掉标签，交给人看的原文以弹层那份为准。

和案件要求表的列不同。案件要求 `GetDemandBuCaseid` 的 `colsel` 只有 `demand_type`、`demand_name`、`demand_desc`。客户要求多了案件类型、附件、人员、时间和停用标记。

客户页「联系人」表。打开客户页就会拉，不等点击客户要求。这是 `Customer.ashx`，和邮件页 `Mail.ashx` 的同名 `GetCustomerContact` 不是一个接口。邮件页那条见 [09-期限监控.md](09-期限监控.md)。

| 参数 | 本次 |
|---|---|
| Call | `GetCustomerContact` |
| customer_id | 客户 GUID |
| order_by | 空字符串 |
| pageIndex | `1` |
| pageSize | `10` |
| _PK | `contact_id` |
| searchKey | 空字符串 |
| colsel | `;sn;case_type;contact_name;contact_type;tel;mobile;is_enabled;email;contact_address_cn;contact_id;` |

外壳同样是 `TableRows`、`TableRowsCount`。这次 9126 字节。回调只按权限改 `contact_id` 列的操作按钮，没有再点行字段。

`GetCustomerInit` 两页共用同一份数据。客户页实际绑定的键：

```text
customerfrom, countrylist, customersize, customersecret, customercredit,
customertown, customerpark, customerbuss, sourcetype, cusinterval, customertype,
belongtocompany, customer_request_periods, contact_way, customer_pay_type,
customer_class, businesscoop, casetype, CustomerZZW, Customershow,
affiliated_company, SalerRate, prepayBusinessType, advpayBusinessType
```

字典行页面用到的形状：`customerfrom`、`countrylist`、`customertype` 读 `value` 和 `text_` + 语言；`customerbuss` 另有 `role_code`；`customer_class` 读 `id`、`name`；`casetype` 读 `value` 和 `text_` + 语言；`Customershow[0]` 读 `cfg_key`、`cfg_value`。`CustomerZZW` 为空时隐藏「平台」页签。
