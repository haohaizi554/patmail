# 文件查询字段映射

数据来源：`FileSearch.aspx` HTML、`FileSearch.js` 的 `FileManager.SearchFile()`、抓包 117 项 Payload。

控件位于文件查询 iframe：

```html
<iframe src="Forms/Patent/FileSearch.aspx?..."></iframe>
```

顶层页面需先取 `iframe[src*="FileSearch.aspx"]` 的 `contentDocument`。

统计：117 字段中，108 个来自 DOM；92 个 API 名与 DOM id 相同；16 个改名；9 个由 JS / Layui / Ajax 封装生成。

QueryHistory XML 保存的是 DOM id，不是 GetSearchFiles 参数名。

## 取值模式

**文本 / select**

```text
$("#case_name").val()
```

**Tree / object**

```text
$("#customername").attr("objid")
$("#filetype").attr("objid")
```

**日期空值 checkbox**

```text
checked → on
unchecked → ""
```

**布尔 checkbox**

```text
checked → true
unchecked → ""
```

**申请号**

```text
trim(val).replace(/\./g, "")
```

例：`202620536145.1` → `2026205361451`
