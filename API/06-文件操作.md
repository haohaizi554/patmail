# 文件操作

页面脚本：`Scripts/Page/Patent/FileSearch.js`。下载函数在 `Scripts/JSCOMM/public.js`。

多个 ID 的分隔符已在抓包里确认是分号。`GetFileName.file_ids` 本次是 10 个 GUID 加 9 个分号，总长度 369。`MailCustomer` 的 `_file_ids` 和 `_file_names` 也是分号。

写接口和真实下载没有重新调用。

## GetFileName

生成下载用的文件名，不是按单个 `file_id` 取文件信息。

```http
POST /AjaxServers/CaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFileName` |
| file_ids | 是 | 分号分隔的文件 GUID |
| new_filename | 是 | 与 `file_name_type` 逐段对应，段之间用分号 |
| file_name_type | 是 | 每段是 `colname` 或 `txt`。抓包示例：`colname;txt;colname;txt;colname` |
| childpath | 否 | 子目录列名。不用时为空 |
| zip_name | 否 | 压缩包名称模板 |
| zip_file_name_type | 否 | 压缩包名称的 `colname` / `txt` 序列 |
| log_pagename | 否 | `FileSearch.aspx` |

`colname` 段的 `new_filename` 取值来自 `GetFlowdirection.DownLoadFileName.value`。`txt` 段是用户输入的固定文字。

只传 `file_name_type=colname` 且 `new_filename` 为空时，返回「系统繁忙，请求失败，请稍后重试！」。

用一个文件 ID、`new_filename=file_name`、`file_name_type=colname`、压缩包参数为空做只读调用时，`ClientInfo.Status=true`，`Message=null`。响应字段：

| 字段 | 说明 |
|---|---|
| file_names | 生成的文件名，多个时用分号连接 |
| zip_names | 压缩包名，本次空字符串 |
| child_path | 子目录，本次空字符串 |
| ClientInfo | 公共响应 |

没有配置重命名时，页面改调 `GetFileNameByConfig`，参数是 `file_ids`、`zip_name`、`zip_file_name_type`。成功回调同样读 `file_names` 和 `zip_names`。这次没有单独调用。

生成出的具体文件名没有写入本文。

## 下载

`public.js` 的 `DownLoad(file_no, file_name, model, zip_name, zip_pwd, type, childpath)`。文件查询传入的 `model` 是 `FILE`。

1. 租户配置 `FileUpload / is_not_approval` 打开时，先调用 `CaseInfo.ashx` 的 `GetApprovalByFileNo`，参数 `file_no`。`flag` 为 `"True"` 才继续。
2. `POST /AjaxServers/BaseInfo.ashx`，`Call=DownLoad`。参数：`file_no`、`file_name`、`zip_name`、`zip_pwd`、`down_type`、`model`、`childpath`。
3. 成功时 `ClientInfo.Result=true`，并返回 `file_guid`、`file_size`。`error` 为真则直接取文件；否则先用 `error_message` 确认。
4. 取文件是 GET：

```text
/AjaxServers/FileHandler.ashx?guid=<file_guid>&file_size=<file_size>
```

还有 `DownLoadZip`、`DownLoadFiles`，分别调用 `BaseInfo.ashx` 的 `DownLoadZip`、`DownLoadFiles`。批量打包另有 `FileHandlerNew.ashx?guid=`。这三步都没有重新执行。

## GetFileReceiveInfo

获取收文信息。`Call` 已确认。

```http
POST /AjaxServers/CaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFileReceiveInfo` |
| file_id | 是 | 单个文件 GUID。页面在批量入口会传空字符串，只用来装状态下拉 |
| log_pagename | 否 | 页面未强制传 |

响应：

| 键 | 说明 |
|---|---|
| FileReceiveInfo | 数组。有 `file_id` 时本次 1 行 |
| FileStatus | 4 条字典，`value` 长度 2，显示名在 `text_zh_cn` |
| ReceiveFileList | 额外回执文件。本次 `null`。有数据时元素含 `file_id`、`file_no`、`file_name` |
| ClientInfo | `Status=true`，`Result=false` |

`FileReceiveInfo[0]` 字段：`file_name`、`case_volume`、`file_status_id`、`post_date`、`upload_time`、`sales_date`、`forward_date`、`cus_receive_date`、`receive_name`、`cus_receipt_date`、`remark`、`fileids`。页面还会读 `proc_id`，这次该键没有出现。

## 删除

两步都在 `CaseInfo.ashx`，都没有调用。

| Call | 参数 | 作用 |
|---|---|---|
| GetDelFileInfo | `file_ids` | 删除前的提示。`ClientInfo.Message` 会拼进确认文案 |
| BatchDelFile | `file_ids` | 确认后删除。成功时 `ClientInfo.Result=true`，页面提示「删除成功」 |

`file_ids` 来自文件列表的勾选列，和 `GetFileName` 使用同一个拼接函数。已抓到的勾选结果用分号。

## 上传

HAR 里没有上传正文。页面有两条入口：

1. 弹层 `Forms/UploadFile.aspx?model=CASE&Call=CommUpload&objid=<file_id>&filedesc=<GUID>&filetype=<GUID>`。
2. 拖拽上传打开 `Forms/UploadFileNew.aspx`，由 `CommDragUploadNotices` 初始化。允许的扩展名来自 `Common.ashx` 的 `GetAccepttype`，字段 `Accepttype.accept_file_ext`，分号分隔。

上传完成后，收文窗口调用 `CaseInfo.ashx` 的 `AddReceiveFile`，参数 `file_id`、`proc_id`。成功时返回 `ReceiveFileList`。

旧文档里的 `SaveFile`、`AddFile` 不是案件附件保存。`FileManager.SaveFile` 保存的是下载文件名模板，Handler 是 `BaseInfo.ashx`，`Call=SaveFileTepmName`，参数 `new_filename`、`temp_name`、`file_name_type`。压缩包模板是 `SaveFileTepmNameZip`。`AddFile` 这个 Call 没有出现。
