# 案件信息

Handler：`POST /AjaxServers/CaseInfo.ashx`

---

## GetCaseInfo

获取案件详情。

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetCaseInfo` |
| case_id | 是 | 案件 ID |
| log_pagename | 否 | 示例 `CaseManage.aspx` |

### 请求示例

```http
POST /AjaxServers/CaseInfo.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=GetCaseInfo&case_id=xxxx&log_pagename=CaseManage.aspx
```

### 响应

返回案件基础信息、客户信息、申请信息、状态信息。字段级 Schema 未完整落盘。

## GetFeeListByCase

按案件查询费用。

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 待确认 | 未在抓包中单独标注，入口为 CaseInfo.ashx |
| case_id | 是 | 案件 ID |
| fee_class | 是 | 费用分类，见下表 |
| pageSize | 是 | 每页条数 |
| pageIndex | 是 | 页码 |
| colsel | 否 | 返回字段选择 |

### fee_class

| 值 | 类型 |
|---|---|
| A | 官方费用 |
| O | 代理费用 |

### 请求示例

```text
case_id=<案件ID>
fee_class=A
pageSize=50
pageIndex=1
colsel=
```
