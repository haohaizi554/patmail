# 案件信息

Handler：`POST /AjaxServers/CaseInfo.ashx`

2026-09-24 用已登录会话做了只读核对。样本来自文件查询里一笔专利案件。响应里的文号、名称、备注和人员姓名没有写入本文。`ClientInfo.Result` 为 `false` 时，只要 `Status` 为 `true` 且业务数据在，就不是失败。

## GetCaseInfo

获取案件详情。

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetCaseInfo` |
| case_id | 是 | 案件 ID，GUID |
| log_pagename | 否 | 本次 `CaseManage.aspx` |

### 响应

顶层是 `CaseInfo` 和 `ClientInfo`。`CaseInfo` 是长度为 1 的数组，元素有 388 个字段。

这次专利案件里有值的是 115 个，其余为空字符串。空字段里有一大组商标、许可、转让和著录变更栏位，专利案不会填。日期字段除了原值，还会带 `_dd`、`_mm`、`_ss` 三个拆分字段，长度分别是 10、16、19。

## GetCaseSales

获取销售人员。

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetCaseSales` |
| obj_id | 是 | 案件 ID |

## GetSalesAssistant

文档里的两种参数都返回失败：

```text
Call=GetSalesAssistant&obj_id=<案件ID>
Call=GetSalesAssistant&case_id=<案件ID>&log_pagename=CaseManage.aspx
```

`ClientInfo.Status=false`，`Message` 为「系统繁忙，请求失败，请稍后重试！」。`FileSearch.js`、`mail.js`、`IhgFlow.js` 里没有这个 Call。请求名保留，响应结构仍未确认。

## GetFeeListByCase

按案件查询费用。`Call` 已确认就是 `GetFeeListByCase`。

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFeeListByCase` |
| case_id | 是 | 案件 ID |
| fee_class | 是 | `A` 官方费用，`O` 代理费用 |
| pageSize | 是 | 本次 `5` |
| pageIndex | 是 | 本次 `1` |
| colsel | 否 | 本次空字符串 |
| log_pagename | 否 | 本次 `CaseManage.aspx` |

### 响应

顶层：`TableRows`、`AgencyFeeRuleType`、`ClientInfo`。没有 `TableRowsCount`。本次 `pageSize=5` 时官方费和代理费各返回 4 行，就是该案的全部费用。

`AgencyFeeRuleType`：

| 字段 | 类型 |
|---|---|
| case_volume | 字符串 |
| case_id | GUID |
| third_fee_rule | 字符串，本次空 |
| agency_fee_rule | 字符串，本次空 |
| agency_fee_sum | 数字 |
| agency_currency_id | 字符串，本次空 |

费用行官方费 188 个字段，代理费 200 个字段。差集没有逐项比对。代理费行出现过、做业务时会用到的字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| fee_id | GUID | 费用 ID |
| fee_case_id | GUID | 案件 ID |
| proc_id / proc_id1 | GUID | 处理事项 |
| ctrl_proc | 字符串 | 处理事项显示名，官方费行本次未见此键 |
| fee_class | 字符串 | `A` 或 `O` |
| fee_type / fee_type_id / fee_name / fee_desc / fee_desc_cn | 字符串 / GUID | 费用类型和名称 |
| amount / recieve_amount / target_amount | 整数 | 金额。`recieve_amount` 是响应里的拼写 |
| currency_id / currency_name | 字符串 | 币别，本次长度 3 |
| target_currency_id / target_currency_name | 字符串 | 目标币别 |
| pay_status / receive_status / request_status / payment_status | 字符串 | 支付、到款、请款状态 |
| request_id / request_no / request_date | GUID / 字符串 / 日期 | 请款 |
| pay_due_date / pay_date / receive_due_date / receive_date | 日期 | 缴费期限、实付、应收、实收 |
| bill_no / fee_bill_out_no / fee_bill_out_id | 字符串 / GUID | 账单 |
| case_type_id / apply_type_id / business_type_id / country_id | GUID 或短字符串 | 案件维度 |
| create_user_id / update_user_id | GUID | 创建人、更新人 |
| is_check / is_confirm / is_zuofei / is_cffee / is_deposit | 布尔 | 核对、确认、作废、官费、押金 |
