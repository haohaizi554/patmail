# 历史查询条件 QueryHistory

适用页面：`FileSearch.aspx`、`Forms/Report/LimitMonitor.aspx`  
Handler：`POST /AjaxServers/CaseInfo.ashx`

`query_type` 按页面区分，不是固定值：

| 页面 | query_type |
|---|---|
| `FileSearch.aspx` | `FileSearch` |
| `LimitMonitor.aspx` | `LimitMonitor—liall` |

期限监控这个值中间是 U+2014 长破折号。详见 [09-期限监控.md](09-期限监控.md)。

本模块管理查询模板，不返回文件业务数据。查询文件见 [04-文件查询.md](04-文件查询.md)。

历史 XML 节点名为页面控件 ID，与 `GetSearchFiles` 参数名不完全一致，映射见 [05-文件查询字段映射.md](05-文件查询字段映射.md)。

历史列表依赖当前登录 Session，请求中无 `user_id`。是否用户私有 / 部门共享未 empirically 验证。

## SearchQueryHisList

列出当前账号可用历史条件；指定 `query_id` 时同时返回该条条件 XML。

### 请求参数

| 参数 | 必填 | 类型 | 说明 |
|---|---|---|---|
| Call | 是 | string | 固定 `SearchQueryHisList` |
| query_type | 是 | string | 文件查询为 `FileSearch`；期限监控为 `LimitMonitor—liall` |
| query_id | 否 | string | 指定模板 ID；空字符串表示只取列表 |
| log_pagename | 否 | string | `FileSearch.aspx` |

### 请求示例（列表）

```text
Call=SearchQueryHisList
query_type=FileSearch
query_id=
log_pagename=FileSearch.aspx
```

### 请求示例（加载指定模板）

```text
Call=SearchQueryHisList
query_type=FileSearch
query_id=227BFA59-A8A7-4EC6-928D-50FB5C29F960
log_pagename=FileSearch.aspx
```

### 响应结构

```json
{
  "Options": [
    {
      "query_id": "122F1BAA-F03E-42EE-B297-D9E47C0823A4",
      "title": "宁德授权请款"
    }
  ],
  "QueryXml": [
    {
      "query_xml": "<xmlRoot>...</xmlRoot>",
      "out_xml": "<xmlRoot></xmlRoot>",
      "is_proc": false
    }
  ],
  "ClientInfo": {
    "IsLogin": true,
    "Status": true
  }
}
```

### 响应字段

| 字段 | 说明 |
|---|---|
| Options[].query_id | 模板 ID |
| Options[].title | 模板标题 |
| QueryXml[0].query_xml | 查询条件 XML（指定 query_id 后有值） |
| QueryXml[0].out_xml | 导出栏位 XML |
| QueryXml[0].is_proc | 处理事项相关状态 |

已观察到的标题：宁德授权请款、广汽周五授权证书更新、微众OA反馈、微众新申请反馈、宁德25号、微众官文、宁德新申请递交、宁德预审、宁德时代官文、微众-月初、宁德OA反馈。

### QueryXml 规则

- 根节点：`xmlRoot`
- 普通控件：节点名 = 控件 id，节点值 = 控件值
- Tree / object：同时写 `{id}` 与 `{id}_text`
- checkbox / radio：仅勾选时写入

示例（宁德25号）：

```xml
<xmlRoot>
  <customer_name_vague>宁德时代</customer_name_vague>
  <customer_country>CN</customer_country>
  <customer_country_text>中国</customer_country_text>
  <case_type>31D1A147-2931-43B5-94AE-B72B1525BA8A</case_type>
  <filetype>603ca943-a07a-4894-9461-29dff2d60c4b</filetype>
  <filetype_text>专利证书(CERT)</filetype_text>
  <selfileclass>general</selfileclass>
  <selfileclass_text>所有文件（不含官方来文zip及分析纸件通知书）</selfileclass_text>
  <txtpost_s>2025-09-15</txtpost_s>
  <txtpost_e>2025-10-20</txtpost_e>
</xmlRoot>
```

示例（微众OA反馈，`query_id=227BFA59-A8A7-4EC6-928D-50FB5C29F960`）：

| 字段 | 值 |
|---|---|
| customer_name_vague | 微众 |
| filetype | 5 个文件类型 ID，逗号分隔 |
| filetype_text | 电子申请回执(200105),权利要求书(100001),权利要求书(161603),修改对照页(100042),意见陈述书(100012) |
| TreefiletypetxtSearch | 意见陈述 |
| txtupdate_s | 2025-12-15 |

页面回填：解析 `query_xml`，按节点名匹配 `table_element` 内 input / select / textarea / checkbox 的 id。

## SearchQueryHisSave

保存或更新历史查询条件。

前端仅在 `is_out_save` 或 `is_query_save` 至少一个为 `true` 时发起保存。

`query_id` 为空为新建；有值为更新。有 ID 时是否覆盖原条件未最终抓包确认。

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `SearchQueryHisSave` |
| is_proc | 否 | 处理事项相关状态 |
| is_out_save | 是 | 是否保存导出栏位 |
| is_query_save | 是 | 是否保存查询条件 |
| query_save_title | 条件 | 模板标题 |
| query_id | 否 | 空=新建 |
| query_xml | 条件 | 查询条件 XML |
| out_xml | 条件 | 导出栏位 XML |
| query_type | 是 | `FileSearch` |

### 请求示例

```text
Call=SearchQueryHisSave
is_proc=false
is_out_save=false
is_query_save=true
query_save_title=我的查询条件
query_id=
query_xml=<xmlRoot>...</xmlRoot>
out_xml=
query_type=FileSearch
```

## SearchQueryHisDelete

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `SearchQueryHisDelete` |
| query_id | 是 | 模板 ID |

### 请求示例

```text
Call=SearchQueryHisDelete
query_id=<历史条件ID>
```
