# 公共数据

## GetFileType

获取文件类型树。

**地址**：`POST /AjaxServers/Common.ashx`

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFileType` |
| log_pagename | 否 | 示例 `CaseManage.aspx` |

### 请求示例

```http
POST /AjaxServers/Common.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=GetFileType&log_pagename=CaseManage.aspx
```

### 响应

文件类型树。节点 ID 用于 `GetSearchFiles.filetype` 等字段。完整树 Schema 未落盘。

## IPGetBasicData

获取系统基础枚举（GUID → 显示名称）。

用途包括但不限于：

- `case_type`
- `filetype`
- `fileclass`
- 其它 Tree / object 控件内部 ID

Handler、完整参数、响应结构未落盘。
