## IPGetBasicData

文件查询页初始化时加载的基础枚举。页面脚本是 `Scripts/Page/Patent/FileSearch.js`。

```http
POST /AjaxServers/CaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `IPGetBasicData` |
| log_pagename | 否 | `FileSearch.aspx` 或 `FileSearchMail.aspx` |

没有其它业务参数。响应约 360KB。

顶层键：

```text
customer_kind, ProcStatus, czx_list, ReviewStage, CaseStatus, zdypg1_list,
ApplyType, CaseType, work_difficulty_coefficient, RelateType, ClientInfo,
case_coefficient, flh_list, Country, Case_direction, jsjd_list, ProtectionCenter,
CaseBranchDept, CaseAgencyLevel, zdypg2_list, PayType, AgencyList, Products,
CtrlProc, from_stage, customerfrom, market_business_type, customerclass,
generation_status, ApplicantType, BussType, customer_status,
delivery_business_type, ApplyTags, sourcetype, Technical, Sentence
```

这次为 `null` 的键：`czx_list`、`zdypg1_list`、`work_difficulty_coefficient`、`flh_list`、`jsjd_list`、`ProtectionCenter`、`zdypg2_list`、`market_business_type`、`generation_status`、`delivery_business_type`、`ApplyTags`、`Sentence`。

文件查询实际用到的数组：

| 键 | 本次数量 | 元素字段 |
|---|---|---|
| CaseType | 7 | `case_type`、`case_type_id`、`case_type_code` |
| Country | 312 | `value`、`country_code`、`text_zh_cn`、`text_en_us`、`text_zh_tw`、`text_ja_jp`、`is_madrid` |
| CaseStatus | 158 | `case_status`、`case_status_id`、`case_type_id`、`status_class` |
| ApplyType | 28 | `apply_type`、`apply_type_id`、`case_type_id`、`country_id` |
| BussType | 按案件类型过滤 | `bussType`、`business_type_id`、`business_type_code`、`case_type_id` |
| customer_status | 有数据 | `customer_status`、`customer_status_id`、`case_type_id` |
| CtrlProc | 444 | `ctrl_proc`、`ctrl_proc_id`、`case_type_id`、`country_id`、`business_type_id`、`apply_type_id` |
| ProcStatus | 18 | `proc_status`、`proc_status_id`、`status_code` |
| Case_direction | 4 | 字典行，`value` 长度 2，`text_zh_cn` 是显示名 |
| CaseBranchDept | 3 | `dept_id`、`dept_name`、`dept_full_name`、`dept_code`、`parent_id`、`dept_level`、`is_branch`、`is_charge`、`is_enabled` |

`CaseStatus.status_class` 为 `ALL` 或 `CASE`，并且 `case_type_id` 等于当前案件类型时，才进入文件查询的案件状态树。`ApplyType`、`BussType` 同样按 `case_type_id` 过滤。

字典行的公共字段是 `dictionary_id`、`dictionary_name`、`dictionary_description`、`value`、`text`、`text_zh_cn`、`text_en_us`、`text_zh_tw`、`text_ja_jp`、`seq`，其余 `type`、`id`、`table_type`、`is_date`、`date_change_sql` 这次为空。

`AgencyList` 本次 327 条，`Products` 364 条。元素键已在响应里，名称未记录。

## GetFlowdirection

文件查询页加载文件状态、分部、处理状态、流向，以及下载重命名用的列名。

```http
POST /AjaxServers/CaseInfo.ashx
```

只有 `Call=GetFlowdirection` 和 `log_pagename`。

| 键 | 本次数量 | 元素 |
|---|---|---|
| FileStatus | 4 | 字典行，`value` 长度 2 |
| CaseBranchDept | 3 | 与 `IPGetBasicData.CaseBranchDept` 相同 |
| ProcStatus | 18 | `value`（GUID）、`text_zh_cn`、`status_code`、`text_en_us`、`text_ja_jp` |
| Case_direction | 4 | 字典行，`value` 长度 2 |
| DownLoadFileName | 32 | 字典行。`value` 是列名，长度约 9；`text_zh_cn` 是显示名 |

`DownLoadFileName.value` 会作为 `GetFileName.new_filename` 里 `colname` 段的列名。

## LoadFileTypeByCaseType

文件查询的文件类型树。页面绑定到 `GetSearchFiles.filetype` 的是这个接口，不是下面的 `GetFileType`。

```http
POST /AjaxServers/Common.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `LoadFileTypeByCaseType` |
| official | 是 | 页面固定传 `1` |
| case_type | 是 | 案件类型 GUID |
| file_type | 否 | 页面传空字符串 |
| log_pagename | 否 | `FileSearch.aspx` |

响应：`FileType` 数组。本次专利类型 651 个节点。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | GUID | 节点 ID，提交到 `filetype` |
| name | 字符串 | 显示名 |
| pid | 字符串 | 父节点。根节点为空 |
| TreeType | 字符串 | 本次有两种值，长度都是 4 |
| seq | 整数 | 排序 |
| tree_level | 整数 | 层级 |

## LoadDeptTree

部门树。文件查询的承办部门、期限监控的承办部门和处理人部门都调用它。`public.js` 的 `LoadDeptTree` 把结果放进 `sessionStorage`，所以打开页面的 HAR 里经常看不到这次请求。

```http
POST /AjaxServers/Common.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `LoadDeptTree` |
| log_pagename | 否 | 公共封装会带，如 `FileSearch.aspx` |

没有其它业务参数。响应键是 `DeptTree`。2026-09-28 只读核对 201 条。

| 字段 | 说明 |
|---|---|
| id | 节点 ID。筛选里的 `dept_id`、`pic_dept_id` 提交这个值 |
| name | 显示名 |
| pid | 父节点。根节点为空。同一次响应里父节点能对上 |
| TreeType | 节点类型 |
| is_branch | 是否分部 |
| is_charge | 是否承办部门。页面可按这个值只显示承办部门 |

## GetTreeAgent

代理机构树。文件查询页 `#agency_id` 绑定的是它，不是 `IPGetBasicData.AgencyList`。

```http
POST /AjaxServers/Common.ashx
```

HAR `文件管理入口`、`发文客户` 都只有 `Call=GetTreeAgent` 和 `log_pagename`。`LoadTreeAgent` 读取的响应键是 `TreeUser`，元素形态与 `GetTreeUser` 相同。这次没有单独保存响应正文，不能把上面的 771 条当成代理机构数量。

期限监控的代理机构输入框不是这棵树。那个框调用 `CaseInfo.ashx` 的 `LoadAgency`，参数是 `Key`，响应键是 `agency`。`LoadAgency` 的元素字段这次没有保存。

## GetApplyTags

专利标签。

```http
POST /AjaxServers/CaseInfo.ashx
```

只有 `Call=GetApplyTags` 和 `log_pagename`。期限页用 `LimitMonitor.aspx`。

响应键是 `ApplyTags`。没有标签时为 `null`，同时 `ClientInfo.Result` 仍可能是 `false`。这是空数据，不是失败。2026-09-28 当前账号就是 `null`，响应约 204 字节。

有数据时，页面读取 `id` 和 `name`。筛选提交 `id`。`IPGetBasicData.ApplyTags` 这次同样是 `null`，不要从基础枚举里再找一份标签。
