# 邮件签名

个人设置里的「邮件签名」和发文页底部的「邮件签名」不是同一个接口。邮箱上预留的那段 `Signature` 又是第三条。三条都会返回 HTML，保存时页面还会再编码一次。姓名、电话、邮箱和签名原文没有写入本文。

`HAR/签名` 已对照过。文件约 38KB，四条业务响应都是 HTTP 200，长度分别是 4878、124082、2478、4897 字节。`content` 里只有 `size` 和 `mimeType`，没有 `text`。124082 字节的代理机构响应不可能装进这个文件，所以它不是带正文的 HAR。下面只记录请求、长度，以及页面脚本实际读取的键。没有把猜测出来的整段 JSON 当成已核对原文。

| 用途 | Handler | Call | 这次结果 |
|---|---|---|---|
| 个人设置名单 | Login.ashx | GetMailSignatureSettingList | 200，4878 字节，正文未保存 |
| 个人设置一条的正文 | Login.ashx | GetSignatureset | 200，4897 字节，正文未保存 |
| 签名页代理机构下拉 | CaseInfo.ashx | GetAencyList | 200，124082 字节，正文未保存 |
| 发文页下拉 | Mail.ashx | GetSignature | 200，4681 字节，正文未保存。字段名已在 2026-09-24 只读核对 |
| 发文页写进正文的预留段 | Login.ashx | Getmailset | 页面脚本已核对，这次抓包没有这条请求 |

页面脚本是 `Scripts/Page/Manage/SignatureInfo.js` 和 `Scripts/Page/Mail/mail.js`。

## GetMailSignatureSettingList

个人设置打开 `SignatureInfo.aspx` 时，表格 `SignatureSetting` 发出。来源：2026-09-29 抓包。

```http
POST /AjaxServers/Login.ashx
```

| 参数 | 本次值 |
|---|---|
| Call | `GetMailSignatureSettingList` |
| pageSize | `10` |
| pageIndex | `1` |
| _PK | `signature_id` |
| searchKey | 空字符串 |
| colsel | `;sn;signature_name;update_time;is_enabled;` |
| log_pagename | `SignatureInfo.aspx` |

`_PK` 是行主键。`colsel` 是表格要显示的列，不是响应里只有这四列。点某一行时，页面用该行的 `id` 作为 `signature_id` 去调 `GetSignatureset`。

读取端目前认这些键。键不在、或 `signature_id` 不是 GUID、或没有 `signature_name` 时，这一行丢掉。

| 键 | 说明 |
|---|---|
| TableRows | 行数组。不是数组时按没有名单处理 |
| TableRows[].signature_id | GUID |
| TableRows[].signature_name | 显示名 |
| TableRows[].is_enabled | 页面写回「是否有效」下拉。读取端把 `true`、`1`、`"1"`、`"true"`、`"是"` 当成有效 |

`sn`、`update_time` 在 `colsel` 里，响应里是否还有别的列，这次正文没留下，不能补。

## GetSignatureset

选中名单一行后读取这一条。来源：2026-09-29 抓包。`signature_id` 是 GUID，原文不记录。

```http
POST /AjaxServers/Login.ashx
```

| 参数 | 说明 |
|---|---|
| Call | `GetSignatureset` |
| signature_id | 名单行的 GUID |
| log_pagename | `SignatureInfo.aspx` |

`SignatureInfo.js` 在 `SignatureInfo` 不为 `null` 时读第 0 条：

| 键 | 页面用途 |
|---|---|
| SignatureInfo[0].signature_name | 名称 |
| SignatureInfo[0].is_enabled | 「是否有效」 |
| SignatureInfo[0].agencyid | 代理机构下拉的值，对应 `GetAencyList` 的 `agency_id` |
| SignatureInfo[0].signature_content | 编辑器正文。页面先 `HTMLDecode` 再写入 |

`signature_content` 是 HTML，而且保存时用 `HTMLEncode` 又编了一层。现场见过 `&amp;nbsp;` 这种两层实体：只解一次会在页面上留下字面的 `&nbsp;`。换行来自 `<br>` 和块级结束标签。图片、样式和其余标签不保留。

没有 `SignatureInfo[0].signature_content` 时，这一条没有正文，不能拿名单上的名称充正文。

## GetAencyList

签名页初始化代理机构下拉。Call 的拼写就是 `GetAencyList`。来源：`SignatureInfo.js`，2026-09-29 抓包为 200，正文未保存。

```http
POST /AjaxServers/CaseInfo.ashx
```

只有 `Call=GetAencyList`。脚本读取 `AgencyList[]`：

| 键 | 说明 |
|---|---|
| agency_id | 选项值 |
| agency_code | 有值时显示成 `(代码)名称` |
| agency_name_cn | 名称 |

`agency_code` 为空时只显示 `agency_name_cn`。

## GetSignature

发文页 `mail.aspx` 的「邮件签名」下拉。来源：`HAR/跳转到发文`、`HAR/期限监控跳转发文页面`、`HAR/在发文审核中结束流程`。三次请求相同，响应都是 4681 字节，正文未保存。

```http
POST /AjaxServers/Mail.ashx
```

| 参数 | 说明 |
|---|---|
| Call | `GetSignature` |
| mailset_id | 当前发件邮箱 GUID。没有 GUID 时页面仍会发，读取端不发 |
| log_pagename | `mail.aspx` |

`mail.js` 的 `Mail.GetSignature` 读 `Signature` 数组。2026-09-24 只读核对过元素字段，内容没有写入文档。

| 键 | 说明 |
|---|---|
| signature_id | 下拉的 value |
| signature_name | 下拉的文字 |
| signature_content | 选中后写入正文的 HTML |
| seq | 顺序。页面脚本这次没有读它 |

下拉第一项 `0` 是页面自己加的「请选择」，不是接口返回的。没有名称或没有正文的项不采用。`is_default`、`IsDefault`、`is_reserved`、`reserved` 为 `true`、`1` 或 `"1"` 时，这一条是标明要写入正文的那一条。多项都标明，或多项都没标明时，不拿第一条充数。

这个接口不代替个人设置的 `GetSignatureset`。它挂在 `mailset_id` 上，不是挂在当前登录人的签名名单上。

## Getmailset

发文页在正文里插入预留签名时调用。来源：`mail.js` 的 `Mail.AddSignature`。这次签名页抓包没有它。

```http
POST /AjaxServers/Login.ashx
```

| 参数 | 说明 |
|---|---|
| Call | `Getmailset` |
| mailset_id | 当前发件邮箱 GUID |

脚本只在 `mailsetinfo` 不为 `null` 时读 `mailsetinfo[0].Signature`。有值时包进 `<div id="div_sg{mail_id}">` 写进编辑器。这是邮箱上的预留 HTML，不是 `GetSignature` 下拉里的 `signature_content`。其余 `mailsetinfo` 字段这次没有从响应里核对。

`MailinfoInit.mailsettinglist[].Signature` 是同一段预留内容在打开邮件页时带出来的副本。字段见 [09-期限监控.md](09-期限监控.md)。

## 保存和删除

`SignatureInfo.js` 里还有两个写操作。这次没有调用，响应未核对，不发明成功条件之外的字段。

`SaveSignatureset`，`POST /AjaxServers/Login.ashx`：

```text
Call=SaveSignatureset
signature_id
signature_name
is_enabled
signature_content    HTMLEncode 之后的编辑器 HTML
agencyid
```

成功看 `ClientInfo.Result`。为真时重新加载名单。

`DeletSignatureset`，同一个 Handler。Call 的拼写是 `DeletSignatureset`。参数只有 `Call` 和 `signature_id`。`ClientInfo.Result` 为假时页面提示删除失败。
