# 文件查询 GetSearchFiles

Handler：`POST /AjaxServers/CaseInfo.ashx`  
页面：`FileSearch.aspx` / `FileManager.SearchFile()`

已验证：`case_volume=PA2622582CND-YS` 时 `TableRowsCount=24`。

---

## 请求

| 项 | 值 |
|---|---|
| Method | POST |
| 地址 | `/AjaxServers/CaseInfo.ashx` |
| Call | `GetSearchFiles` |
| Content-Type | `application/x-www-form-urlencoded; charset=UTF-8` |

当前抓包 Payload 共 117 个字段。未使用的业务条件传空字符串。是否全部必传未验证；当前按全量提交。

可选参数 `order_by_search` 仅在表格排序时出现，不在 117 项固定列表中。

---

## 框架参数

| 参数 | 类型 | 示例 | 说明 |
|---|---|---|---|
| pageIndex | int | 1 | 页码，从 1 开始 |
| pageSize | int | 50 | 每页条数 |
| Call | string | GetSearchFiles | 固定 |
| IsFirst | string | false | `true`=页面初始化查询；`false`=手工查询。前端在 `IsFirst=false` 且无业务条件时提示「请输入查询条件！」 |
| is_pat | int | 0 | 租户配置；当前环境为 0 |
| colsel | string | 见 5.4 | Layui 当前列字段集合 |
| _t | long | 1790046359929 | 毫秒时间戳 |
| log_pagename | string | FileSearch.aspx | 页面名 |
| _doneCallback | — | undefined | 前端回调序列化产物，非业务条件，自定义请求可不传 |
| order_by_search | string | ` case_volume asc` | 可选排序，字段 + `asc`/`desc`，前有空格 |

### colsel（当前环境）

```text
;undefined;undefined;case_id;file_name;file_status;case_volume;case_volume_customer;app_no;case_name;file_type;file_desc;post_date;upload_time;ctrl_proc_name;apply_type;customer_name;customer_status;legal_due_date;case_status;
```

前两节 `undefined` 对应无 `field` 的序号列、复选框列。是否可省略未验证。

### 当前环境固定业务默认值

| 参数 | 值 | 说明 |
|---|---|---|
| fileclass | general | 页面默认「所有文件（不含官方来文 zip 及分析纸件通知书）」 |
| case_type | 31D1A147-2931-43B5-94AE-B72B1525BA8A | 内部案件类型 ID，非显示文本，不可当作全局常量 |
| is_pat | 0 | 配置项 |
