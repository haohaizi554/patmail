# PatMail

专利事务智能自动化系统。面向知识产权代理机构和企业 IP 部门，把案件查询、文件筛选、客户发文规则和流程提交从人工操作收成可配置的自动执行。

当前仓库包含方案、接口资料和浏览器插件基础框架。插件安装与构建说明见 [patmail-extension/README.md](patmail-extension/README.md)，本阶段不包含后端实现。

## 目录

| 路径 | 内容 |

## 目标流程

用户配置一次客户规则、查询模板和发文模板。之后由插件按接口查询文件、生成发文并提交，人工只做最终审核。

## 接口范围

服务为 ASP.NET WebForms，统一入口 `POST /AjaxServers/*.ashx`，业务动作由 `Call` 分发。

已落盘：案件信息、历史查询条件、文件查询 `GetSearchFiles`、字段映射。  
入口已确认、参数未齐：文件上传下载、客户发文、邮件草稿、流程审批。

细节见 [API/README.md](API/README.md)。
