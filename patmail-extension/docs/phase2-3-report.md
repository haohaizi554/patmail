## 已实现

- 五条只读字典路由，沿用 `EasyRuntime`。
- `IPGetBasicData`、`GetFlowdirection`、`LoadFileTypeByCaseType`、`GetFieldColumn`、`LoadListColumn` 的归一化适配器。
- 统一 `DictionaryOption`。不同数组使用各自的 ID 和显示名字段。
- 文件描述树：层级、排序、搜索、多选、重复 ID、无效父节点和环的诊断。
- 业务 Schema 和文件查询表单。案件类型联动文件描述、申请类型、业务类型和案件状态。
- 字典缓存：用户隔离、TTL、手动刷新参数、并发去重、会话失效清理。
- 列表列配置可以替换 `colsel`；没有可用列时保留环境默认值。
- 历史模板预览用字典把已知 ID 显示成中文，未知 ID 显示「未识别的历史 ID」。

## 尚待验证

在已登录的 EASY 页面：

1. 检测登录态。
2. 打开案件类型，核对中文名称来自 `CaseType`，值是 GUID。

7. 给客户加上覆盖字段，预览来源后查询，并翻到下一页。
8. 退出原网站，确认会话失效后字典缓存不再被当作已登录数据。

## 当前限制

- 客户主数据没有可靠的内部 ID 列表，客户条件仍是名称模糊查询。
- 文件来源只有当前环境核对过的 `general`，不是完整字典。
- `DownLoadFileName` 只缓存，不下载。
- 禁用的自定义栏位不能在表单里新编辑；历史值不会被删掉。
- 文件描述树默认折叠，搜索最多 50 条。
- 本地配置在拿不到用户 GUID 时仍使用 `unscoped`。
