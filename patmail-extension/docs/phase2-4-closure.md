# Phase 2.4 遗留问题收口

日期：2026-09-26。以下三项在 Phase 2.5 开始前收口。真实 EASY 现场核对仍未做。

| 项 | 状态 | 说明 |
|---|---|---|
| 客户身份 | 已收口 | 绑定保留原始客户名称、客户配置 ID、确认状态和来源 `explicit`。名称不一致时按原始客户名称分组，未勾选的组不会写入绑定。不按名称相似度推断 |
| 不同已确认身份 | 已收口 | 分组键包含客户配置 ID 和原始客户名称。同一配置下两份不同原始客户名称不会合成一封草稿 |
| 描述映射唯一 | 已收口 | 有文件描述 ID 时用 `id:`，否则用标准化原文 `text:`。同一有效键对应两个发文类型时保存被拒绝，历史冲突让草稿 `blocked`，不取第一条 |
| 映射维护 | 已收口 | 浮窗可编辑、禁用、删除本地映射。成功保存时版本加一 |
| 草稿失效 | 已收口 | 指纹覆盖文件、绑定、规则版本、用户和站点。指纹不一致时不能把旧预览提交给 `MailCustomer` |

查询行仍然没有可靠的客户内部 ID。客户配置 ID 只存在 PatMail 本地，不会写入 EASY 的 `customer_id`。
