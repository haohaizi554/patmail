# 系统设置

顶栏个人资料或侧边底部「系统设置」进入。

| 区域 | 控件 | 作用 |
|---|---|---|
| 头像 | 上传头像 | 登录 EASY 后上传自定义头像，或从预设里选一个 |
| 头像 | 放大 | 查看当前头像大图 |
| 头像 | 删除自定义头像 | 恢复默认 |
| 发文写入 | 并发数 | 同时创建/提交几封信，网络不稳就调小 |
| 发文写入 | 写开关 | 总闸。关着时页面和 AI 都不会真正向 EASY 提交 |
| AI 助手 | 思考开关 | 打开后模型先思考再回答，等待时显示「正在思考」 |
| AI 助手 | 连通测试 | 测一下本地模型链路是否可用 |

写开关的读取状态会显示在下方；「正在读取写开关」表示还没就绪。
