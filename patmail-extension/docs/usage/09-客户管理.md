# 客户管理

维护客户档案和这位客户发文要用的默认配置。

## 列表操作

| 按钮 | 作用 |
|---|---|
| 联系人 | 打开这位客户的联系人名单 |
| 查询 | 打开客户的查询条件（文件查询或期限监控二选一） |
| 备注 | 写一句备注 |
| 编辑 | 改客户资料 |
| 删除 | 删除客户配置 |

## 编辑表单

| 控件 | 作用 |
|---|---|
| 重新读取（客户名单 / 审核人 / 发件邮箱 / 发文类型） | 从 EASY 重新拉对应名单 |
| 使用默认 | 发文方式、审核人、发件邮箱直接套默认值 |
| 发文方式 | 这位客户按哪种方式合并发文 |
| 审核人 | 提交给谁审核 |
| 发件邮箱 | 默认发件邮箱 |
| 发文类型 | 这位客户常用的发文类型 |
| 客户要求 | 读取 EASY 客户页的要求原文，仲裁时用作材料 |
| 备注行 | 同一客户有多条配置时写一句分辨 |

保存（继续保存）/ 另存一套 / 取消。
