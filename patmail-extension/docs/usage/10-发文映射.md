# 发文映射

维护文件描述到发文类型的映射，以及各客户的收件人和签名。

| 区域 | 作用 |
|---|---|
| 文件描述 → 发文类型 | 来文上的文件描述对上 EASY 的发文类型，一条描述一行 |
| 收件人 | 按客户配默认收件人 |
| 默认发件邮箱 | 按客户配默认发件邮箱 |
| 默认审核人 | 按客户配默认审核人 |
| 签名 | 默认签名和操作员签名，自选任务的签名下拉从这里读 |
| 客户发文策略 | 按客户选查询方式（文件查询/期限监控）和发文方式，可存多套并写备注 |

每块都有保存按钮（主按钮保存，次按钮存为草稿/另一套）。文件管理的工作流和自选任务都依赖这里的映射。
