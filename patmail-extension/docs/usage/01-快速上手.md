# 快速上手

PatMail 是挂在 EASY 专利管理系统上的 Chrome 扩展，把「读表格、核对案件、定收件人、创建发文、提交审核」这条链路自动化。

## 安装

1. 先运行构建（项目根目录的 start.py），产物在构建输出目录里。
2. 打开 chrome://extensions，右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选中构建输出目录。
4. 之后每次改完代码，都要重新跑 start.py，再回到 chrome://extensions 点这张卡片上的「重新加载」。

## 连接 EASY

插件本身不存账号密码。连接靠浏览器里的 EASY 会话：

1. 在浏览器里打开对应客户系统并登录。
2. 大客户系统是 `http://183.36.43.66:88`，中小客户系统是 `http://183.36.43.44:88`。
3. 登录完成后打开 PatMail，顶部右上角的个人资料下标会显示「EASY 已连接」。
4. 会话过期时插件会提示登录已失效，回浏览器里重新登录 EASY 一次即可。

## 选客户系统

顶栏右侧有两个按钮：**大客户**、**中小客户**。

- 选中哪个，插件就查哪个系统的数据，发件邮箱、发文类型、客户名单都会按这个系统读。
- 切换会清掉当前核对进度，重新连接。

## 发文链路总览

按工作流发文一整套流程是：

| 步骤 | 在哪做 | 干什么 |
|---|---|---|
| 1. 选工作流 | 发文任务 → 工作流 | PCT 提醒、文件管理或自己搭的工作流 |
| 2. 传表格 | 同上 | 上传 .xlsx，插件读文号、客户、收件人 |
| 3. 核对 | 自动 | 按文号去 EASY 查案件、发文流程状态，顺带带回客户要求和著录项目 |
| 4. 仲裁 | 自动或手动 | IPR 空着的行交给 AI 定收件人，拿不准的留空 |
| 5. 提交 | 期限表 | 勾选事项，点「提交到 EASY」，创建发文并交给审核人 |

写开关（系统设置里）控制插件能不能真正向 EASY 提交；关着时所有提交都会被拦下来。
