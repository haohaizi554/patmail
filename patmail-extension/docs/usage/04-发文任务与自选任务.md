# 发文任务页

发文任务页有两个入口，顶部两个按钮切换：**自选任务**、**工作流**。

## 自选任务（DIY）

手工挑文件建一条发文计划，适合临时补发：

| 控件 | 作用 |
|---|---|
| 客户 | 选择客户，列出这位客户的文件 |
| 发件人 | 选择发件邮箱 |
| 签名 | 选择邮件签名，签名内容在发文映射里维护 |
| 文件名 | 按文件名缩小范围，回车即可搜索 |
| 读取发文类型 | 发文类型下拉没数据时点一下重新拉 |
| 搜索文件 | 按上面条件查文件 |
| 应用规则 | 按发文映射把文件描述对上发文类型 |
| 生成预览 | 把选中的文件拼成一条任务预览 |
| 收件人 | 手填收件人地址，多个用分号分开 |

生成的任务记在插件里，之后在列表里点开继续，或去工作流页批量处理。
