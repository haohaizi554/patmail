# 顶栏与侧边导航

## 顶栏

| 元素 | 作用 |
|---|---|
| PatMail 徽标 | 点击回首页 |
| 让每一封专业邮件，都温柔且高效 | 口号装饰 |
| 核对进度条 | 发文任务页核对时显示彩虹进度和百分比，例如「100%（179/179）核对完成」 |
| AI 助手 | 打开/收起 AI 助手浮窗，见「AI 助手」章节 |
| 文档 | 打开本文档浮窗，左侧文件树分「使用文档」和「接口文档」两组 |
| 个人资料 | 显示当前登录人姓名和连接状态；点头像可放大；点击进系统设置 |

## 侧边导航

| 菜单 | 页面 | 干什么 |
|---|---|---|
| 首页 | 首页 | 概览和联系方式 |
| 文件管理 | 文件查询 | 按条件查 EASY 里的文件 |
| 期限监控 | 期限表 | 独立查期限，也可在发文任务页内嵌使用 |
| 客户管理 | 客户列表 | 维护客户、联系人、查询条件和默认配置 |
| 发文映射 | 映射规则 | 文件描述到发文类型的映射、收件人、签名 |
| 发文任务 | 任务页 | 发文的核心入口，自选任务和按工作流发文都在这 |
| 发文记录 | 记录页 | 查每次发文的批次和结果 |
| 查询模板 | 模板页 | 保存文件查询和期限查询的常用条件 |
| 邮件草稿 | 草稿页 | 打开建过但没提交的任务草稿 |
| 工作流 | 工作流页 | 配置自动发文的流程 |
| 系统设置 | 设置页 | 头像、写开关、并发数、AI 助手 |
