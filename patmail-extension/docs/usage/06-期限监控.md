# 期限监控

期限监控既是独立页面（侧边「期限监控」），也内嵌在按工作流发文页里。两边同一套查询和提交。

## 查询表单

| 控件 | 作用 |
|---|---|
| 类型按钮组（全部/缴费/中止/放弃/撤回/优先权/费用） | 按处理事项类型过滤；「流程」页签是预留位 |
| 我方文号 | 一个文号，或多个用分号、空格、换行隔开 |
| 申请号 | 按申请号查 |
| 客户名称 | 按客户名称查 |
| 重置 | 清空全部条件 |
| 查询 | 执行查询 |
| 模板下拉 | 套用查询模板页保存的条件 |

## 列表

列依次是：勾选框、我方文号、案件名称、处理事项、客户、申请号、官方期限、客户期限、内部期限、流程状态。

流程状态的配色：蓝色是还没提交审核，灰绿是已发文未管制完成日，紫色是不用发，绿色是已经审核完成，橙色是已提交审核，灰底是库里没有或没查成。

## 勾选与提交

| 按钮 | 作用 |
|---|---|
| 全选本页 / 全选所有 / 全选所有（非补非仲） | 只勾还能提交的行；已提交审核、不用发、发过的不能勾 |
| 确认勾选 N | 记下提交范围。独立页面里这个范围会写进当前工作流任务 |
| 提交到 EASY | 按合并逻辑提交：有名字的行按写回收件人，空着的行按发文规则勾选联系人兜底 |

写开关关着时会直接提示「写开关在系统设置里关着，没有提交到 EASY」。
