# AI 助手

顶栏「AI 助手」按钮打开浮窗。可以问操作问题，也能驱动插件干活。

| 区域 | 作用 |
|---|---|
| 输入框 | 直接打字。以 / 开头会弹出技能列表（如 /建任务） |
| 回车 / 发送 | 发给模型；正在回复时也可以接着发，会排队按顺序办 |
| 对话气泡 | 助手回复支持表格、列表、代码的 Markdown 排版；每条可复制 |
| 正在思考 / 过程 | 折叠面板，点开看模型当前在想什么、在跑哪一步；仲裁分批时这里显示「正在仲裁收件人和抄送 第 N/M 批」 |
| 会话列表 | 左上可看历史会话、新开对话、给对话改名 |
| 关闭按钮 | 收起浮窗，会话保留 |

核对后自动仲裁的批次进度也显示在这个浮窗里。写开关关着时，让助手提交它也会如实说明没有提交。
