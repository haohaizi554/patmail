# 文件管理工作流

工作流里选「文件管理」进入这一页。适合没有固定 PCT 表格、按文件批量发文的客户。

| 控件 | 作用 |
|---|---|
| 选择客户 | 选一个绑好了文件管理配置的客户 |
| 查询条件 | 按客户保存的查询条件查出文件，通常按文件描述或日期 |
| 发文映射 | 文件描述对上发文类型，映射规则在发文映射页维护 |
| 收件人 | 案件联系人 |
| 抄送 | 默认发件人和商务 |
| 审核人 | 默认审核人 |
| 标题 | 标题模板 |
| 正文 | 发文页邮件签名下拉里的格式 |
| 发明人 | 所属部门包含研发本部时，文件描述右侧写入全部发明人，顿号分隔 |
| 提交 | 创建发文并提交给默认审核人 |

文件管理路径的「完成事项」保留草稿原值，不会像 PCT 提醒那样自动勾上本封的处理事项。
