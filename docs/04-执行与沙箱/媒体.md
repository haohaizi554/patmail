# 媒体

生成和理解都是工具。没有配提供商，工具就不出现。图片、视频和音乐在聊天里异步跑，完成后再投递。语音合成是同步的。把图片嵌进工具结果，等于以后每一轮都再付一次图的费用，所以要有次数和体积上限。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 生成 | `image_generate`、`video_generate`、`music_generate`，聊天里后台完成再发 | 图像和视频是可插的提供商 | 客户端若支持，作为工具或附件 |
| 理解 | 入站图片、音频、视频走视觉模型和理解插件 | 视觉内容块。原生嵌入记在工具结果里反复发送 | 图片作为用户或工具内容块 |
| 说话 | `tts` 同步。实时对话走 Talk，不走一次性媒体工具 | TTS 提供商。流式语音另有合同 | 无 Gateway Talk |
| 文件根 | 任务工作目录、批准的文件系统根、Gateway 媒体库。越界和符号链接拒绝 | 粘贴的图存到家目录的 `images/` | 附件在会话侧 |

## OpenClaw

图像、视频、音乐、理解入站媒体、把回复说出来，都由工具驱动。每个工具至少有一个后端提供商才出现在目录里。

`image_generate`、`video_generate`、`music_generate` 在聊天会话里异步：后台跑，好了再发。TTS 同步。实时语音用 Talk 会话，不走这一次性媒体工具。Talk 有三种模式：提供商原生的 realtime、本地或流式的语音识别加合成、以及只观察的转写。这三种和电话、会议、浏览器实时、本机按住说话共用目录、事件信封和取消语义。

`view_image`、`pdf` 和生成工具的参考图使用任务的工作目录解析相对路径。跑在 git worktree 里的任务可以读那棵树里的媒体，即使 agent 的默认工作区在别处。只允许工作区时，根是会话批准的文件系统根，可以包括当前目录的父目录。主机工具还能读 Gateway 的媒体库，例如浏览器截图和暂存的入站附件。根以外的路径和符号链接拒绝。沙箱工具走沙箱文件系统。选了主机 worktree 不等于获得沙箱外的访问。

媒体任务事实只包含已启用的媒体工具，以及属于当前请求者的任务。恢复出来但没有记录请求者的任务，用配置的会话主人。已完成的任务不放进提示。

入站语音可以走批量转写，或走语音通话的流式转写。播放在控制界面和原生应用里内联，带托管访问和可移植的播放副本。

## Hermes

CLI 可以把剪贴板图片贴进对话。图片存成家目录 `images/` 下的 PNG，提交时作为视觉内容块送给模型。只有图片、没有文字时，终端送不出二进制，要用 `/paste`。远程 SSH 读不到本机剪贴板。

原生视觉把图片烤进工具结果。这份结果会在之后的每次 API 调用里重发。体积和重复政策在 `vision` 配置：目标字节数、每张图的调用次数。计数键是会话 id 加解析后的源，所以同一文件的区域裁剪共享次数。默认上限只在委派子进程上下文里生效。新的嵌入费用规则放在这一处，不另做计数器。浏览器截图走同一套。

图像生成和视频生成是提供商插件，挂在对应的 ABC 上。没有密钥或没启用时，工具不进这一会话的 schema。生成结果若再被视觉工具读回，又会进入上面的嵌入预算。

TTS 是工具加可替换的提供商，包括命令行提供商。它把音频作为出站媒体，不把整段波形写进系统提示。

## Claude Code

图片是消息里的内容块。读图和截图的结果受工具结果预算约束：单条和单轮都有字符上限，超出落到 `tool-results/`。没有 Talk 会话，也没有「生成任务完成后唤醒原渠道」的 Gateway 合同。视觉分析若再把大图留在上下文里，下一轮压缩会按工具结果预算裁它。
