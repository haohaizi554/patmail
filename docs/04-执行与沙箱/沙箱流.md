# 沙箱流

原生沙箱执行默认不流。打开实验开关之后，沙箱里的进程按顺序送出标准输出、标准错误或终端通知。OpenClaw 只留一份有界的近期输出缓冲，给轮询和重放。长时间的进程不能把应用服务器桥无限撑大。进程退出和清理仍绑在沙箱拥有的进程上。环境登记失败从不退回宿主机执行。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 开关 | `appServer.experimental.sandboxExecServer`。只对活动的 OpenClaw 沙箱 | 终端流在环境后端里。没有这道实验沙箱流开关 | 工具输出在客户端流里 |
| 中断 | Ctrl-C 同时打断交互和非交互的原生命令。关掉执行服务器连接会取消未完成的 HTTP，并等清理完再放租约 | 后台进程先给记录的父进程信号 | 取消在这一轮的执行器上 |
| 远程 | 节点上的远程执行和本地实验开关分开。认证留在 Gateway。节点在生成被钉住的二进制之前再查一次本地策略 | 远程终端是 SSH 一类后端。秘密按被服务的 profile | 工作区可以在另一台机器，权限仍是这一轮 |
| 侧问 | 普通回合可以。`/btw` 侧问失败关闭，因为它们不绑放置 | 旁问有自己的预算 | 无放置绑定的侧问 |

## OpenClaw

交互命令拿到真终端。Ctrl-C 同时打断交互和非交互的原生命令。关掉执行服务器连接会取消它未完成的 HTTP 请求，并等清理完成，再释放沙箱租约。

节点上的远程执行，无论是配对设备还是和 OpenClaw 工人回合共用的同一云 profile，都和本地实验沙箱开关分开。Codex 应用服务器和模型认证留在 Gateway。登记节点上、经过明确授权的托管执行服务器，拥有进程、文件系统、能力和不含凭据的 HTTP。Gateway 在认证、cookie、API 钥匙和其它敏感 HTTP 头到达节点之前把它们拒绝掉。带认证的 HTTP 必须在 Gateway 上跑。已有的双工节点通道承载 Codex 的 JSON-RPC 流，不启动 OpenClaw 工人子进程，也不占工人槽。Gateway 的命令允许名单仍然必需。启动需要每次尝试的一次批准，或精确准入的会话完全访问，并且节点本地策略是完全或关闭。完全访问压不过本地的拒绝、询问或允许名单、配对、托管同意、命令授权或工具策略。节点在生成被钉住的二进制之前立刻再查本地策略。过期的启动被拒绝。每次尝试拥有一个隔离的 Gateway 应用服务器客户端，远程环境登记随这次尝试退役。断开结束活动尝试和它的远程进程。重连只允许一次全新的尝试。普通 Codex 回合可以工作。`/btw` 侧问失败关闭，因为它们不绑放置。放置工作区并不圈住执行。进程和文件系统访问仍然只受节点操作系统账号约束。

分到活动远程放置的回合使用那个执行主人，包括可写沙箱检查。Gateway 仍在自己的宿主文件系统策略下准备源文件和提示附件。远程执行根仍归放置所有。本地沙箱分配留给没有远程放置的回合。

## Hermes

终端环境有本地、容器和远程后端。后台进程的清理先通知记录的父进程。没有「实验沙箱流只留有界缓冲、环境登记失败绝不退回宿主、敏感 HTTP 头在到节点前被拒绝」这一页。远程孩子的环境按被服务的 profile 组装。

## Claude Code

沙箱是权限和可选的工作区隔离。工具输出随这一轮流式回来。没有配对节点上的托管执行服务器，也没有「断开结束这次尝试、重连只能全新再来」的放置合同。
