# 原生许可

Codex 的 `PermissionRequest` 上，OpenClaw 只在策略做了决定时返回明确的允许或拒绝。没有决定不是允许。Codex 把它当成没有钩子决定，落到自己的守卫或用户批准。Codex app-server 的批准模式默认省掉这道原生钩子，除非 `permission_request` 明确列在 `nativeHookRelay.events` 里，或兼容运行时把它装上。

## 对照

| | OpenClaw 管 Codex | Hermes | Claude Code |
|---|---|---|---|
| 没决定 | 不是允许。Codex 继续自己的守卫 | 没有批准界面则那一次不执行 | 询问停住等人 |
| 总是允许 | 记住的是提供商、会话、工具输入和工作目录的精确指纹。改了任何一项都是新的批准 | 会话里的允许不跨成另一条命令 | 可以记住这一次 |
| 表单 | 最多 12 个字段，每批最多 3 个，每个字段最多 4 个选项。超出是拒绝，不是截断 | 澄清是服务器问客户端 | 无这道诱发 |
| 链接 | 字面展示。不抓取、不打开。不带凭据 | 访客内容不自己打开系统浏览器 | 客户端 |

## OpenClaw

操作者对 Codex 原生许可选了总是允许时，OpenClaw 在有界的会话窗口里记住那份精确指纹：提供商、会话、工具输入、工作目录。故意只做精确匹配。命令、参数、工具载荷或工作目录变了，就是一次新的批准。

Codex 把 `_meta.codex_approval_kind` 标成 `mcp_tool_call` 时，MCP 工具批准的诱发走 OpenClaw 的插件批准流。插件、账户、电脑使用和 MCP 的批准分类跑在普通输入处理之前。策略拒绝或无法映射的批准模式返回明确的拒绝，绝不变成一张通用表单。

app-server 的 MCP 诱发模式支持 `form`、`openai/form` 和 `url`。标准和扩展表单最多 12 个字段。OpenClaw 把字段名规范化成 Gateway 安全的问题 id，在接受的内容里保留原名，并按顺序每批最多三个字段展示。每个字段最多四个选项。字段或选项超过上限就拒绝，不截断。支持的字段是自由字符串、字符串枚举或 `oneOf`、布尔、数字和整数，以及多选字符串数组。自由字符串最长 4096 个字符。长度、邮箱、URI、日期和日期时间约束，以及数字或数组的界，在返回已接受的响应之前校验。可选、必填和合法默认值保持模式里的含义。

没有字段的表单展示原来的请求消息，选项是允许和拒绝。只有明确的允许之后，才返回空的内容对象。拒绝或取消从不确认请求。迟来的回答不能确认回合已经结束的请求。

`openai/form` 还支持一个单选的 `openai/imagePicker`，最多四个有界的项 id 和标题。OpenClaw 只用这些 id 和标题。不抓取、不渲染项的图片。未知的扩展字段类型产生一条可见的操作者消息和明确的拒绝。这是 `openai/form` 能力合同的一部分。

URL 诱发以字面文本展示，选项是继续和拒绝。OpenClaw 不抓取、不打开这个 URL。URL 最长 2048 个字符，必须是 HTTP 或 HTTPS，不能包含凭据，不能含有控制字符或不可见字符。非法 URL 给出可见说明和明确拒绝。

Codex 的 `request_user_input` 和普通 MCP 诱发共用每一轮的一个交互队列。控制界面渲染每一个非秘密的 Gateway 问题。频道支持按钮时，单个选项用带类型的频道按钮。按钮、控制界面的回答，以及队列里下一条纯文本回复，解析的是同一个 app-server 请求。`serverRequest/resolved` 用外层的字符串或整数 JSON-RPC id 选定请求。尝试中止、超时和清理取消当前主人。迟来的回答不能解析已经被替换的队列项。

## Hermes

批准在工具执行前。自由文本的「是」不授权。没有「没决定就交给另一套守卫、总是允许只认精确指纹、表单超限拒绝而不是截断」这一页原生诱发。澄清、秘密和批准是服务器向客户端的请求，客户端要声明自己会回答。

## Claude Code

`canUseTool` 给出允许、询问或拒绝。没有把 Codex 的诱发收成最多十二个字段、并且不打开 URL 的这道门。
