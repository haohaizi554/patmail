# 文稿

`pdf` 一次分析一份或多份 PDF，返回文本。Anthropic 和 Google 走原生文档输入。其它提供商走文本或图像抽取。最多十份。没有单独的 PDF 钥匙，用选中模型的提供商凭据。解析不到可用模型时，在打开文件之前失败。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 原生 | Anthropic、Google 的文档输入 | 读文件和视觉分析。没有这页上的 `pdfModel` 五级顺序 | 客户端读文件或视觉 |
| 抽取 | 其它提供商。页码过滤和密码只在这条回退里 | 视觉嵌入有体积和重复次数预算 | 工具结果进字符预算 |
| 上限 | 合并去重后最多 10 份。默认单份 10 MB。选出的页默认最多 20 | 无这份页数合同 | 工具结果预算 |
| 失败 | `No PDF model configured.` 在打开 PDF 之前 | 工具错误回到模型 | 工具结果里的错误 |

## OpenClaw

工具可以在自动模型选择完成前就注册。真正执行时按这个顺序找模型：

1. `agents.defaults.pdfModel` 的显式主模型和备用。
2. `agents.defaults.imageModel` 的显式主模型和备用。
3. 默认模型的提供商里、支持原生 PDF 的视觉模型（Anthropic、Google）。
4. 有可用认证的自动候选：先原生 PDF 提供商，再能做图像或视觉、或声明了 PDF 文本抽取的提供商。默认提供商声明的文本抽取模型优先于泛泛的图像候选。
5. 更早的候选都没有时，用活动会话模型，条件是它支持图像、提供商有可用认证、并且该提供商没有关掉 PDF 图像抽取。包括没单独配 `pdfModel` 或 `imageModel` 的、有视觉能力的 OpenRouter 模型。

自动候选在选择前检查认证。显式的 PDF 或图像设置保持配置的优先序，在执行时认证。延后解析找不到可用模型，调用以「没有配置 PDF 模型」失败，此时还没打开 PDF。

`pdf` 和 `pdfs` 合并、去重，至少要有一份。`pages` 是从 1 数的页码，去重后排序，例如 `1-5` 或 `1,3,7-9`。原生提供商模式不支持页码过滤。`pdfMaxPages` 默认 20，限制的是选出的页数，不是页码数字。选择被截短时，PDF 模型和调用方模型都收到一份部分文档的说明。密码用于加密 PDF，对这次请求里的每一份都适用，只在抽取回退里使用。单份大小默认 `pdfMaxMb`，没设则是 10 MB。可选的 `model` 是 `provider/model`。

引用可以是本地路径（包括 `~`）、`file://`、`http://` 和 `https://`。分析用的是选中模型已配置的提供商凭据或已连接账号。

## Hermes

文档路径走读文件。图像和截图走视觉分析，嵌入进工具结果，受体积和每张图的重复次数预算。没有「先找 pdf 模型、找不到就在打开文件前失败」这一级，也没有「页码只在抽取回退有效、密码不进原生模式」。

## Claude Code

读文件和视觉是客户端工具。结果进这一轮的字符预算。没有 Gateway 上的原生 PDF 提供商阶梯。
