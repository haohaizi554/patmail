# 通告

子代理的结果交给请求者。投递不要求孩子再生成一份单独的通告。`expectsCompletionMessage: false` 的运行整段跳过完成投递，登记簿把这次投记成不需要。孩子必须交回有意义的结果或具体的阻碍。精确的 `NO_REPLY` 或没有输出，不能满足缺失的孩子结果，并触发正常的缺答案恢复。留下了完成记录但没有可见结果时，交给请求者的是 `(no output)`，多份孩子结果收在一起时也一样。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 谁说话 | 请求者收到结果。孩子不再写一份通告 | 父代理读摘要。叶子不把完成再委派 | 子代理工具把摘要交回 |
| 重复 | 用记下的完成和来源消息投递事实压掉。不用沉默令牌做去重 | 完成队列按委托 id | 侧链 JSONL |
| 嵌套 | 顶层用后续 agent 调用并对外投递。嵌套请求者只做内部注入 | 编排者可以再委派。深度有上限 | 子代理默认不递归 |
| 私有 | `completionTarget: "parent"` 不自动发到频道。父会话在恢复前被重置，结果丢掉且什么都不发 | 结果进父回合 | 摘要进父工具结果 |

## OpenClaw

顶层请求者会话用后续的 `agent` 调用，对外投递。嵌套的请求者子代理会话收到内部后续注入，不对外投递，让编排者在会话里综合孩子结果。嵌套请求者会话已经不在时，若有，退回那个会话的请求者。

顶层的完成模式直接投递，先解析绑定的对话或线程路线和钩子覆盖，再用请求者会话里存的路线补齐缺的频道目标字段。这样完成仍落在正确的聊天或话题上，即使完成来源只标明了频道。覆盖选了另一个聊天或话题时，不继承上一条路线的线程。绑定或钩子给出的显式线程保留。

孩子完成的聚合，在构造嵌套完成发现时，范围是当前请求者这一轮。先前一轮的孩子输出不漏进这次通告。通告回复在频道适配器有线程或话题时保留它。

`sessions_yield` 之后，冻结的这一批等自己的孩子和后代落定。更早一轮里仍在跑的孩子，不拖延这一批的结果。更早的那批保留自己的完成唤醒。

完成输入在压缩和运行时上下文消息之间保留自己的回合身份。转录持久化若因为键入的输入属于已关闭的回合而拒绝这次完成，投递记下永久失败和错误。它不改试别的模型，也不继续调度同一次完成。

私聊文本回退里，前面的块已经发出去，后面一块失败或中止，OpenClaw 记下不完整投递。它停止自动重试，避免把收件人已经收到的块再发一遍。成功的孩子结果仍可供恢复。

`sessions_spawn` 上 `completionTarget: "parent"` 把结果放回原请求者会话的私有回合。父审结果，继续没做完的工作，把审过的结局写在内部的最终回复里。OpenClaw 不自动把孩子结果、父的最终回复或生成的媒体发到频道。父仍可以用它被允许的工具自己发。

父在等私有孩子时调用了 `sessions_yield`，交接把对话交还它。孩子落定后父恢复，并按它平时的回复规则回答原来的对话。自动回复时最终文字投递。`visibleReplies` 是 `message_tool` 时必须用 `message` 工具发送，普通最终文字留在内部。孩子结果保持内部输入。不替孩子自动发送。恢复的回合绑在生出这些孩子的父会话上。那条会话在父恢复之前被重置或替换，例如 `/new`，结果丢掉，什么都不发。

这个选项只支持隐藏的、原生的、一次性运行。

## Hermes

后台委托的完成进队列。父读摘要。独立完成可以把一批拆开。没有「通告不让孩子再生成一份、精确 NO_REPLY 触发缺答案恢复、父会话重置则丢掉私有结果」这一页。停止会扇出到活动孩子。后台单元在分发时脱离，停止面还要打断会话上的异步委托。

## Claude Code

子代理工具把摘要交回父工具结果。侧链有自己的 JSONL。没有完成目标设成父会话、且父被重置就丢弃且不发送这一条。
