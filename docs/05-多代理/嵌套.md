# 嵌套

子代理默认可以递归委派到深度 5。深度 0 是主会话，总能再生。深度 1 到 4 默认是编排者。深度 5 是叶子，不能再委派。每个 agent 会话同时最多 5 个活动孩子。`maxConcurrent` 默认 8，限制的是这一层正在执行的孩子。每个嵌套编排者有自己的执行预算。它的孩子不占用根会话的槽。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 深度 | 默认 5，范围 1 到 5。到顶的是叶子 | 默认深度 2。叶子去掉再委派 | 子代理默认不递归 |
| 通告 | 只看见直接孩子的通告。一层一层向上综合 | 父读摘要。独立完成可以拆开 | 摘要进父工具结果 |
| 认证 | 按 agent id，不按会话类型。共享 profile 始终是回退。没有开关把 agent 和共享库隔开 | 孩子用被服务 profile 的环境 | 客户端的登录 |
| 记忆听众 | 宿主铸造根听众。提供者不得自己顺着会话谱系走 | 记忆按家目录。孩子不因此读到别的家 | 无这道听众 |

## OpenClaw

结果一层一层回去。后代完成后通告直接父母。父母综合自己的孩子，再向上通告。主 agent 收到最终通告，再交给用户。每一层只看见直接孩子的通告。

孩子工作启动一次，然后等完成事件。不要用 `sessions_list`、历史、子代理列表或 `exec` 里的睡眠去轮询。列表把孩子关系收在活的工作上。活着的孩子保持附着。结束的孩子在短的最近窗口里仍可见。过了新鲜窗口的、只在存储里的孩子链接被忽略。这样重启之后，旧的 `spawnedBy` 元数据不会把幽灵孩子复活。完成事件若在你已经发出最终答案之后到达，审它并继续没做完的工作。不要重复已经交付的更新。内部编排仍要有意义的结果。沉默令牌不能把孩子任务结算掉。

孩子在生成时抓住请求者当时有效的发送者策略。没有发送者的孩子运行，以及已认证的操作者恢复，即使后来 `toolsBySender` 变了，仍保留那份快照。当前的全局、agent、提供商、沙箱和子代理限制仍适用。新的、打到这个孩子的外部频道回合，重新解析当前的发送者策略。角色和控制范围在生成时写入会话元数据，供出处用。当前的深度政策是权威的。配置的上限一变，已有会话会得到或失去递归编排工具。

编排者在上限之下，有生成、子代理、列表和历史，以便生孩子并看状态。其它会话和系统工具仍拒绝。叶子没有递归编排工具。

就地的整段对话重置，取消和这条会话关联的、未完成的原生子代理，包括已交出的孩子，以及完成请求者和控制者不同的孩子。聊天 `/reset` 和 `sessions.reset` 用同一个清理主人。孩子取消不完整时，重置在清对话之前报告失败。去看剩下的任务再重试。孩子转录和无关会话保留。

显式取消编排者，会级联到它的后代树。主聊天里的 `/stop` 作用于那个请求者的孩子树。

子代理认证按 agent id，不按会话类型。会话键是 `agent:<agentId>:subagent:<uuid>`。本地认证覆盖从那个 agent 的 `agentDir` 加载。共享认证 profile 作为回退并入。冲突时 agent 的 profile 压过共享的。合并是加性的。共享 profile 始终可作回退。没有设置能把一个 agent 的认证和共享库隔开。

`sessions_spawn`，包括 ACP 运行时，以及实时语音咨询，记下直接父母键、精确的父母会话 id、父母生命周期修订，以及这次生成调用的受信任主人状态。这些是宿主拥有的事实，不是工具参数，也不是 `sessions.patch` 的字段。主人旗标从不从孩子的合成启动权威推断。语音咨询只从调用者的入站认证取它。缺失或假的主人状态不授予主人访问。

记忆访问上，OpenClaw 对每一跳父母核对当前的父母化身和生命周期，包括同一 id 的重置。然后把宿主铸造的根听众交给记忆提供者和插件工具。提供者必须消费这份准备好的听众，不得自己走会话谱系，也不得从会话查找推断记忆权威。

孩子重置保留记下的父母授予，所以新解析的听众仍可以从同一个根继承。记下的任一父母被重置或移除，会使已经抓住的听众失效。下一次受保护的提供者或工具操作，会在听众时效检查上失败。没有完整谱系戳的旧孩子得不到继承的记忆听众。它们的回合没有私人或对话记忆。Gateway 日志警告这条会话早于记忆谱系回执，必须从父母重新生成。父母缺少生命周期修订的孩子，要在父母下一次重置之后重新生成。那次重置建立起当前的生命周期修订。

这道合同覆盖 OpenClaw 创建的孩子会话。原生运行时的孩子线程还要它们的运行时工具桥提供一次活的、已授权的调用。

## Hermes

委派深度默认 2。叶子去掉 `delegate_task`。编排者保留它，并受深度上限。后台单元在分发时脱离。停止要另外打断会话上的异步委托。没有「默认深度 5、共享认证无法隔开、记忆听众由宿主铸造且提供者不得自己走谱系、重置在孩子取消不完整时先失败」这一页。

## Claude Code

子代理工具把摘要交回。侧链有自己的 JSONL。没有一层一层的通告链，也没有「沉默令牌不能结算孩子」。
