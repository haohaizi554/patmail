# 子停

每个生成会话有自己的进程内队列。默认同时 8 个普通孩子。独立会话的预算互不占用。嵌套编排者的孩子用编排者自己的预算，不用父母的。预算属于孩子的直接生成或控制会话。把完成改投到别处，不把执行搬到另一个会话的预算上。超过执行上限的已接受运行排队，直到有槽。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 重启之后 | 被打断的子代理走正常完成路径，不自动重新启动。父决定还剩什么 | 后台委托是进程本地的。重启不续 | 侧链 JSONL 还在，不自动重跑 |
| 活性 | 没有 `endedAt` 不是还活着的永久证明。另一进程里，只有持久化元数据建立不了所有权 | pid 加启动时间 | 进程在就在 |
| 积压 | 投递积压到 25 警告。计数不变不重复警告。积压不丢结果、不改保留 | 已就绪的完成并进一轮 | 无 |
| 复用 | 复用孩子恢复对话上下文。不重放被打断的命令 | 新的委托是新的孩子 | resume 读侧链 |

## OpenClaw

Swarm 收集者走专用车道，上限是组的 `maxConcurrent`，默认 32，和父母的普通子代理车道无关。普通生成在 Swarm 车道满的时候仍可以开始。收集者生出的普通孩子用收集者自己的会话车道。每个在跑的收集者占一条模型流和一个代码模式工人隔离。调 Swarm 上限时按 Gateway 的资源。提高执行并发不提高每会话活动孩子上限，默认 5。收集者的准入用组的孩子上限，默认 50，以及组的总数上限，默认 200。提高执行并发也不提高这两道。Codex 原生子代理用 Codex 自己的调度和上限，独立于这些 OpenClaw 队列。

挂起的完成投递不挡住新工作。原生子代理、ACP 会话和可见会话保留自己的活动运行上限和授权检查，与投递积压无关。积压到 25 时警告。同一 Gateway 进程里，计数没变就不在每次清扫重复警告。计数在 25 或以上发生变化，或恢复之后又回到这道门槛，才再警告。积压大小不丢弃结果，也不改保留。

OpenClaw 不把缺少 `endedAt` 当成子代理仍活着的永久证明。读的进程若能核实当前的执行主人，或精确的排队收集者保留，未结束的运行无论年龄都继续计数。另一进程里，只有持久化元数据建立不了那份所有权。其它未结束的运行，过了陈旧窗口就不再算活动或待定。窗口是 2 小时，或配置的运行超时加一小段宽限，取更长的。这些保留的计数管列表、状态摘要、后代完成门和每会话并发检查。它们不是执行者仍活着的证明。

优雅重启或 Gateway 挂起期间，已经准入的运行的生命周期事件仍经重启保留和完成处理跟踪。已经准入的替代运行可以在关机前刷新一份推迟的孩子结果。刷新一直跟踪到捕获和持久化结束。它不准入新的运行。

Gateway 重启之后，父拥有用户任务的延续。被打断的子代理经正常完成路径收尾，不自动重新启动。结果告诉父：执行被打断了，部分完成的动作要核对。等着孩子批的父收到已落定的结果，包括重启前就完成的孩子，并决定还剩什么工作。

已经准入的、交给嵌套请求者的完成回合，和孤儿孩子启动不同。它冻结的孩子结果批在重启之后保留精确保存的延续。登记簿恢复等那个主人，而不是在同一延续正在重放时报告打断。这不授权自动重开无关的、被打断的孩子工作。

恢复在还原剩余认领之前，退役被取代的请求者转移代。当前代保持完成保管。过时的转移不无限重试。瞬时的持久化失败仍重试。

恢复既处理标了 `abortedLastRun` 的会话，也处理硬杀、来不及写下关机标记的情况。硬杀时，孩子会话仍必须认出退役 Gateway 上的那一次精确运行，并且没有更新的运行或已准入的工作拥有那条会话。活的执行和排队的收集者保持已有主人。孤儿运行在清理前结算原生执行状态，这样留下的孩子会话不留下幻影的正在跑。结算失败时，完成仍可重试。

恢复记住活会话的所有权，不保留保存的提示快照。没变的、已拥有的行跳过会话读取。所有权释放或已发布的会话变更，在一秒内再请求一次清扫。读不到的恢复按行重试，指数退避从一秒到一分钟。登记簿生命周期变化和会话发布清掉那个退避。没有活主人的持久化行，在恢复能改它们的状态之前仍要一次新的读取。

启动时的会话维护用一条信息摘要报告留下的运行或任务主人。那些行仍归登记簿恢复。只修会话的孤儿修复不和它们争所有权。修复期间的所有权变化和失败的所有权检查仍产生警告。

父可以查看留下的孩子转录，用 `sessions_send` 继续那条会话，或在确认旧执行已停之后生一个替代。复用孩子恢复它的对话上下文。它不重放被打断的命令。已有的清理和保留设置仍适用。

脱离的清理尝试若记下收尾失败，重试在当前 Gateway 进程里用有界退避。重试用尽，运行仍记下清理不完整。看警告认出失败的操作。无关的子代理完成不重启失败的清理，也不重置它的重试预算。

## Hermes

停止扇出到活动孩子。后台单元在分发时脱离，所以每个停止面还要打断会话上的异步委托。深度大于 0 的委派总是同步的，停止会递归。没有「重启不自动重开子代理、投递改道不搬预算、积压 25 不丢结果、没有结束时间不是还活着」这一页。

## Claude Code

子代理在侧链。中断停掉那一次。没有 Gateway 重启之后把孩子收成「被打断、请父核对部分动作」而不自动重开的登记簿。
