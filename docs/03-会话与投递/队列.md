# 队列

入站的自动回复经进程内的车道队列串行，避免多次 agent 运行撞在同一份会话状态上。会话之间仍可以安全并行。CLI、嵌入运行和 Codex 共用同一条会话键车道。每一轮先在那里等待，再取得会话的执行认领。换运行时也不能另开一轮竞争的回合。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 车道 | 未配置的车道默认并发 1。主车道是 `max(8, CPU 并行度 × 4)`。普通子代理每个发起会话默认 8。Swarm 收集者每组默认 32 | 委派并发和看板工人池分开计 | 这一轮的工具执行器 |
| 默认模式 | `steer`。内置 500 毫秒防抖。帽 20。丢弃默认摘要最老的 | 忙碌时排队。`/steer` 是工具结果后的用户行 | 中途输入等这一轮 |
| 丢弃 | `summarize` 留紧凑摘要。`old` 直接丢最老的。`new` 在已满时拒绝最新的。低于 1 的帽被忽略 | 队列有自己的上限和中断 | 无这三档丢弃 |
| 权限 | 排队或交给孩子时保留已认证的操作者和原来的范围天花板。不借用活动发送者或最新发送者的权限 | 停手和批准按会话 | 权限在这一轮求值 |

## OpenClaw

入站会话运行接着进入全局 `main` 车道，并行由 `agents.defaults.maxConcurrent` 帽住。普通子代理用发起或控制会话自己的预算。Swarm 收集者孩子用组自己的预算。嵌入尝试的准备在 16 次阶段开始之后，或每片至少 8 毫秒的同步派发工作之后，让给事件循环。正在跑的阶段不被抢占。异步的阶段工作可以重叠，并且不计入那段时间预算。这不降低运行并发上限，也不改变会话串行。详细日志开着时，排队的运行若等了大约超过 2 秒才开始，会发一条短通知。渠道支持时，打字指示在入队时就发出，不等轮到它。

没设置时，入站渠道用转向、500 毫秒防抖、帽 20、丢弃方式摘要。同一轮转向是默认。回合中途到达的提示，在运行能接受转向时注入活动运行时，不再开第二次会话运行。活动运行不能接受转向时，等它结束再启动这条提示。

跟随不转向，把每条消息排到当前运行结束之后的后一轮。收集不转向，在安静窗口之后把排队的消息收成一次跟随回合。消息指向不同渠道或线程时，逐条排干，以保住路由。中断中止该会话的活动运行，然后跑最新的消息。

Gateway 输入在排队或委派给孩子时，保留已认证的操作者和原来的范围天花板。收集消息或转向活动运行，要求兼容的操作者来源和工具权限。其它输入按先进先出等着，不借用活动发送者或最新发送者的权限。已接受的回合可以在请求返回或客户端断开之后继续。这不延长已被撤销的设备权威，或当前操作者角色拿掉的权限。随后的动作仍查原来的来源，包括已接受的孩子持有的工作。

按会话的 `/queue` 选项作用于排队的投递。`debounce` 也设置 Codex 在转向模式下的安静窗口，再发送成批的 `turn/steer`。裸数字是毫秒。`cap` 是每个会话最多排队的消息。低于 1 的值被忽略。`summarize` 按需要丢掉最老的条目，留下紧凑摘要，并作为合成的跟随提示注入。`old` 丢掉最老的，不留摘要。`new` 在队列已满时拒绝最新的消息。

渠道流是部分或块时，转向看起来可以像好几条短的可见回复。部分模式里，预览可能提前收尾，转向被接受后再开一条新预览。没有流时，运行时不能接受同一轮转向，就退成活动运行之后的跟随。转向不中止正在飞的工具。被跳过的 OpenClaw 工具调用收到成对的合成错误结果，转录仍然合法。最新消息应该中止当前运行时，用中断模式。

## Hermes

网关在忙碌时把普通消息放进队列，并让少数控制命令穿过两道守卫。委派的并发孩子有上限。没有「主车道按 CPU 的四倍、未配置车道默认 1、丢弃分成摘要、丢最老、拒绝最新」这一页进程内车道。`/steer` 作为工具结果之后的用户行进入，不涂进已经落盘的工具结果。

## Claude Code

工具可以在正文还没结束时开始。中途的用户输入等这一轮的工具边界。没有跨会话的主车道帽，也没有按会话 20 条、默认把最老的收成摘要的队列。
