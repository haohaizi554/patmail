# 斜杠

以 `/` 开头、单独成条的消息由 Gateway 处理。指令在模型看见之前从正文里剥掉，只动认出来的指令、它的参数和紧挨着的分隔。其余文字的空格、换行和代码缩进留着。后加的提示上下文不再扫描、也不当指令剥。未授权的发送者看到的指令就是普通文字。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 命令 | 整条消息只有命令时由 Gateway 执行 | 注册表里的命令。技能正文作为用户消息注入 | 内建的在客户端。技能变成用户消息 |
| 指令 | `/think`、`/model`、`/queue` 等先剥再给模型 | 改变系统提示的命令默认下一会话再生效 | 思考档是客户端参数 |
| 只含指令 | 写入会话并回一条确认。混在正文里的多数不持久 | 斜杠在调度表里，没有「混在句子里就不持久」这一档 | 无 |
| 例外 | 行内 `/model` 仍持久。`/exec` 的安全和询问只对这一条 | `--now` 才立刻改提示状态 | 无 |

## OpenClaw

三类：

- 命令是单独的 `/...`，必须是这条消息的全部内容。
- 指令包括 `/think`、`/fast`、`/verbose`、`/trace`、`/reasoning`、`/elevated`、`/exec`、`/model`、`/queue`。大多数在单独发送时把设置写入会话。`/exec` 的安全和批准选项只对这一条消息，不改变以后的回合。把它们和任务写在一起。会话范围的政策用权限模式。`/exec` 的 `host` 和 `node` 仍然持久，那是放置。
- 行内快捷如 `/help`、`/commands`、`/status`、`/whoami` 立刻执行，并在模型看见剩余文字之前剥掉。只有已授权的发送者。

只含指令的消息写入会话。普通聊天里夹着其它文字时，指令是这一次的提示，不写入会话设置。模型选择是例外：已授权的行内 `/model` 或配置的别名会持久会话选择。主人或管理员的 `-a` 和 `-g` 范围还会请求更新所选的默认。

指令只对已授权发送者生效。设了 `commands.allowFrom` 时，它是唯一使用的允许名单。否则授权来自频道允许名单、配对，以及始终开着的访问组执行。未授权时，指令当普通文字。

对话绑到 ACP 会话时，普通文本路由到 ACP 运行时。Gateway 的管理命令仍在本地：`/acp` 总是到达 OpenClaw 的命令处理。表面上的命令处理开着时，`/status` 和 `/session` 留在本地。

主机上的 bash 用 `! <命令>`，别名是 `/bash`。这不是模型看见的指令剥除，而是主机命令入口。

技能命令另登记。点名之后正文再进入，不把每份技能都放进常驻提示。

## Hermes

命令从一份注册表来。CLI、网关、补全和帮助都从它派生。改变系统提示状态的命令默认推迟到下一会话，`--now` 才立刻做。技能斜杠注入为用户消息，不改系统提示字节。没有「夹在正文里的 `/think` 先剥掉、且不持久」这一层指令语法。桌面把终端专用和消息专用的内建命令从发现里拿掉，用户启用的技能和快捷命令仍可执行。

## Claude Code

内建斜杠在客户端处理。其余落到技能或命令。技能索引常驻，正文作为用户消息。思考档不经过「未授权则当普通文字留下」的 Gateway 允许名单。
