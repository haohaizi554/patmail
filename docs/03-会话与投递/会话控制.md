# 会话控制

会话行带 `snapshotAt`，是 Gateway 的采样时间。缓存行保留原来的采样时间。客户端用它给读快照排序，包括那些不推进持久化 `updatedAt` 的、只在运行时的变化。时间相同用请求顺序打破平局。没有采样元数据的读观察仍按请求顺序对账。这个读时间不代替事件顺序或会话身份检查。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 活动 | `hasActiveRun` 是直接会话活动的权威合计。投影出的 `activeRunIds` 为空，证明空闲。合计为真而字段省略，表示另一个运行时主人在活动，但精确身份不可用 | 忙碌是网关状态。不把列表第一行当主人 | 无花名册 |
| 导入 | 同一目录再导入复用会话，只追加没见过的项。最多约 5 万项或 64 MiB。`complete: false` 表示更旧的被界省略。内容是不可信参考，没有原生延续 | 迁入有自己的计划和应用 | 打开 JSONL |
| 计数 | 主人会话计数在分页之前算完。小的 `limit` 不截断这份计数。字段省略不表示零 | 侧栏自己数可见会话 | 无 |
| 断开 | `describe` 和 `get` 绑在连接上。断开取消进一步的行准备重试。要当前结果就重连再读 | 重连再拉 | 无 |

## OpenClaw

存储准入之后，直接会话目标的授权只准备被请求的行。脏目标必须先过规范校验才授权。无关的行在后台继续校验。方法范围、profile 绑定和启动可用性在准备之后再查一次。`sessions.list` 先授权调用者的范围，行的有效性和可见性留给会话读取器。

已接受的会话变更保留已有的完成寿命。列表顺序随已提交的会话元数据增量更新。每次请求在分页前仍套用当前的可见性、活动和时间过滤。已归档会话在显示行从内存释放后，仍保留列表位置。

`hasActiveRun` 是权威的、直接会话的活动合计。投影出来时，`activeRunIds` 是完整的精确活动集合。空数组证明会话空闲。合计活动为真而字段省略，表示另一个运行时主人在活动，精确身份不可用。快照上的省略表示身份不可用。增量事件上，省略表示没变化。`null` 是只在事件里的墓碑，把缓存的精确 id 清成不可用。数组替换缓存。客户端只关联自己本地拥有的、或从请求、历史、事件收到的精确 id。从不把列表第一项选成主人。

目录导入把可读的目录转录留在一条普通 Gateway 会话里。可选显示名只给新建导入设标题，1 到 500 个字符。已有导入保持标题。没有标题时用「Imported」加目录标签。再导入同一代理的同一位置，复用会话，只追加没见过的项。保留最近的历史，上限约 50,000 项或 64 MiB，另有每项文本上限。`complete: false` 表示更旧的历史被界省略。它记下来源出处，并把内容标成不可信的参考，没有原生延续、模型锁或节点运行绑定。

`excludeDock: true` 在所有权、人员分面、计数和分页之前，省略以插件停靠面创建的对话。普通控制界面发现和工作板花名册用这个过滤。精确的会话读取和深链保持正常的访问检查。

`includeOwnerSessionCounts` 返回每个有效人类 profile 主人的未归档数和正在跑的数。计数用调用者看得见的、分页之前的匹配会话。合并的 profile 收到规范身份。正在跑只数直接的、活的 agent 回合，不含排队、只有后代的活动，以及陈旧的存储运行状态。侧栏范围的摘要不要带 agent、时间、搜索或主人过滤，并排除全局、未知、子代理、cron、系统和停靠。小的 `limit` 不截断这份计数。响应里有这个数组时，缺一个 profile 才表示零。字段整个省略并不建立计数。客户端在 `sessions.changed` 上刷新这份摘要，包括无键的可见性或 profile 失效，而不是从分页的会话行重建。

`sortBy: "activity"` 按最新活动在前，没有置顶优先。时间戳取最后完成的运行和最后一次用户或渠道输入里较晚的那个。两个都没有合法活动时间时退到 `updatedAt`，再退到 `createdAt`。缺时间戳的排最后。默认的 `updatedAt` 顺序把置顶放前面。

带了 `activeMinutes` 时，可见候选人有年龄边界就返回 `activityExpiresAt`。这个期限包括选中的人之外、以及返回页之外的候选人。边界含在内。`Date.now()` 超过它之后再读。没有年龄过滤，或没有候选人会变老时，字段不出现。它不代替会话变更的失效。

云工人放置开着或有耐久恢复状态时，行带封闭的放置状态：本地、已请求、开通中、同步、启动、活动、排水、对账、已收回或失败。本地和已请求的放置不带机器身份。Gateway 重启之后，配对设备的运行者从离线开始，直到那个运行者重连。容量清单的变化不使会话行失效。

## Hermes

会话列表是缓存。活跃会话和草稿分开。没有「空的活动 id 数组证明空闲、省略不等于零计数、导入上限 64 MiB 且标成不可信参考」这一页协议。回绕和恢复有自己的错误码。

## Claude Code

没有 Gateway 会话索引。恢复是打开转录。没有采样时间来给不推进 `updatedAt` 的运行时变化排序。
