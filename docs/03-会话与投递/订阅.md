# 订阅

客户端用一次 `sessions.subscribe` 既可以订阅，又可以装上初始花名册。参数是非空的 `sessions.list` 对象，例如限制条数并让主人在前。成功的 WebSocket 响应是 `{ subscribed: true, list }`。传空对象只确认订阅，不读快照。列表参数选择这份快照。它们不过滤这条连接上的会话事件订阅。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 一次调用 | 订阅和初始列表一起回来。空参数不读快照 | 会话列表是网关方法。重连再拉 | 无花名册订阅 |
| 紧凑行 | 省略的细节表示这次没要。不得清掉先前已经准入的细节字段 | 列表合并，不整表覆盖 | 无 |
| 时序 | Gateway 先登记订阅，再投影列表。客户端要在请求之前听 `sessions.changed` | 事件在连接上。重连换订阅 | 无 |
| 来源 | 诊断用的 `source` 不改变选择或访问 | 无这道来源标签 | 无 |

## OpenClaw

紧凑行省掉重复的、只给详情的元数据，例如上下文窗口、思考档、工具覆盖。返回的每一行带 `rowMode: "compact"`。那些省略表示细节没被请求，不得清掉先前已经准入的细节字段。细节用 `sessions.describe` 或完整的会话信息。不写 `rowMode` 就保持完整行合同。标题、预览和活动回顾仍由已有的包含旗标控制。

控制界面的列表用紧凑行，并带有界的诊断来源：侧栏、仪表盘、活动、会话页、聊天窗格、agent 花名册、命令面板或技能工坊。来源不改变选择或访问。列表和事件行带 `hasBoard`，是准备好的仪表盘成员事实，画廊可以应用行更新而不必再枚举页面。在会话页展开紧凑行时，用 `sessions.describe` 读完整细节。行还带 `childOwnerSessionKeys`，是 Gateway 的 `spawnedBy` 过滤当前保留的主人。这些回执包括运行时控制者和导航所有权，随同一个主人过期，让子窗口应用事件时不必在浏览器里重做保留规则。

Gateway 在投影列表之前登记订阅。客户端必须在发出请求之前听 `sessions.changed`。事件可以在快照还在建的时候到达。把那些事件和响应对上，需要时再补一次尾随的 `sessions.list`，包括事件只是让缓存的列表失效的时候。重连要新的订阅和新的快照。

Gateway 把耐久的会话元数据留在内存里，并在正常启动完成之前做完初始行的物化。重连的客户端在 Gateway 就绪后就能读初始花名册。已提交的主人变更增量刷新受影响的行。响应消费当前行的事实，没有陈旧窗口。按键的描述、解析和聊天启动准备它们要的那一行，不等批量刷新。新准入或被替换的存储加载一次元数据。存储离开当前拓扑时，行消失。每次响应套用当前查看者的可见性和当前活动时间。等价的查看者在投影事实改变之前共享不可变的行呈现和编码后的行字节。`snapshotAt` 保留这一行的采样时间。运行时权威、权限变化和会过期的事实在复用之前核对。

## Hermes

桌面和 TUI 用 JSON-RPC 拉会话。重连之后再要列表。没有「先登记订阅再投影、紧凑省略不得清掉已准入细节、诊断来源不改变访问」这一页 Gateway 协议。会话身份在库里。界面上的列表是那份真相的缓存。

## Claude Code

没有会话花名册的订阅。恢复是打开一份 JSONL。
