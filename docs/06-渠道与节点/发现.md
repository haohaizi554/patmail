# 发现

找 Gateway 有两件事。操作者从别处遥控。节点要发现并配对。广告只由 Gateway 发。客户端只消费。多播 Bonjour 尽力而为，不过网。TXT 记录没有认证，只当界面提示。路由用解析到的服务端点，不用 TXT 里的主机或端口。已经存下的 TLS 指纹，不能被广告里的哈希盖掉。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 谁广告 | Gateway。默认环回 `127.0.0.1:18789`。绑定可改到局域网或 tailnet | 无 mDNS 信标。桌面知道自己拉起的后端 | 无 |
| 直连 | 同一网络或 tailnet。配对令牌和 ACL 在 Gateway。不需要 shell | URL 加令牌，或本机拉起 | 本机 |
| SSH | 把环回端口转出去。除了 SSH 不新开入站 | SSH 是终端后端或远程连接的一种 | 无 |
| 信标 | `_openclaw-gw._tcp`。默认 `minimal` 不带 SSH 端口和 CLI 路径 | 无 | 无 |

## OpenClaw

直连的体验最好：局域网用 Bonjour 发现，令牌和访问控制归 Gateway，不要求 shell。SSH 是到处都能用的后备，跨无关网络，躲过多播和 mDNS 的问题。

同一信标也可以在配置的广域 DNS-SD 域里浏览，这样同一局域网的 `local.` 和跨网络的单播域都能发现。捆绑的 `bonjour` 插件启用时，Gateway 广告 WebSocket 端点。客户端列出可选的 Gateway，再套自己的连接信任政策。macOS 上选中一项是打开连接编辑器，不把广告的端点存下来。

服务类型是 `_openclaw-gw._tcp`。TXT 里非秘密的键包括角色、传输、显示名、局域网主机（只在局域网广告上，广域 DNS-SD 不写）、端口、TLS 打开时的标志和指纹、可选的 tailnet DNS。`sshPort` 和 `cliPath` 只在 `discovery.mdns.mode` 为 `full` 时出现，局域网广告和广域都如此。默认 `minimal` 省略它们，SSH 仍按 22。`off` 关掉 mDNS。

TXT 无认证。路由应优先 SRV 加上 A 或 AAAA 解析出的端点，而不是 TXT 里的 `lanHost`、`tailnetDns` 或 `gatewayPort`。TLS 钉扎绝不让广告的 `gatewayTlsSha256` 覆盖先前存下的指纹。iOS 和 Android 节点在安全或 TLS 路线上第一次存指纹之前，应要求显式的「信任这个指纹」，并做带外核对。

`openclaw plugins enable bonjour` 打开局域网多播广告。`OPENCLAW_DISABLE_BONJOUR=1` 强制关掉广告。`discovery.mdns.mode` 为 `off` 独立关掉。环境变量设成 `0` 是显式加入，用来盖过插件在检测到的容器里自动关闭。它盖不过配置里的 `off`。捆绑插件在 macOS 上默认启动，在 Docker、containerd、Kubernetes、LXC 里自动关闭。

节点配对和操作者遥控都消费这份发现。发现本身不授予范围。连上之后仍是先挑战、再 `connect`，角色和范围另算。

## Hermes

后端地址来自本机拉起、SSH、URL 加令牌，或云。没有一条无认证的 mDNS TXT 可以改路由或 TLS 指纹。远程连接的拨号用操作者给的地址。OAuth 连接每次拨号领新票。确认的 401 或 403 才重新认证。

## Claude Code

没有要发现的 Gateway。客户端和模型、工具在本机或它配置的端点上。
