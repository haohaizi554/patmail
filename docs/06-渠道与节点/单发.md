# 单发

`openclaw agent` 从命令行跑一轮，没有入站聊天消息。默认走 Gateway。`--local` 才强制当前机器上的嵌入式运行时。握手重试之后，Gateway 超时或连接关闭会让命令失败，并在标准错误里提示。CLI 从不静默改在嵌入式里把这一轮再跑一遍。Gateway 仍可能把已经接受的那一轮做完，所以要再向 Gateway 核对。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 一轮 | `--message` 或 `--message-file`，恰好一个。文件去掉可选的 UTF-8 BOM，超过 4 MiB 在分发前拒绝 | `hermes` 的单次查询走 CLI。会话仍进家目录的库 | `-p` 一类的一次提示 |
| 会话 | `--agent` 用该 agent 的主会话。也可以会话 id 或精确会话键 | 当前 profile 的会话 | 项目会话 |
| 投递 | `--deliver` 才把回复送进频道。可以改回复频道、目标和账号 | 消息网关自己投递入站的回复 | 无频道 |
| 失败 | 不静默改跑嵌入式。已接受的回合可能仍在 Gateway 上结束 | 中断和 `resume_pending` 另计 | 客户端看到错误 |

## OpenClaw

`--to` 从电话或聊天 id 推导会话键。`--session-key` 用精确键。`--session-id` 复用已有会话。`--model` 只覆盖这一次运行。`--thinking` 给选中的模型配置设思考档。`--verbose` 把详细级别写入会话。`full` 还把工具输出记进日志。超时默认 600 秒，或用配置值，可用旗标覆盖。

`--channel` 是投递频道。和 `--agent` 加 `--to` 一起时，也作用于私聊范围。回复的目标、频道和账号可以单独覆盖。

严格的、短暂的 CI 或编码自动化，要自己管准备、清理、输出投影和进程状态时，用 `openclaw agent exec`。那种运行默认丢掉临时状态，审计证据一起没。要留下证据就指定状态目录。

文件必须是合法 UTF-8。多行保留。太大在分发前拒绝，不把半份提示送进一轮。

这和迁入、重置不同。单发是跑一轮。它不导入另一套系统的家目录，也不按范围删状态。

## Hermes

单次查询进当前 profile 的 agent 循环，结果可以落会话。没有「超时之后禁止静默改到另一个嵌入式运行时再跑同一轮」这一条 CLI 合同。桌面和 TUI 走 JSON-RPC 的 `prompt.submit`。忙碌时的回绕不进队列。普通提交可以转向或排队。

## Claude Code

一次提示在客户端里跑。失败就是这次客户端的错误。没有 Gateway 可能仍在做完已接受回合、而 CLI 已经报超时的分叉。
