# 系统提示

OpenClaw 为每次 agent 运行自己组装系统提示。没有一份运行时默认提示。Hermes 按缓存层切开的装法在 [提示词](提示词.md)。组装分三层。纯渲染器从显式输入画出提示，不直接读全局配置。配置层在渲染前套上这个 agent 的旋钮：主人显示、语音提示、模型别名、记忆引用方式和子代理委派模式。运行时适配器收集活的事实，再调用配置过的门面。导出和调试看见的提示因此和活的运行对齐。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 分层 | 稳定的大块在缓存边界之上。每回合会变的段在边界之下 | 稳定、上下文、易变三层。技能索引在易变层，钉住的技能在稳定层 | 系统或开发者说明加当轮用户消息 |
| 节点 | 节点上的会话用同一份提示和引导准备。节点只提供自己的路径、宿主、系统和进程事实 | 远程执行换环境，不换系统提示字节 | 工作树不改系统提示身份 |
| 提供商 | 只能替换三个命名段，或在边界上下各注入一段。不能整份换掉 OpenClaw 拥有的提示 | 提供商插件贡献路由，不在回合中改已发送的系统字节 | 模型家族有自己的默认 |
| 委派 | 没写明时，主会话用 prefer，别处用 suggest。这只是提示。工具策略仍决定能不能生成 | 叶子和编排者是运行时角色 | 子代理工具按深度 |

## OpenClaw

节点托管的会话和 Gateway 本地会话用同一套提示和引导准备。Gateway 在会话已有的隐私和工具策略下选择说明、人格文件、技能、记忆指导和对话上下文。节点提供自己的工作区路径、宿主、操作系统、shell 和活动进程事实。把执行挪到节点上，不会把 agent 换成一份通用编码提示，也不会把没被选中的、节点本地的引导文件放进上下文。上下文引擎的选择、历史准备和回合结算仍归 Gateway。直接的回合后钩子在节点工作区结果被接受之后、放置认领释放之前运行。

提供商插件可以贡献缓存感知的指导，而不替换 OpenClaw 拥有的提示。运行时可以替换三个命名核心段之一：交互风格、工具调用风格、执行偏向。也可以在缓存边界之上注入稳定前缀，在边界之下注入动态后缀。自 v2026.4.5 起，模型家族的调优走这条提供商贡献。`before_prompt_build` 仍支持，留给兼容或真正全局的提示变更。GPT-5 家族的内置贡献是一份稳定前缀行为合同，外加可选的更友好语气。OpenAI 家族路线上，人格默认友好。`on` 是友好的别名。`off` 只拿掉友好覆盖，稳定的行为合同还在。

执行偏向要求对可行动的请求在本回合里做，做到完或被挡住，从弱的工具结果里恢复，现场核对会变的状态，收尾前验证。请求的动作若有可用工具，就算被授权。工具策略、沙箱和执行批准在运行时闸风险。提示不要求模型事先拒绝、警告或另求许可。

答应未来、后台、委派或延续的工作，就产生跟进所有权。结束回合前要安排一条可用的完成或监视路径，主动带回结果或具体的阻塞。把 `running` 这种进度当成完成是不行的。

运行时上下文是给所有提供商的稳定指导，紧接在 Care 之后、缓存边界之上。OpenClaw 可以另附一条带类型的运行时上下文消息，给当前请求。里面是活动执行会话、活动子代理和媒体生成进度的紧凑事实，以及 Windows 上 `exec` 可用时的建议性已批准可执行文件提示。提供商按自己协议支持的最强权威投影这条消息。前缀绑定的重放可以留一条带标签的兼容消息。用它，不要回复或描述它，内部细节保持私有，也不要等另一条消息。

大块稳定内容，包括项目上下文和静态的记忆召回说明，留在内部提示缓存边界之上。每回合会变的段附在边界之下，让带前缀缓存的本地后端能在渠道回合之间复用稳定的工作区前缀。这些易变段包括界面呈现、控制界面嵌入指导、消息、可折叠细节、语音、群聊上下文、反应、运行时、项目记忆事实、渠道专属的 ACP 提示、委派或编排模式，以及当前的提权级别。执行、子代理和媒体事实走更后面的运行时上下文载体，好保住对话历史前缀。它们按能力写的说明仍留在系统提示里。边界是内部传输元数据。对 CLI 后端，每一段仍是系统提示指导。工具描述在已接受的模式已经带上运行时细节时，应避免再嵌当前渠道名。

媒体任务事实只包括已启用的媒体工具，以及属于当前请求者的任务。恢复的、没有记录请求者的任务用配置的会话主人。已完成的任务省略。

长时间工作的指导写在工具说明里。未来的跟进用 cron，不用 `exec` 睡眠循环、延迟花招或反复轮询进程。`exec` 和 `process` 只给现在就开始、并在后台继续的命令。自动完成唤醒开着时，命令启动一次，靠推送的唤醒路径。更大的任务优先 `sessions_spawn`，并遵守它接受的完成模式。孩子完成是那次运行的结束，不是被委派的用户目标已经完成的证明。不要为了等完成而循环轮询子代理列表或会话列表。

`delegationMode` 没写明时，每个 agent 的主会话用 `prefer`，别处用 `suggest`。显式的默认或单个 agent 的覆盖始终赢。`prefer` 加一节委派，让 agent 保持可响应，内部杂活用隐藏子代理，用户会跟着看或会回来的工作用可见的侧栏会话。这只是提示。工具策略仍决定 `sessions_spawn` 是否可用。思考档是 ultra 且生成可用时，再加一节主动的子代理编排：独立的调查、实现和验证并行，简单或紧耦合的工作留在本地，每个子代理给有界目标，回复前综合结果。

本地日期和时区在缓存边界之下。精确时间在 `session_status` 可用时从那里来。Git 共同作者尾注只在共享会话有人可署名时出现在运行时那一行。

## Hermes

系统提示按稳定、上下文、易变组装。身份、指导和钉住的自动加载技能在稳定层。技能索引在易变层开头。日期行在当天内字节稳定。换表面是一条一次性的用户消息说明，系统字节不动。提供商不能在回合中替换三个命名段。节点或远程执行不另备一套「同一提示、节点只补路径和系统事实」的组装。

## Claude Code

系统或开发者说明在会话开始时定下。技能索引常驻，正文作为用户消息注入。没有「缓存边界之上放项目上下文、之下放群聊和反应、运行时上下文另附一条不要求回复的消息」这一页 OpenClaw 组装。
