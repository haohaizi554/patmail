# 检索

会话搜索查的是过去可见会话里的用户和助手正文，返回会话钥匙、时间和一小段摘录。要用返回的钥匙、消息 id 和会话 id 一起再打开历史。没有消息 id 时，历史给的是当前这一段重置之后的最新尾巴。摘录在回到模型之前打红。隐身会话不进结果。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 工具 | `sessions_search`，再用 `sessions_history` | `session_search`。库坏了 FTS 拆掉后改 `LIKE` | 在项目 JSONL 里找 |
| 可见性 | 默认 `all`。未沙箱的调用方可以搜这台 Gateway 上别的 agent，包括别人的对话 | 搜的是这个家目录的会话 | 本机项目 |
| 重置 | 明确的消息 id 若在当前视图外的保留路径上，打开原来的闭合区间，不混入重置之后的新轮 | 压缩把旧行标成不活跃。查活历史看活跃行 | resume 依赖转录还在 |
| 锚点 | 带锚点时不要再给偏移。找不到的消息返回空历史，不退回最新尾巴 | 无这套重置区间 | 无 |

## OpenClaw

每条结果有 `sessionKey`、时间、角色和短摘录。把返回的 `sessionKey`、`messageId` 和 `sessionId` 一起交给 `sessions_history`，才能打开匹配的上下文，包括重置之前保留的历史。不带 `messageId`，历史返回最新的、相对重置的尾巴。明确的消息 id 若仍在当前视图里，包括重置后仍留着的重置前行，保持当前视图，可以包含重置之后的更晚回合。明确的消息 id 若指向当前视图之外、仍保留的活跃路径，打开原来那个闭合区间，不把后来的重置后回合混进去。

带锚的读取用 `limit` 限制周围消息。用锚点时省略 `offset`。SQLite 转录里，缺失或不在路径上的消息返回空历史，而不是最新尾巴。不属于所选会话钥匙的 `sessionId` 被拒绝。本地嵌入模式、没有运行中的 Gateway 时，这些规则同样适用。

搜索和 `sessions_history` 用同一套可见性。默认 `tools.sessions.visibility` 是 `all`，允许未沙箱的调用方搜索这台 Gateway 上跨 agent 的会话，包括其他用户的对话。跨 agent 默认开着，由 `tools.agentToAgent` 管。设成关闭则挡住普通的跨 agent。`allow` 限制 agent 对。请求者拥有的原生子代理和 ACP 子会话在 `tree` 或 `all` 下仍可到达。需要更窄时显式设 `agent`、`tree` 或 `self`。按对端拆开的私聊分开了对话上下文，但不限制会话工具的可见性。

调用方有效范围之外的结果在施加条数限制之前就去掉。沙箱 agent 在开启了「所生成会话」可见性时，仍只限于它们生成的会话。隐身会话排除。把可见性从 `all` 收窄，会挡住普通的跨 agent。

摘录在返回给模型之前打红。结果还有条数和摘录长度的上限。

控制界面的命令面板和线程页把会话过滤交给 Gateway，在该范围内搜完整的、已授权的索引历史。浏览器不下载花名册来决定搜哪些转录。花名册的页大小不排除更老的匹配会话。标题搜索把标点和重复空白当成词分隔，所以带连字符的标题能被拆开的词找到。命令面板在会话或消息分组下用同一规则。标识符搜索保持字面匹配。控制界面的消息搜索把最后一个词当前缀，前面的词要完整。面向 agent 的 `sessions_search` 保持整词匹配。命令面板在你切到另一段对话之后，仍能按标题或转录找到分到自定义侧栏组的、由 agent 创建的对话。未分组的生成会话和子代理运行排除在面板之外。组不授予私人对话的访问，活动搜索也不包含隐身或已归档会话。返回的是有界的最佳匹配。匹配多于条数上限是正常的，不是索引不完整的警告。收窄查询即可。真正的索引工作和被排除的冷归档转录有分开的状态消息。冷的转录历史在会话被打开、历史被恢复之后重新可搜。搜索不自动恢复已归档历史。

全文索引放在每个 agent 的 SQLite 里，挨着转录行。新的用户和助手消息在持久化的同一事务里建索引，所以索引不落后于活对话。工具结果、推理块和图片排除。只有转录的活动分支可搜。早于索引的转录，以及活动分支被回绕的会话，由下一次搜索启动的后台对账重新索引。响应里 `indexing` 为真时，结果可以不完整，索引结束后再试。删除会话在同一事务里去掉它的索引条目。分词用 SQLite 的 Unicode 词切分，并去掉变音符号。

默认的跨用户可见是这台 Gateway 只有一个信任边界的直接后果。要把别人的对话从搜索里拿掉，收窄可见性，或把对方放到另一台 Gateway。不要指望会话钥匙会做授权。

## Hermes

`session_search` 在提示里被要求：用户提到过去的对话，或怀疑有跨会话上下文时，先搜再让人重复。索引是 `messages_fts`。FTS 损坏时拆掉同步触发器，搜索改走正文上的 `LIKE`，正文写入继续。不在失败的那次活操作上重建整库索引。

搜索看见的是这个 profile 的库。另一个 profile 的会话不在这份索引里。多路复用不会把次要家的转录搜进默认家。

压缩后的不活跃行不是当前活历史。检索若要旧代，得显式包含它们。相同内容的受保护消息不要因为两代里都出现就当成重复删掉。

## Claude Code

过去的上下文在项目 JSONL 和子代理侧链里。没有默认跨所有 agent、包括其他用户对话的搜索工具。恢复靠文件还在，以及 resume 选中的那一份。侧链可以单独打开，不会自动变成主会话。
