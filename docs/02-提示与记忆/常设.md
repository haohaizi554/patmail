# 常设

常设命令把「每周五编译报告，只在异常时升级」写进每次会话都会注入的工作区文件。钟点靠自动化任务执行。一次性的 `agent exec` 跳过引导文件，因此不受这些命令管辖。写在提示里的授权不是操作系统边界。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 放在哪 | `AGENTS.md`，或由它引用的文件。子目录里的任意文件不会自动注入 | 人格和项目上下文在会话开始时装进提示。目标是会话内的判断循环 | `CLAUDE.md` 和设置里的说明 |
| 何时跑 | 触发写成日程、事件或条件。日程靠 cron 一类自动化落地 | `/goal` 做到完。`/loop` 在会话内按钟。cron 在会话外 | 计划模式等人批准。`/loop` 在会话内 |
| 跳过 | `openclaw agent exec` 不加载工作区引导 | 子代理可跳过上下文文件 | 无对等的「跳过常设」入口 |
| 批准 | 常设里的批准门是给模型的规则。真正的执行升级仍走批准和权限模式 | 批准门看命令，不看常设散文 | `canUseTool` |

## OpenClaw

常设命令给定义好的项目永久的操作授权：范围、触发、批准门、升级规则。推荐直接写在 `AGENTS.md`，因为每次会话都会注入。更大的配置可以放在 `standing-orders.md`，再从 `AGENTS.md` 引用。工作区引导自动注入 `AGENTS.md`、`SOUL.md`、`IDENTITY.md`、`USER.md`、`BOOTSTRAP.md` 和 `MEMORY.md`。子目录里的任意文件不会仅仅因为放在工作区就被注入。

严格的、一次性的 CI 或脚本入口用 `openclaw agent exec`。它跳过工作区引导，每次运行自包含，不受常设命令管辖。

时间上的强制靠自动化任务。常设文件本身不注册 cron。文件告诉模型何时该做、何时该停、何时该问人。到点真的醒来，要有一条 cron 或别的调度。

这和长期意图不同。长期意图按事件，不按钟。常设可以写事件触发，但周五下午四点这种钟点仍要自动化去执行。

提示里的「你可以发送标准报告」不取代执行批准、沙箱和工具策略。模型被指示在异常时升级。真的升级到人，走批准卡或 `/approve`，不走自由文本。记忆刷写和权限模式继续约束它能碰的文件。

## Hermes

`AGENTS.md`、`SOUL.md` 和 `USER.md` 在提示组装里各有位置。它们是每次会话的上下文，不是一份带触发器和升级规则的项目登记表。改变它们要等下一会话，或显式 `--now`，以免打断缓存。

`/goal` 在一条会话里做到判断认为完成、继续或堵住。它不创建看板卡片，也不跨重启。`/loop` 在同一条会话里按钟重跑。过夜和重启之后用 cron。cron 每次触发自己的会话，不把常设散文当成权限。

技能和记忆的分工是：跨任务的做法进技能，每条会话都适用的事实进记忆。常设若写成「永远这样做」，在 Hermes 里更接近钉住的技能或记忆，而不是 OpenClaw 的项目授权块。

## Claude Code

项目的 `CLAUDE.md` 在会话开始时进入上下文。它指导模型，不注册调度，也不跳过权限。计划模式在写之前要人接受计划。`/loop` 离开会话就停止。

没有 `agent exec` 那种明确跳过引导文件的一次性入口写在这套对照里。一次不加载项目说明的运行，就是不把那些文件放进这次请求。
