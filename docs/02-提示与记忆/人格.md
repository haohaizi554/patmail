# 人格

语气、操作规矩和用户偏好是三份文件。混在一起，要么人设把安全规矩冲掉，要么规矩把说话方式写成员工手册。三家都在会话开始时注入工作区说明，并且把这份说明和「这一轮的用户消息」分开。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 语气 | `SOUL.md` | `SOUL.md` 在提示词的 stable 层 | 没有单独的人设文件注入 |
| 规矩 | `AGENTS.md` | 项目里的 `AGENTS.md`、`CLAUDE.md` 在 context 层 | 仓库里的 `CLAUDE.md`、`AGENTS.md` 在会话开始读入 |
| 用户 | `USER.md`，单独 4000 字 | `USER.md` 在 volatile 层 | 记忆预取是附件，不是用户档案文件 |
| 名字 | `IDENTITY.md` | 皮肤和提示词里的 agent 名 | 客户端品牌，不随仓库文件改循环 |

## OpenClaw

工作区是文件工具的默认目录，也是要注入的上下文。它不是 `~/.openclaw`。配置、凭据和会话库在状态目录里，不要提交进工作区仓库。工作区也不是沙箱。相对路径落在这里，绝对路径在没开沙箱时可以碰到主机别处。沙箱打开且工作区访问不是 `rw` 时，工具在 `~/.openclaw/sandboxes` 下的沙箱工作区里操作。

默认工作区是 `~/.openclaw/workspace`。命名 profile 时默认变成 `~/.openclaw-<profile>/workspace`。`OPENCLAW_WORKSPACE_DIR` 再覆盖。多 agent 花名册里，没写 `workspace` 的条目用 `<默认工作区>/<agentId>` 或 `workspace-<agentId>`。要让 `main` 留在原来的共享根上，必须显式写 `agents.entries.main.workspace`。

`openclaw setup` 会在文件缺失时种下引导文件，不覆盖已有文件。`skipBootstrap: true` 则不创建。沙箱种子只接受工作区里的普通文件，指到外面的符号链接和硬链接忽略。缺了必需的引导文件时，会话里注入一条「文件缺失」标记，然后继续。`USER.md` 和 `MEMORY.md` 缺了就省略。一般引导文件单份默认最多 20000 字，合计 60000。`USER.md` 另有 4000 字帽。

各文件分工：

| 文件 | 放什么 |
|---|---|
| `AGENTS.md` | 操作规矩、优先级、怎么用记忆。每次会话都加载。里面的 Tools 节只是环境说明，不决定工具在不在 |
| `SOUL.md` | 语气、立场、简短、幽默、边界。短而具体 |
| `USER.md` | 稳定偏好和当前项目。写成带日期的有效或已替代指示 |
| `IDENTITY.md` | 名字、气质、表情。引导仪式里写 |
| `BOOT.md` | Gateway 启动清单。只有 boot-md 钩子开着才跑。保持短 |
| `BOOTSTRAP.md` | 只给全新工作区的一次仪式。做完删掉 |
| `memory/YYYY-MM-DD.md` | 每日笔记。情节层，不在会话开始灌入 |
| `MEMORY.md` | 策划过的长期事实。只在主私聊会话加载，不进共享群 |
| `skills/` | 该工作区技能，同名时优先级最高 |

`SOUL.md` 不写生平、变更日志、安全政策或没有行为效果的氛围。员工手册式的「始终专业、提供全面协助」会把回答磨成没有立场的套话。共享频道和对外回复仍要适合那个房间。操作规矩留在 `AGENTS.md`，避免人设文件变成第二份策略。

群和共享上下文不加载 `MEMORY.md`，避免把私人长期笔记送进房间。这和记忆笔记里的策划层资格是同一道边界。

## Hermes

`SOUL.md` 在 stable 层，和身份、工具说明一起缓存。子代理设了 `skip_context_files` 时不读它，改用内置身份。这样孩子不会继承父工作区的人设文件，系统提示仍是一份稳定前缀。

项目的 `AGENTS.md`、`CLAUDE.md`、`.hermes.md`、`.cursorrules` 在 context 层，放在工作区 git 快照前面。同一项目的不同 worktree 可以共用更长的缓存前缀。`USER.md` 和 `MEMORY.md` 在 volatile 层，所以改偏好会动前缀的后部，不动身份和工具说明。

表面从桌面换到 TUI 时，已存的系统提示字节不动。当前表面的说明作为一次性用户消息送出。人设文件不因为换界面而重写。

技能索引也在 stable 层。技能教的是怎么做某件事，不是这个 agent 说话的声音。`/learn` 写的是技能，不改 `SOUL.md`。

## Claude Code

仓库根或子目录里的 `CLAUDE.md`、`AGENTS.md` 在会话开始时作为项目上下文读入，有长度帽。这是给这次编码任务的规矩，不是一份会改所有回复语气的人设。子目录提示追加在工具结果上，并有头尾截断，不改系统提示。

安装树里的 `AGENTS.md` 不当成项目上下文。工作区外的 `~/.claude/CLAUDE.md` 一类路径不能混进子目录提示。记忆预取是最多几条附件，不替代 `USER.md` 那种每次都在的用户档案。

计划模式改变的是能不能改文件，不改变人格文件。没有 OpenClaw 那种「缺了引导文件就注入缺失标记」的工作区仪式。
