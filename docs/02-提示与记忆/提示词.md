# 提示词

系统提示按缓存边界切开。OpenClaw 各段怎么组装、执行挪到节点时提示为什么不变，在 [系统提示](系统提示.md)。稳定的身份、工具纪律和项目上下文放在前面。会变的技能索引、记忆快照、时间和当前目录放在后面，或者根本不进系统提示，改走当轮的附带消息。中途改系统提示会让之后每一次请求都按全价重读前缀。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 谁组装 | 纯渲染函数，不直接读全局配置。运行时适配器收集事实 | `system_prompt.py` 三个缓存层：稳定、上下文、易变 | 客户端系统提示加设置里的附加说明 |
| 缓存边界之上 | 项目上下文、静态记忆说明、执行纪律 | 身份、工具引导、钉住的技能、编码简报。无工作区时尾部引导也在稳定层 | 工具 schema 和长系统提示尽量不动 |
| 边界之下或当轮 | 时间、群上下文、反应、运行时一行、当前提权级别 | 技能索引、记忆、用户档案、插件段、时间、运行环境 | 技能正文作为用户消息注入 |
| 中途插入 | 运行时上下文是单独的载体，不写进用户可见转录 | 换界面时把表面说明放进当轮用户消息，系统字节保持 | 斜杠技能在回合间隙展开成用户消息 |

## OpenClaw

没有一份运行时默认提示。`buildAgentSystemPrompt` 只根据显式输入渲染。`buildConfiguredAgentSystemPrompt` 再套上这个 agent 的配置旋钮，例如主人显示名、语音提示、模型别名、记忆引用方式、子代理委派模式。嵌入、CLI、导出预览和压缩各自收集活的事实，再调用这层。导出的提示和真的运行对齐。

节点上的会话用同一套提示和引导准备。Gateway 选指令、人格文件、技能、记忆和对话上下文。节点只提供自己的工作区路径、主机、系统和进程事实。把执行挪到节点上，不会换成一份通用编码提示。

提供商可以替换三个命名段落：交互风格、工具调用风格、执行偏向。也可以在缓存边界之上注入稳定前缀，在边界之下注入动态后缀。GPT 一族的贡献是一份稳定行为合同，加上可选的友好语气。关掉友好只拿掉语气，行为合同还在。

固定段落里和缓存有关的安排是：工具、执行偏向、承诺的后续工作、谨慎、运行时上下文的稳定说明，这些在边界之上。时间、界面呈现、消息、可折叠细节、语音、群聊、反应、运行时一行、项目记忆事实、当前提权级别在边界之下。执行中的命令、子代理和媒体进度不写进系统提示正文，走稍后的运行时上下文载体，这样对话历史的前缀也能复用。载体里的事实按当前请求者过滤。已完成的媒体任务省略。

执行偏向要求这一轮就做可执行的请求，弱的工具结果要补救，改完要核对。风险由工具策略、沙箱和批准在运行时拦，提示词不要求模型预先拒绝。承诺了后台或委派的工作，就必须在结束前安排完成或监视路径。进度状态不是完成。

群里的登录码和验证链接要私发给请求者，群里只留一句不含码的确认。Gateway 自己的安装不能用 `exec` 去改。给这台 Gateway 更新要走 `gateway` 的 `update.run`，而且只在用户明确要求时。

风险不写进提示散文里当边界。提示词硬化会在新会话里转义入站文本中的内部上下文分隔符，并给上下文数据加引号。存储的用户转录不改。匹配到分隔符也不会把一条消息提升成运行时上下文。这不是授权边界。

节点会话的上下文引擎、历史准备和回合结算仍归 Gateway。直接的回合后钩子在节点工作区结果被接受之后、放置声明释放之前运行。

## Hermes

代码里的三层顺序是稳定、上下文、易变，用空行接起来。稳定层是身份（`SOUL.md` 或内置身份）、帮助与工具引导、钉住自动加载的技能、编码简报。上下文层是调用方的 `system_message`、项目上下文文件，然后才是依赖工作区的 git 快照。易变层以技能索引打头，然后是记忆、`USER.md`、外部记忆块、插件段、profile 路径、时间戳，最后是运行环境。运行环境以固定标题开始、固定标记结束，避免项目正文里引用这个标题时被当成当前目录。

钉住的技能是这个 agent 的常量，放在稳定前缀。技能索引会随安装变化，放在易变带的最前，这样最长前缀缓存仍能复用身份和项目上下文。记忆快照也在易变带。文档里有一处把技能索引说成稳定层，和组装函数不一致。以组装函数为准。

同一项目的不同 git worktree 把工作区快照放在共享项目文件之后。这样到第一个依赖当前目录的行之前，前缀可以跨 worktree 复用。没有工作区快照的会话把尾部引导留在稳定层。

子代理设了 `skip_context_files` 时不加载 `SOUL.md`，用内置身份。

系统提示在对话生命期内保持字节稳定。压缩是允许重建的时候。日期行按天稳定，时区带偏移，避免每一分钟都打断缓存。表面从桌面换到 TUI 时，已存的系统字节保留，当前表面的说明作为一次性笔记走用户消息通道。

中途要注入的技能斜杠命令是用户消息。子目录 `AGENTS.md` 的提示附在工具结果上，并有长度上限。不允许为了塞一段新说明去改系统提示。改变系统提示状态的斜杠命令默认下一会话生效，`--now` 才立刻重建。

平台提示（「你在终端里，少用 Markdown」）来自内置表，插件可以提供。`Platform:` 故意不是身份字段。

## Claude Code

工具 schema 在每次请求里。技能索引大约占百分之一的上下文，正文在选中后作为用户消息注入，不写进常驻系统提示。MCP 工具列表只在两轮之间刷新，避免一轮中途改 schema 打断缓存。

计划模式和权限模式改变的是工具是否可用和用户是否被询问，不是每次都重写一整份人格。附加系统说明来自设置。项目里的 `CLAUDE.md` 一类文件在会话开始时进入上下文，和 Hermes 的项目上下文文件同一类问题：中途改文件不会自动重载进已经缓存的前缀，除非开始新会话或走压缩重建。

记忆预取若存在，是附在请求上的检索结果，不是改写系统提示的中间段。
