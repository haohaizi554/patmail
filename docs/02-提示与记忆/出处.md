# 出处

记忆块的出处类存在散文外面：`owner`、`agent`、`untrusted`、`system`。召回出来的文字不能把自己提升成更可信。分类永不默认成 `owner`。梦境在组整理提示之前丢掉 `untrusted` 和 `system`。自动摄入排除 cron、心跳和子代理。这些排除挡不住有权限的工具直接写文件。网络来源的工具结果之后，这一轮后来的每条助手消息都标成污点，记忆上分类为 `untrusted`。群和频道既不是跨对话召回的来源，也不是目的地。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 提升 | 出处门在整理之前。检索分高也不能把不可信洗成主人 | 梦境不是 Hermes 的写入者。记忆提供者按自己的规则写 | 预取不改信任等级 |
| 忘记 | `memory forget` 清可归属的条目、日记引文、索引、向量、嵌入缓存和重写备份，并挡住这些会话再被摄入 | 归档技能不是忘记会话 | 删 JSONL 是删文件 |
| 挡不住 | 后来的对话、直接写文件、别的记忆插件、原文转录、别的 agent 的库、导出和外部副本 | 同一家目录里的文件工具仍能写 | 副本在别的路径 |
| 审计 | 不存提示、正文、参数或文件名。没有一行什么都不证明。假名是关联，不是匿名 | 监控不含内容。不把成功升级成授权证明这一句写在同一账本 | 转录含内容 |

## OpenClaw

自动摄入和回填跟踪的条目，在整理之后仍带着原来的会话。合并时出处取并集。替代时重新键。模型自己不携带出处。准入政策可以把指定会话排除在梦境摄入和会话回填之外，排除是记下的、可逆的。

`memory forget` 之后，用耐久的已忘记会话记录挡住再摄入。参与者选择器选的是涉及这个参与者的整个会话，不只是他们的消息。直接编辑、未跟踪的记忆和改写、原始转录、其它 agent 的存储、导出和外部副本要另外审。准入和忘记都不是一般的擦除保证。已忘记的记录保护的是：参与这条路径的摄入、回填和索引，不会从那个 agent 库里的那些会话 id 把数据恢复回来。它不阻止后来的对话、直接写文件或另一个记忆插件再引入同样的信息。

软删除的向量存储可以留着可恢复的东西。已忘记会话记录不是物理或密码学擦除。

审计账本存身份、顺序、动作和结果码。查询有 30 天截止和行数上限。物理剪枝分批。决定回执用封闭词表。`enforced` 表示这道门真的管辖了那个动作。光是成功，不会被升级成授权证明。文档自己的非声称包括：没有某一行什么都不证明。假名化是关联，不是匿名化。OpenTelemetry 可以导出运行诊断，有界队列、采样、关闭和导出失败都可以丢数据。两面都不承诺无损的合规档案。

参与的频道入站队列把花完重试的事件留在可检查、可重交的死信队列。IMAP 触发走另一条钩子，没有频道死信的重交。出站有分阶段的终态。目标是每个动作要么有看得见的结果，要么有记下的、故意的未发生。

独立核对有三层。社区威胁模型映到 MITRE ATLAS。风险最高的授权和隔离路径有 TLA+ 模型。那是设计的模型，在有界状态空间里检查。文档写明这不建立「TypeScript 已被验证」。另有公开的成熟度记分卡。

## Hermes

出处若由记忆提供者保存，是那个提供者的事。内置路径没有这套「忘记会话记录挡住再摄入、但不保证磁盘上的向量消失」。审计若走监控，不含正文。成功的工具结果不是授权证明。批准记录的是人的选择。

## Claude Code

预取附件不带 `owner` 到 `untrusted` 的提升门。删掉转录文件不等于擦掉索引、缓存和别的副本。没有「没有审计行什么都不证明」这一份账本非声称，因为内容在 JSONL 里。
