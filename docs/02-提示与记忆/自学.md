# 自学

纠正和做成了的做法可以变成以后还能发现的技能。默认模式是 `auto`。前台发现自己用过的技能错了，可以在同一轮里打补丁。补丁改的是磁盘上的技能，不改写这一轮已经装进会话的那份快照。体验回顾在安静之后另开一条私人会话，消息不进前台转录。提供商或提示词错误不安排回顾。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 耐久单位 | 工坊目录里的技能 | `SKILL.md`。策展只动 `created_by: agent` 的技能 | 用户或插件放进技能目录 |
| 默认 | `auto`。也可 `propose` 或 `off` | 主循环可以写技能。策展按闲置归档，不删 | 无自动从纠正里写技能 |
| 前台修补 | 只能修这一轮真正用过的技能。授权只对一段精确原文、一次尝试 | 钉住的技能拒绝删除，仍可改文件 | 无运行时使用回执 |
| 回顾 | 至少 10 次模型迭代，安静 30 秒，且不是隐身、cron、心跳、子代理 | 策展按小时间隔，在后台看使用计数 | 无 |

## OpenClaw

技能工坊拥有 agent 学来的技能。`auto` 用普通的文件工具维护工坊目录。`propose` 把草稿留待审阅再应用。`off` 关掉自主学习。

前台若发现用过的技能错了或不完整，先读当前活的技能，再经工坊起草有针对性的补丁。整份技能放不进所选模型的读取预算时，`prepare_patch` 可以授权一段非空的、唯一的、精确的原文，并返回有界的周围上下文。下一次 `patch` 必须引用同一段。授权在一次尝试之后、或目标一变就失效。这段授权还没消耗或作废时，第二次 `prepare_patch` 被拒绝。运行时的使用回执挡住前台去修这一轮没用过的技能。

三种模式都经过提案存储、哈希绑定、安全扫描和回滚捕获。`off` 不做修补。`propose` 留待显式审阅和应用。`auto` 扫描后立即应用。即时修补改的是新会话会读到的活技能。正在跑的会话里已经加载的快照不改写。前台自己没修的，仍可以由延后的体验回顾补上。

每一次学习决定来自模型看真实证据，不是模板或模式匹配。对话和技能文件是证据，不是继续原任务或执行被回顾的步骤的许可。

体验回顾在这些条件同时成立时才开始：前台回合完成或被人打断，但不是死于提供商或提示词错误。这一轮至少用了 10 次模型迭代。运行是合格的前台对话，不是隐身、cron、心跳、记忆、溢出、钩子、子代理或回顾自己。运行时报告了解析到的提供商、模型和 `skill_workshop` 是否真的可用。系统已经安静 30 秒。没有 agent 或回复 run 还在活动。

同一会话里后来的前台完成会重新开始安静计时。除非那一轮自己也够格回顾，否则不换掉已保存的证据。待回顾的属于一个 agent 加一条会话。用 `global` 的多个 agent 各自留候选人。回顾占共享后台预算里的一个工坊槽。前台的回答不等这次回顾。

OpenClaw 记下完成回合的结尾，安静之后再异步读它的完整模型上下文。回顾者把更早的要求和纠正跟观察到的结果接起来，即使最近一轮很平常。更晚的消息排除在外。保存的回合若被改写或删除，回顾记一次失败，不用另一份证据。回顾跑在私人的、脱离的会话身份下。它的消息不进前台转录或会话记录。沙箱策略沿用前台会话的。被人打断的深回合也可以：回顾者被告知这次是打断，只留下打断前已经看得见做成了的步骤。死于提供商或提示词错误的回合不安排回顾。

`auto` 下，回顾者用源会话权限里的目录、文件、补丁和 shell。文件工具根在工坊目录。shell 仍走操作者已有的批准。沙箱若开着，必须能写那个目录。超时用这个 agent 的正常配置。新学到的东西替换误导的规则或加强已有的一条，不另贴一份副本。已经覆盖的教训不改。

`propose` 下只有 `skill_workshop` 执行。回顾者可以先看再暂存一次创建、补丁、更新或修订。草稿保持待审，即使回顾进行中操作者打开了自动学习。

每次回顾一次尝试。失败记下来，不重试。自动维护在 agent 运行成功时记 `completed`。这个状态不表示文件一定改了。已经完成的文件编辑在后来的失败或取消之后仍留着，以后的会话拿到刷新过的技能快照。源会话删除、替换或权限模式变化，会把留着的工具围起来。

值得留下的是：反复失败之后可靠的恢复，耐久的用户纠正（写成那项工作的技能步骤），能挡住反复出错的顺序约束，稳定的多步流程，能省掉以后好几次调用的预检。应放弃的是：例行的成功或一次性请求，个人事实和简单偏好，暂时的环境或服务失败，没有具体证据的泛泛建议，没有根据的否定，以及秘密和凭据。

## Hermes

策展看的是 agent 创建的技能的使用计数，闲置后归档到技能目录下的 `.archive/`，可以恢复。内置和从枢纽安装的不进自动归档的候选，除非单独的确定性闲置行走被允许归档内置。钉住的技能不做自动转换，删除也被拒绝，改文件仍然可以。

这不是「一轮用了十次迭代、安静三十秒、再开私人回顾会话」。`/learn` 和技能工具在主循环里写文件。写进系统提示的索引要等下一会话，除非显式要求立刻生效。正在跑的会话不改写已经缓存的技能前缀。

## Claude Code

技能索引常驻，正文在被调用时作为用户消息进入。没有工坊的三种模式，也没有「提供商错误不安排回顾」这条后台学习。人改 `SKILL.md` 之后，下一次加载才看到。
