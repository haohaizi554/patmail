# 更新

更新先做出一份候选，再停掉正在服务的进程，然后替换运行时。已经在跑的 Gateway 占用的文件不能就地覆盖。停之前要排干回合。写保护或迁移还在进行时，停止可以被拒绝。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 入口 | `openclaw update`，渠道有 stable、beta、dev | `hermes update`：计划、快照、应用、按种类重启、核对、报告 | 客户端自己的安装器 |
| 没变化 | 插件和运行时产物都没变则 `skipped`，原因是已经最新 | 有收据。过期的网关让更新失败退出 | 安装器比较版本 |
| 运行中 | 先构建候选，再停托管 Gateway，再替换。`--no-restart` 不能换掉正在用的文件 | 全舰队先排干。快照覆盖每一个 profile，同一套文件 | 不存在多 profile 快照 |
| 停不下来 | 写保护会拒绝停止并指出主人阶段。没有写保护观测的，到期限带警告停止 | 证明已过期的网关使这次更新失败 | 无舰队 |

## OpenClaw

显式换渠道会把安装方式对齐。`dev` 保证一份 git 检出并从这个检出装全局 CLI。`stable` 用 npm `latest`。`extended-stable` 解析并校验精确包，不退到别的选择器，git 检出拒绝它。`beta` 优先 npm 的 beta 标签，缺失或比当前 stable 旧时退到 latest。

新克隆在发布前校验。校验期间目的地或暂存目录被换掉，更新停止，不改那份替换。解析到的包版本和已装版本相同、渠道和安装方式也没变，或者 git 目标 SHA 等于 HEAD 且运行时产物校验通过，仍会做插件收敛。插件和运行时都没变，结果是跳过。同一版本但显式改了渠道或安装方式，算成功。变了的插件会重启托管 Gateway，除非 `--no-restart`。精确钉住的插件只给建议，不因此重启。

git 检出前进了但没重建，或运行时缺产物、产物未校验，仍需要更新。校验看构建提交、两份构建戳、运行时入口、控制界面资源、版本和构建身份。先在旁边构建并校验候选，再停 Gateway，再替换，再拉起。新构建记下提交，下次才能报已经最新。

`--no-restart` 不能替换同一安装里正在被 Gateway 使用的运行时文件。那些文件留下，报告进程和停止后再试的动作。停掉共享这份安装的另一个 Gateway，是为了保护它正在跑的代码，不迁移它另一份状态。那份旧状态要在它自己的账号、profile 和环境里跑更新后的 `doctor --fix`。

用 `pnpm openclaw` 启动的源码命令，在这份安装的 Gateway 还在跑时拒绝自动重建。要用已安装的 `openclaw update`，或检出里的 `node openclaw.mjs update`。手工 `pnpm build` 前要先停 Gateway。

决定在已安装的更新器里做。旧更新器若带着「运行时校验失败」返回已经最新，它不会去构建它从未构建的修复。要先用真正的服务管理器停掉 Gateway，重建，再由那个管理器启动。

Linux 上核心已经最新或指定了 `--no-restart` 时，仍会刷新过期的、由 OpenClaw 管理的 systemd 策略。这次只确认 `daemon-reload`，不停 Gateway，保留操作者的 drop-in。例如旧的 `TimeoutStopSec=30` 会变成 `330`，而操作者自己写的 `TimeoutStartSec=45` 保持不动。

生命周期主人围住准入，并报告排干进度，直到空闲或更新步骤期限。默认 30 分钟，自动更新 45 分钟。到期后剩余回合可以带警告打断。报告了写保护的，拒绝停止并指出主人阶段。没有写保护观测的居民分不清备份、迁移和普通的根任务或 cron。到期时带警告停止，并写出那些计数。缺少写保护信息从不阻止更新。

连接被拒是因为运行时文件已经不可用的 Gateway，经它的服务主人停掉，不等一个它无法服务的 RPC。

## Hermes

阶段是计划、快照、应用、按种类重启、核对、报告。每一段防的是真实的现场失败。快照覆盖每一个 profile，文件集合相同，用来在丢文件时恢复。回滚归 `--backup`。

Windows 的 ZIP 后备只在 git 本身失败时使用，拒绝脏工作树，并把需要保留的嵌套构建产物接进替换。

重启是全舰队的，并且先排干。每个单元以它运行的家目录为界。另一份安装的运行时不会被重启。

能证明已经过期的网关让更新以退出码 1 失败。每次运行在 `logs/update_receipts/` 写收据。

拉取前的解释器不运行刚拉下来的代码。交接和 serve 义务是冻结的兼容面。删掉一个名字会让正在更新的旧版本在中途起不来。

`hermes update` 不解析外部秘密源，避免慢的保险库助手被当成导入失败。

网关把代码 SHA 和版本写进 `gateway_state.json`，更新器用它核对舰队。Windows 上为了解开 venv 锁而整树 `taskkill` 是已知的缺口，替代是更新前暂停，而不是把网关重新挂到桌面后端下面。

## Claude Code

更新是客户端安装器的事。没有多 profile 的同一文件集快照，也没有「写保护拒绝停止 Gateway」。会话转录留在项目目录。换版本之后，旧 JSONL 仍可被新客户端打开，只要消息形状还认识。工具和权限的行为以新客户端为准。
