# 账本

审计账本可以通过 Gateway 协议读。`audit.activity.list` 给操作者客户端一份稳定的、最新在前的视图，内容是 agent 运行、工具动作、入站消息和终态出站消息的元数据。需要 `operator.read`。查询排除超过 30 天的记录。共享的 SQLite 账本上限 100,000 条。过期行在 Gateway 启动、每小时维护和后来的写入时删除。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 读法 | `audit.activity.list`。游标翻页，每页 1 到 500 | 日志和监控。无这道 RPC | 读 JSONL |
| 身份 | 消息身份是 `hmac-sha256:v1` 加 32 位十六进制钥匙 id 和 64 位摘要。频道发送者同样 | 假名若存在，不在这道协议里 | 会话文件里的原文 |
| 形状 | 每种事件有自己的模式。`schemaVersion` 是整数 1 | 事件信封在网关合同里生成 | 无 |
| 内容 | 仍是元数据。这道 RPC 不把正文加回去 | 监控不含提示和工具参数 | 转录含内容 |

## OpenClaw

参数可以精确过滤 agent、会话键或 run，种类是运行、工具或消息，状态是开始、成功、失败、取消、超时、挡住或未知。消息还可以按入站或出站，以及精确频道。时间界是包含的 Unix 毫秒。`limit` 从 1 到 500。`cursor` 来自上一页。结果是事件数组，可能带 `nextCursor`。

具名的 V1 结果是分开的模式：agent 运行、工具动作、入站消息、出站消息。判别字段 `eventType` 分别是 `agent_run`、`tool_action`、`inbound_message`、`outbound_message`。`kind` 和消息方向仍可用于过滤和显示。每条事件的 `schemaVersion` 是整数 1。消息身份引用必须是精确的 `hmac-sha256:v1:<32 hex key id>:<64 hex digest>`。频道发送者的 actor id 用同一格式。

每种变体都要有事件类型、模式版本、事件 id、序号、来源序号、发生时间、种类、动作、状态、行动者和打红。对话种类是私聊、群、频道或未知。入站结局是完成、跳过或失败。原因码可以是重复、回复操作进行中、回复操作中止、快速中止、插件绑定已处理。出站还可以有投递种类和失败阶段。

这道 RPC 不改变账本不存正文的合同。执行身份和消息记录默认关的那些开关仍在。`openclaw agent exec` 默认删掉临时状态目录时，账本证据一起没了，除非指定了状态目录。

## Hermes

网关事件有生成的类型合同。监控可以导出运行诊断，有界队列和失败可以丢数据。没有「最新在前、30 天、十万条、身份必须是这一版 HMAC」的审计列表 RPC。成功不是授权证明。

## Claude Code

没有这道账本 RPC。会话内容在 JSONL。要核对发生了什么，读的是转录，不是打过红的元数据页。
