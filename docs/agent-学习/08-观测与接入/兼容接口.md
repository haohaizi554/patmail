# 兼容接口

Gateway 可以在同一端口上提供一小面 OpenAI 风格的对话补全。默认关闭。打开之后，请求走和 `openclaw agent` 相同的路径，路由、权限和配置都是这台 Gateway 的。持有 Gateway 令牌或口令，等于主人的操作者凭据，不是按用户收窄的范围。只放在环回、tailnet 或私网入口。不要暴露到公网。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 端点 | 默认关。`/v1/chat/completions`、`/v1/models`、`/v1/embeddings`。`/v1/responses` 另开 | `API_SERVER_ENABLED` 加钥匙。示例绑在环回 | 无 Gateway HTTP |
| 令牌含义 | Bearer 证明共享秘密，忽略 `x-openclaw-scopes`，恢复全套操作者范围，回合按主人发送者 | 会话令牌或 API 钥匙。方法仍绑 profile | 本机 |
| 可信反代 | 有 `x-openclaw-scopes` 就尊重。缺了才用默认全套。收窄且不含 `operator.admin` 时失去主人语义 | 不把转发头变成这套范围 | 无 |
| 何时用 | 另一个操作者客户端，而不是一条有自己用户和房间的消息网络 | 桌面和仪表盘走 JSON-RPC。API 服务是另一面 | 客户端自己调模型 |

## OpenClaw

启用是 `gateway.http.endpoints.chatCompletions.enabled: true`。省略或 `false` 就是关。`POST /v1/responses` 要单独的 `gateway.http.endpoints.responses.enabled`。

认证矩阵：令牌或口令模式加 `Authorization: Bearer`，证明持有共享的 Gateway 秘密。任何 `x-openclaw-scopes` 头被忽略。恢复的默认范围是 `operator.admin`、`operator.approvals`、`operator.pairing`、`operator.read`、`operator.talk.secrets`、`operator.write`。聊天回合按主人发送者处理。

可信的、带身份的 HTTP（可信反代，或私网入口上的 `auth.mode: none`）在头存在时尊重 `x-openclaw-scopes`，没有则退回默认全套。只有调用者显式收窄并且拿掉 `operator.admin` 时，才失去主人语义。主人级控制，例如 `x-openclaw-model`，仍要 `operator.admin`。

`auth.mode: none` 不要求认证头，只用于私网入口。同一台主机上绕过反代的调用者，可以直接用 Gateway 口令。任何 `Forwarded`、`X-Forwarded-*` 或 `X-Real-IP` 会把请求留在可信反代路径上。配置了认证速率限制且失败太多时，返回 429 和 `Retry-After`。

这个端点适合「又一个操作者表面」。原生手机客户端直连远端 Gateway 时，用 WebChat 或带配对设备令牌的 Gateway 协议，让设备不必持有共享的 HTTP 令牌。外面的消息网络有自己的用户、房间、webhook 和出站时，做频道插件。

目标 agent 的策略若允许敏感工具，这个端点就能用那些工具。令牌和能改配置、能批准备份的操作者是同一级信任。

## Hermes

桌面和仪表盘的实时面是 JSON-RPC，用会话令牌。API 服务要在 `.env` 里打开并设置钥匙，示例地址是 `127.0.0.1:8642`。它不是默认开着的 OpenAI 兼容补全，也不把一枚 Bearer 解释成全套 `operator.admin`。

## Claude Code

模型调用在客户端里。没有一台 Gateway 把 `/v1/chat/completions` 映射成一次带工具的 operator 运行。
