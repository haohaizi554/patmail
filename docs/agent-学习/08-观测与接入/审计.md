# 审计

审计账本只记元数据：身份、顺序、出处、动作、状态和规范化的结果码。不存内容。消息标识只以这份安装本地的假名出现。运行和工具活动默认开着。执行身份在新装和升级上默认关，要显式打开并重启 Gateway。消息记录也默认关。已有记录可查到过期，默认 30 天。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 默认 | 运行和工具活动开。执行身份关。消息记录关 | 监控平面不含内容。轨迹另配 | 转录就是内容，在项目里 |
| 账本 | 和转录分开。假名不是原文 id 的可逆展示 | OTLP 不导出提示和工具参数 | 无这份账本 |
| 短暂运行 | `agent exec` 默认删掉临时状态，审计证据一起丢 | 批处理轨迹在人指定的目录 | 无 |
| 查询 | `openclaw audit`。按 agent、状态、会话、run、执行 | 日志和医生 | 读 JSONL |

## OpenClaw

执行身份要 `logging.audit.executionIdentity` 为真，并且 `logging.audit.enabled` 仍然开着。改完重启 Gateway。消息记录设成 `direct` 或 `all` 也要重启。过期前已有记录仍可查。

本机直接命令用和 Gateway 一样的有界写入寿命。`openclaw agent exec` 默认删除临时状态目录，所以这次隔离运行的审计证据故意一起丢掉。要留下就给 `--state-dir`，再用同一份状态目录的 Gateway 去看。

账本不替代转录，也不替代轨迹导出。轨迹含提示，要批准。指标端点是诊断数字，要 `operator.read`。审计是谁在何时跑了什么动作、怎么结束，不含正文。

`--explain` 解释一条 run 或一次执行。种类和条数可以收窄。这是命令表面。完整的数据模型、隐私、保留和覆盖缺口在审计历史那一页。

## Hermes

网关监控导出的是生命周期和健康，不含提示、消息、工具参数和结果、会话历史。铁代理的审计日志在本机，权限收紧。那是出口代理的记录，不是 OpenClaw 这种默认打开的运行活动账本，也不是默认关闭的执行身份。更新收据在日志目录里，用来核对这次更新，不是 30 天的动作账本。

## Claude Code

会话 JSONL 里有对话内容。它不是一份不含内容的活动账本。要回答「谁跑了工具」得看转录本身。
