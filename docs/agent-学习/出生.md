# 出生

新工作区的第一次真实回合才做出生，不是安装向导的一部分。它种下身份文件，让 agent 问名字和一句气质，有图像工具时给出四张头像。身份写两次：文件给 agent 读，另一条命令给渠道和界面显示。头像选完或失败之后才写身份文件，避免异步生成中途把出生结束掉。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 何时 | 引导完成之后，对该工作区的第一次真实回合，只一次 | 家目录在第一次运行时出现。没有四头像的出生仪式 | 无 |
| 种下 | `AGENTS.md`、`SOUL.md`、`IDENTITY.md`、`USER.md`、`BOOTSTRAP.md` | `SOUL.md` 可自己放。项目文件按目录发现 | `CLAUDE.md` 由人写 |
| 身份 | 文件加 `openclaw agents set-identity` | 提示稳定层读 `SOUL.md`，没有则用内置身份 | 无双重写入 |
| 失败 | 图像失败就用表情继续 | 无头像步骤 | 无 |

## OpenClaw

默认工作区是 `~/.openclaw/workspace`。第一次对着全新工作区运行时，种下上述文件。和某台机器有关的工具笔记放在 `AGENTS.md` 的工具一节，不另造一份只在子目录里、又不会被注入的文件。

出生序列很短：问你想怎么称呼它，给出一句气质，`image_generate` 可用时生成四张头像，并问要最小的推荐插件集还是最大方便。同意的身份存两次。`IDENTITY.md` 和 `SOUL.md` 是 agent 读到的自己。`openclaw agents set-identity` 是渠道和界面显示的那一份。两份都要有，避免界面上的名字和提示里的名字分叉。

四张头像排成带编号的两行两列，用配置的图像模型或可用的提供商，例如 OpenAI。选中的肖像从这张表里裁出，放进工作区的 `avatars/`，并同步进身份。身份文件在这次选择之后才保存，这样异步生成不会让出生提前结束。生成不可用或失败，出生用表情继续。

引导期间已经存下的应用推荐只读取，不重新扫描。

这些文件之后进入每次会话的引导注入，并有预算。`USER.md` 可以不存在，启动仍继续。出生种下它，是为了有一个空位，不是为了每次都强制一份偏好。

`openclaw agent exec` 跳过引导文件。出生是工作区的第一次真实回合，不是这条一次性入口。

## Hermes

第一次运行会建家目录和默认配置。秘密仍要人自己放进 `.env`。没有「问名字、生成四张头像、身份写两处」的仪式。`SOUL.md` 若放在家目录，就成为稳定层的身份。没有它，用内置身份。子代理跳过上下文文件时也不加载 `SOUL.md`。

项目文件不在出生时种下。它们从工作目录发现。一条会话只加载一种。

## Claude Code

没有工作区出生仪式。项目说明是人放进去的 `CLAUDE.md`。身份是模型的默认，加上设置里的附加说明。头像和渠道显示名不属于这棵客户端。
