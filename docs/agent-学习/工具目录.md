# 工具目录

工具一多，每轮都把全部 JSON schema 放进上下文。工具目录用三个桥接工具代替那些 schema：搜索、描述、调用。核心的常用工具仍直接可见。策略没批准的工具既不可搜，也不可调。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 默认 | 嵌入和 Copilot 在 `tools.toolSearch` 未设置时自动用结构化目录。`false` 恢复直接 schema | 选择加入。核心工具默认直接加载 | 工具定义随请求发送。MCP 在两轮之间刷新 |
| 桥 | `tool_search`、`tool_describe`、`tool_call` | 同名三个。`tool_call` 的 `calls` 是数组 | 无这层桥。技能是索引加按次正文 |
| 谁被推迟 | 目录可以含插件、MCP 和客户端工具。直接暴露的不重复进目录 | MCP 和非核心插件工具。`defer` 可点名冷的内置工具 | 大结果进 `tool-results/`，schema 仍在 |
| 和代码模式 | 代码模式优先。Codex 用自己的原生动态工具，不看这个开关 | 代码执行是内核，不是这层目录 | Bash 和工具是两套权限 |

## OpenClaw

嵌入运行和 Copilot 在没写 `tools.toolSearch` 时自动使用结构化工具搜索。这推迟 schema，已批准的能力仍在。它不打开精简模式，也不删掉可选工具。写成 `false` 恢复直接 schema。这个自动默认不改写配置文件。

代码模式一旦启用就优先于工具搜索。Codex 的原生代码模式、工具搜索和延迟动态工具是 harness 自己的面，不依赖 `tools.toolSearch`。

启用后，模型得到一份有界的、受信任的工具名和描述目录，加上搜索、描述、调用。空间紧时先缩短描述，再考虑省略名字。每个已授权的目录项仍可搜索、可调用。OpenClaw 自己的工具若参数无效，错误里带一份有界的期望签名，方便改参数而不必再查一次 schema。把技能名当成工具 id 时，错误指回那份技能的完整说明。

已经直接暴露的工具不出现在延迟目录里，但仍可搜索，以便取回完整 schema。目录可以包含合格的 OpenClaw 工具、插件工具、MCP 工具和客户端提供的工具。未受信任的 MCP 和客户端工具的名字与描述不抄进受信任目录。策略没批准的不可发现。

目录规模随当前模型的上下文窗口伸缩。

## Hermes

MCP 服务器和非核心插件工具的 schema 即使用不到，也会占掉窗口。工具搜索打开后，这些工具从模型可见的数组里拿掉，换成三个桥。

核心工作集默认直接加载：终端、读写、补丁、搜索、待办、记忆、浏览器、网页搜索和抓取、澄清、代码执行、委派，以及其余核心工具。冷的、由事件触发的内置工具可以写进 `tools.tool_search.defer`。随发行给出的名单包括电脑使用、会话搜索和部分桌面助手。显式的 `defer` 名单替换这份策划名单。`defer: []` 表示全部急切加载。

`tool_search` 接受一条或多条查询。`tool_describe` 加载完整 schema。`tool_call` 的 `calls` 是 `{name, arguments}` 数组，单次调用也是长度为 1 的数组。独立调用最多一批 10 条。含本地工具的批次被拆成每条一次工具调用，各自做范围检查、schema 校验、钩子、批准和结果，并遵守该工具自己的并发政策。只有 `connectors__` 名字的批次，作为一次分发交给托管的连接器网关。

桥接工具不绕过批准。延迟工具被调用时，走它原来的检查和钩子。

## Claude Code

没有搜索、描述、调用这三座桥。模型看见的是当前允许的工具 schema。技能用短索引常驻，正文在选中后注入。MCP 工具集只在回合之间刷新，避免一轮中途改 schema。

工具结果过大时裁剪并落文件，这是结果预算，不是 schema 延迟加载。权限仍是每次调用前的允许、询问或拒绝。
