# 交付物

消息网关扫描助手回复里的绝对路径和家目录相对路径。命中支持的扩展名，就把文件从可见文本里拿掉，按类型上传。代码块和行内代码里的路径不动，避免样例被拆碎。模型不必写专门的媒体标记。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 怎么交 | 工具结果里的媒体和渠道附件。静默文字去掉后，待送的语音仍送 | 网关从回复正文提取路径 | 本地文件留在工作区。界面自己打开 |
| 图片 | 生成任务完成后投递。理解走视觉 | 图片内联。视频内联。音频走语音附件 | 内容块或工具结果 |
| 路径 | 任务工作目录和批准的根。越界拒绝 | 绝对路径或 `~/`。代码围栏里的忽略 | 工作区路径由读文件和权限决定 |

## Hermes

在 Slack、Discord、Telegram、WhatsApp、Signal 等网关里，生成的文件可以作为原生附件出现，而不是一条要人自己去拷的路径。图是内联图，PDF 是下载，表格是表格文件。

产生文件的是现有工具和技能：代码执行画图、文档技能、表格技能、PDF、演示、图像生成、语音合成。网关看回复正文。绝对路径，或家目录相对路径，并且扩展名在支持列表里，就会被提取。代码块和行内代码中的路径忽略。

图片内联。视频在平台支持时内联。音频走语音或音频附件。其余作为文件上传，包括文档、数据、地理、演示和压缩包。

路径必须是网关读得到的文件。写在回复里的路径若越出策略允许的根，上传不会把沙箱外的文件变成附件。提取发生在可见文本上，不改已经存进会话的工具结果结构。

流即消息的渠道要求草稿前缀稳定，终稿由消费方 `finish` 交出。附件若必须和终稿一起走，走终稿这条，而不是中途把临时文字封成最终消息。

## OpenClaw

图像、视频和音乐在聊天里异步完成后再发。TTS 同步，作为附件。`NO_REPLY` 去掉可见文字，待送的工具媒体仍交付。

本地媒体的相对路径相对任务工作目录。根是批准的文件系统根或沙箱文件系统。根外和符号链接拒绝。所以交付的是工具已经读到或生成的媒体，不是从回复散文里随便抠一条路径。

反应、打字和块回复是另一条呈现。它们不代替文件上传。

## Claude Code

生成的文件留在工作区。用户在编辑器或终端里打开。没有「从助手散文里抠绝对路径再上传到 Telegram」这一层。图片作为内容块进入模型或从工具结果回来。要送到聊天渠道，得另有一条 Hermes 或 OpenClaw 那种网关扫描。
