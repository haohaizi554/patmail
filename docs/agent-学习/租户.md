# 租户

一台 Gateway 是一个信任边界，不是一栋楼里的多户隔离。互不信任的人或组织要各跑一台完整实例。会话 id、沙箱和工具策略都不是租户授权。主机管理员被每个租户信任。对抗被攻破的主机不是目标。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 默认 | 一个操作者边界一台 Gateway | 单租户个人 agent。多 profile 是同一操作者的岛 | 本机用户的项目会话 |
| 多户 | 实验性的 fleet：每户一个 cell，各自的容器、状态、令牌和回环端口 | 多路复用是多个家目录进一个进程。秘密失败关闭 | 无 cell |
| 会话 id | 只选路由 | 会话属于一个家目录 | 转录文件 |
| 主机 | 管理员可读挂载、环境、令牌。抵抗被攻破的主机不是目标 | 进程内插件与 agent 同权。边界是操作系统 | 本机进程 |

## OpenClaw

默认安全模型是每台 Gateway 一个受信任的操作者边界，不是在共享的一台 Gateway 里做敌对多租户隔离。不共享信任边界的用户或组织，要各自跑一台完整的 OpenClaw。

`openclaw fleet` 把每台隔离实例叫做 cell。cell 是硬化容器里的完整 Gateway，有自己的状态、凭据、工作区、渠道账号、令牌，以及只绑定回环的主机端口。命令、旗标和容器配置可以在版本之间改变，没有弃用窗口。测试在 Linux 和 macOS。Windows 主机目前未测。

已认证的操作者在一台 Gateway 里拥有受信任的控制面角色。会话 id 选择路由，不授权一个租户针对另一个。agent 沙箱能减小不可信内容和工具执行的影响，不把共享 Gateway 变成租户授权边界。每个信任域要有自己的 Gateway 进程、容器、持久状态树和 Gateway 凭据。不要把互不信任的用户放进同一个 OpenClaw 进程或同一个操作系统用户。

Fleet 的 CLI 是主机侧的生命周期监督。cell 记在状态库里，由本机 Docker 或 Podman 创建、查看、启动、停止、替换和删除容器。不支持远程运行时端点，因为绑定路径和回环 URL 属于本机。Fleet 不代理租户消息，也不在 cell 之间加共享的应用层数据路径。

每个 cell 用官方镜像，跑在自己的用户定义桥网络上。分开的桥阻止 cell 之间直接用容器 IP 互访，同时保留出站 NAT。出站默认不限制。Podman 可以用内部网络挡住出站，同时保留发布出来的回环 Gateway 端口。Docker 的内部网络会弄坏那个发布端口，Fleet 拒绝这种组合。Docker 的出站政策用主机防火墙，例如 `DOCKER-USER` 链。容器内监听 18789，运行时只把它发布到主机的 `127.0.0.1` 上分配的端口。远程访问要在这道回环前面加被批准的反向代理、SSH 隧道或 tailnet。

持久状态来自状态目录下该租户的 cell 目录，挂到容器里的 OpenClaw 家目录。当前的 OAuth 访问令牌、刷新令牌和 ID 令牌以明文坐在那次挂载下的 SQLite 里。cell 状态的备份和拷贝要当凭据对待。旁边的认证 profile 秘密目录只放遗留加密边车的恢复钥匙。它不加密当前的 SQLite 行，也不保护只拷状态的备份。渠道账号在拥有它的 cell 里终结。Fleet 不提供共享渠道账号或入站路由器。

官方镜像默认非 root 的 `node` 用户。Fleet 用和主机兼容的用户映射，让私有绑定挂载可写。主机 SELinux 开着时加私有的 `:Z` 重标记。配置避开特权主机特性，对无根友好。无根是主机运行时的选择和前提，不是 Fleet 自动打开的。

多租户保护的是租户彼此。Fleet 操作者和主机被每个租户信任。主机管理员可以看容器配置和环境、读挂载的 cell 数据、换镜像或进入容器。Gateway 令牌和 `--env` 传入的值，管理员经 Docker 或 Podman 查看就能看见。基线防止意外的通配网络暴露，并拿掉常见的容器提权原语。它不使不受信任的主机变得安全。

## Hermes

安全政策把产品定义成单租户个人 agent。对抗恶意模型的唯一边界是操作系统隔离。批准、打红和允许名单是启发式。

多 profile 是同一个操作者名下的多份家目录，可以由一个网关进程服务。这不是多租户。秘密在 scope 里失败关闭，免得次要 profile 读到启动 profile 的环境。一个 profile 的记忆不能刷进另一个的存储。这些隔离是 profile 之间的正确性，不是「把不受信任的客户放进同一进程」。

要把不受信任的多方隔开，需要每方自己的操作系统用户、容器或机器。一个 Hermes 进程加上多路复用，仍然是一个操作者边界。

## Claude Code

会话在本机用户的项目目录里。没有 cell，也没有把第二个不受信任的用户接进同一条 Gateway。远程和 IDE 接的是同一用户的会话。子代理继承这次运行的权限，不构成另一个租户。
