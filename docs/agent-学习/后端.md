# 后端

搜索、抓取、浏览器、图像和视频都是登记处加一个活动名字。核心工具不按提供商名字分支。浏览器插件不实现浏览，它只创建远端会话并交回 CDP 地址，页面由 Hermes 自己的浏览器栈来开。

## 对照

| 能力 | 配置 | 插件做什么 |
|---|---|---|
| 搜索 | `web.search_backend`，否则 `web.backend` | 服务 `web_search` |
| 抓取 | `web.extract_backend`，否则 `web.backend` | 服务 `web_extract`。深爬在抓取里面 |
| 云浏览器 | `browser.cloud_provider` | 创建会话，交回 CDP，再拆掉 |
| 图像 | `image_gen.provider` | `generate` |
| 视频 | 视频提供商 | 有 `image_url` 走图生视频，没有则文生视频 |

两边都没写时，网页能力按环境里出现的钥匙或 URL 自动检测。`hermes tools` 带人去选。用户目录里的后端要启用。发行目录里带 `kind: backend` 的随后加载。

## 网页

内置的 Firecrawl、SearXNG、Tavily、Perplexity、Exa、Parallel、Brave、xAI、DDGS 都在 `plugins/web/<name>/`。`register` 调用 `ctx.register_web_search_provider`，进 `agent/web_search_registry.py`。搜索和抓取可以各选一个后端。深爬模式走抓取那把钥匙，不另开第三个工具名。

未选中的提供商钥匙在 OpenClaw 里是未激活表面，解析失败不挡启动。Hermes 的自动检测是「环境里有哪把钥匙就用哪个后端」。选定之后，换后端是改配置，不是把所有钥匙同时打出去。

抓取正文是工具结果。它不是浏览器标签，不回答对话框，不进入跨域 iframe。

## 浏览器

Browserbase、Browser Use 和 Firecrawl 在 `plugins/browser/`。分发是登记处查找，没有按提供商的条件分支。活动名字是 `browser.cloud_provider`。

插件的合同是会话生命周期：建远端浏览器，交回 CDP 的 WebSocket 地址，用完拆掉。Hermes 的浏览器栈连上这个地址，于是每个提供商都免费得到整套 `browser_*`。对话框、跨域 iframe 和视觉嵌入预算在这套栈上，不在插件里各写一份。

本机 CDP 和云提供商是两条路。云提供商没选中时，本机监督器仍可以盯有调试端口的浏览器。Camofox 只有 REST 时，监督器帮不上抓取替代不了的点击。

## 视频

`video_generate` 一个工具两种模态。只有提示词是文生视频。加上 `image_url` 是图生视频。提供商内部选端点。编辑和延长故意不做，免得工具描述里出现按后端分叉的散文。`capabilities` 广告宽高比、时长和模态。发现路径和图像插件相同：发行、用户目录、pip。

## OpenClaw 和 Claude Code

OpenClaw 的搜索、抓取和浏览器也是分开的工具。提供商在设置里选定之后，其它钥匙变成未激活。没有「插件只交 CDP、核心栈负责点击」这一句写在 Hermes 的登记处合同里。Claude Code 的 `WebFetch` 和 `WebSearch` 是客户端工具，没有这五份后端登记处。
