# 锁

一个状态目录只该有一个 Gateway 进程。再跑一台要换 profile、状态目录、配置和端口。崩溃后只有确认进程已死，或进程启动身份已经变了，才能收回所有权。单靠文件有多老，收不回活着的主人。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 单实例 | 进程主人、兼容投影、端口绑定三层 | 每家目录的网关 pid 和 tick 锁。多 profile 可以进一个进程 | 无守护进程锁 |
| 共享状态 | `OPENCLAW_ALLOW_MULTI_GATEWAY` 也不允许共享可写状态 | 多路复用共享进程，不共享 `.env` | 本机单用户 |
| 等待 | 启动最多等五分钟让别人放开状态 | 更新排干有期限。过期网关让更新失败 | 无 |
| 多台 | 隔离 profile 和端口。基端口至少隔 120，避开浏览器端口 | 桌面的 serve 跟应用死。消息网关分开活 | 无第二台 Gateway |

## OpenClaw

多数安装只要一台 Gateway。它自己接多条消息连接和多个 agent。再开一台只在需要更强隔离或冗余时，例如救援机器人。

启动在发布兼容元数据和绑定监听之前，先取得状态所有权。每次服务启动用同一套准入，包括容器引导拉起的临时 Gateway。直接的服务器一直持有到关停完成。托管的服务器用运行环里已有的主人。这个主人负责重启交接和释放。关掉一代服务器不释放那个主人。

三层。进程主人按规范的共享状态库路径独占创建一份边车。Gateway 启动、嵌入 agent 和离线维护抢的是同一个主人。允许多 Gateway 的环境变量不允许共享可写状态。兼容投影把主人的 pid、进程启动身份、角色和运行端口写进历史的状态锁，给旧 Gateway 认出当前进程。它是进程主人底下的元数据，不是另一个生命周期主人。套接字再独占绑定 HTTP 和 WebSocket，默认 `127.0.0.1:18789`。

启动或重启时最多等五分钟，让另一个 OpenClaw 进程放开状态。等待开始、取得所有权或超时都会记日志。超时则启动失败，并写出等了多久。

Linux 和 macOS 上，进程主人在状态目录下按用户和库路径哈希命名的锁里，不要求能写父目录，也不依赖系统临时目录。`TMPDIR` 不改变这个命名空间。Windows 在用户的 `AppData/Local/OpenClaw/locks` 下。破坏性清理保留进程主人和兼容投影，同时清状态内容，所以新启动仍被挡住，直到原生库资源和破坏性操作落定。正常释放删掉边车，旁边没有一份 SQLite 协调库。

清理在删除状态之前拒绝被重定向的库路径或运行时锁路径。删掉内部符号链接可能选出新主人，而原文件仍锁着。先选定真正的状态根和真实的内部目录。整个状态根的别名仍支持。

所有权用独占创建文件，以及已有的检查释放和过期恢复。进程已死，或核对过的进程启动身份变了，才允许恢复。年龄本身从不撤销活主人。所有权读不出来就拒绝。

共享状态的读传输可以把一次成功的主人核对缓存不到一秒。到期后，读准入同步解析路径并核对边车，再把工人 I/O 派出去。这个上限不靠定时器或事件环。释放、清理和 schema 维护立刻作废缓存的路径。写、schema、租约和每个通用 SQLite 工人作业仍立即做新鲜的所有权检查。缓存的读核对不代替物理库身份、调用方授权或提交准入。

没有活着的本地 Gateway 或维护主人时，schema 工作会短暂取得同一道进程门和历史投影，免得新的 CLI 在一台仍受支持的旧 Gateway 底下迁移状态。

活主人在任何一方绑定端口之前就挡住另一次启动。

救援机器人用另一个 profile、另一枚机器人令牌和更高的基端口，例如 19789。基端口至少相隔 120，因为浏览器控制在基端口加 2，CDP 范围延伸到基端口加 110。救援实例有自己的工作区、状态和配置。主机器人还在跑时，通常装好救援服务即可。

## Hermes

一个家目录的 cron 用该家目录下的 tick 锁，防止两个进程同时拨同一份任务库。锁挡的是同时拨，不挡「主机网关和这个 profile 自己的网关谁该拨」的竞赛。后者用是否已有别的网关在为这个家服务来决定主机是否让出。

消息网关和桌面拉起的 `hermes serve` 是两个进程。serve 随应用退出。网关被拆出来继续跑。不要为了让网关随应用死，而把它重新挂到后端下面。

多路复用是一个进程服务多份家目录，不是两台 Gateway 共享一份可写状态。秘密和终端范围按活动绑定。

## Claude Code

没有状态目录锁，也没有第二监听端口。两个客户端可以打开同一项目目录里的转录，冲突是文件写入的事，不是 Gateway 所有权。worktree 把检出分开，不分配 18789 这段端口。
