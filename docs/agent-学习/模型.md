# 模型

选中的模型和真正答这一轮的模型可以不同。显式选过的模型失败时要报错，不能悄悄换成配置里的备用。同一提供商的多把钥匙先轮换，跨提供商的备用只活在当前这一轮。换钥匙会让提供商侧的前缀缓存作废。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 引用 | `provider/model`。加认证不改已有主模型 | 保存的 `model` / `provider` 高于残留的环境变量 | 客户端当前模型 |
| 同提供商 | 认证 profile 按会话钉住。失败再轮换 | 凭据池先试。402 立刻换钥匙 | 登录和 API 密钥在客户端 |
| 跨模型 | `fallbacks` 只用于这一轮。用户覆盖是严格的 | `fallback_providers` 链。限流可按重置时间停板 | 没有 Gateway 式的会话模型覆盖来源 |
| 组合 | 参考模型不进工具循环。聚合器才是在跑的模型 | MoA：参考模型无工具，聚合器持有工具循环并计费 | 无内置混合代理 |

## OpenClaw

失败分两段。先在当前提供商里轮换认证 profile，再落到 `agents.defaults.model.fallbacks` 的下一个模型。轮换之前，对临时限流和提供商故障做有界的同模型恢复，沿现有 transcript 继续，并要求先检查被打断的动作。本地 transcript 写入冲突不重试模型、不换账号、不触发备用。思考级别只有在提供商明确指出推理参数时才恢复。模型或账号限制不会靠关掉思考再试一次。

候选链看选择来源。配置的默认、cron 的主模型和自动选出的备用可以用配置的 fallback。用户用 `/model`、模型选择器、`session_status` 或 `sessions.patch` 选中的是精确选择，失败就报告，不用无关的备用回答。选「默认」会清掉覆盖并恢复配置默认的备用策略。旧会话里只有 `modelOverride`、没有来源字段的，当成用户覆盖，避免把当年的明确选择悄悄变成可回退。cron 的 `payload.model` 是任务主模型，自带 `fallbacks: []` 时变严格。

备用执行只属于这一轮。下一轮仍从选中的主模型开始。状态里只留下通知，让 `/status` 能区分选中的模型和实际回答的模型。回合超时和空闲超时熔断是终局，不请求再试下一个模型。

认证存在每个 agent 的 SQLite 里。配置里的 `auth.profiles` 和 `auth.order` 只是元数据和顺序，不含秘密。退役的 `auth.json` 一类文件要 `doctor --fix` 才导入。运行时在迁完之前对该 agent 失败关闭，不悄悄回退去读旧文件。

多 profile 的顺序是：该 agent 存下的顺序、配置的 `auth.order`、配置里的 profile、库存里的 profile。没有显式顺序时按类型：OAuth，然后静态令牌，然后 API 密钥。OAuth 里当前还能用的访问令牌排在已过期的前面。过期的仍有资格，以便在没有可用同伴时刷新。同层里最久没用的先用。冷却和禁用的排到末尾。

自动选中的 profile 按会话钉住，为的是提供商缓存。压缩不换钉。`/new`、冷却和禁用才会动自动钉。用户用 `/model …@profile` 钉住的，跨重置、压缩和冷却窗口都还在。钉住的那一个在冷却时，先试同提供商的下一个，但不改存着的钉。用户选的提供商和模型仍然严格：同提供商的 profile 用尽就报失败。

普通冷却按最近错误次数：30 秒、1 分钟、5 分钟封顶。限流冷却可以只针对那一个模型，同提供商的兄弟模型仍可试。账单和永久认证类先禁用约十分钟。每周或每月额度窗口走短冷却，不走长禁用。账单失败值得转移。格式错误通常终局，因为同一份载荷再发还会失败。已知的修复路径要显式加入，例如把工具调用 id 洗干净再试一次。

OpenAI 的 `openai/gpt-*` 前缀本身不选 Codex。运行时策略未设或为 `auto` 时，只有精确的官方 HTTPS Responses 路线才可能隐式选 Codex。自写的 Completions 适配器和明文 HTTP 端点留在 OpenClaw。加 OpenAI 认证时保留已有主模型。

结构化的 OpenAI 网络安全拒绝可以在本轮重放到 Daybreak，前提是没有工具或投递副作用会被重放，选择也不是严格的。普通提供商故障不走这条。重放已经执行过工具或发出过内容之后失败，保留重放自己的结果。

## Hermes

解析顺序是：当次显式请求、`config.yaml` 里保存的模型、环境变量、提供商默认。保存的选择是常态真相，避免壳里残留的 `OPENAI_BASE_URL` 盖掉上次在 `hermes model` 里选的端点。

每个提供商插件声明 `api_mode`、`base_url`、环境变量优先级和备用模型。用户目录里的同名插件盖过内置的。密钥按端点隔离：OpenRouter 的钥匙只发给 `openrouter.ai`，AI Gateway 的钥匙只发给自己的主机。自定义端点和「没有自定义端点时走 OpenRouter」是两条路。

Anthropic 选中时走原生 Messages API，不是一律经 OpenRouter。可刷新的 Claude Code 凭据优先于抄进来的环境令牌。

三层韧性按顺序：同一提供商的凭据池、主模型的跨提供商备用、辅助任务自己的备用。池的策略可以是轮转、最少使用、先填满或随机。429 若是用量封顶，立刻换下一把钥匙，不再对同一把重试。普通 429 先对同一把再试一次。402 立刻轮换，并冷却一小时。401 先尝试刷新 OAuth。内容策略失败不轮换。

提供商侧的提示缓存按账号或 API 钥匙。池中途换钥匙，下一请求按全价重读整段历史。轮换让会话活着，长对话每次轮换付一次全价。

主模型备用写在 `fallback_providers`。限流响应若带了重置时间，主模型停到那个时刻。没有时间则按大约 60 秒起到 4 小时的退避。`fallback.min_switch_reset_seconds` 可以让很快就会恢复的主模型先等，而不是立刻换。备用是另一对提供商和模型。遗留的单数 `fallback_model` 仍被承认，两者都在时列表优先。

推理字段在进字符串处理之前被摊平。`reasoning_details` 按到达顺序保留，不合并、不改写，并进入会话重放。推理和可见回答分开。

## 混合代理

MoA 是一个虚拟提供商。选中某个预设后，聚合器才是在行动的模型：它写回答、发工具调用，也承担这一轮几乎全部费用。参考模型先跑，不带工具 schema，只看用户和助手正文，不看 Hermes 系统提示和工具转录。参考输出作为私有上下文交给聚合器。工具结果回来后，下一圈再次先问参考模型。

`/moa` 加提示是一次性：用默认预设跑完，再恢复原来的模型。要让本会话一直用某个预设，从模型选择器里选 `moa`。参考模型默认每个用户回合扇出一次。聚合器的提供商和当前 `model.provider` 不同时，界面标明费用记在聚合器上。

## Claude Code

模型在客户端设置和当次会话里。失败转移笔记里的同模型恢复、空响应修补和流式回退，发生在这一次 `query` 里。没有「用户覆盖所以禁止配置备用」这种来源字段，也没有按会话钉住的认证 profile 来保前缀缓存。换账号就是换客户端登录。

MCP 和技能不改变当前模型。辅助压缩若存在，走客户端自己的摘要路径，不经过 Hermes 的辅助路由表。
