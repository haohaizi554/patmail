# 工作树

托管工作树给一次任务自己的分支和检出，临时目录不放进源仓库里面。删除前给已跟踪的和未忽略的未跟踪内容做快照。快照做不出来时，容量驱逐可以清掉未保存的数据。沙箱里的执行用私有检出，被接受的变更仍归托管工作树。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 位置 | 状态库登记。可放到别的盘或自定义目录 | 终端工作目录。提示把 git 快照放在共享项目文件之后 | 计划模式可配合 worktree |
| 沙箱 | 私有检出执行。托管工作树是已接受变更的主人 | 容器后端困住 shell 和基于 shell 的文件工具 | worktree 是文件系统隔离，不是容器 |
| 依赖 | 在一次性沙箱里准备 `node_modules`，再克隆给会话。仓库代码不在主机上跑 | 不在工作树创建时预装依赖 | 检出就是工作区 |
| 权限 | 创建工作树只钉目录，不改已保存的权限模式 | 批准和终端策略不因换目录自动升档 | 权限规则仍按路径匹配 |

## OpenClaw

任务得到自己的 git 分支和检出。OpenClaw 把它们记在共享状态库里。普通删除之前，快照已跟踪的内容，以及未被忽略的未跟踪内容。容量驱逐在做不出快照时可以清掉未保存的数据。

拉取请求的统计可能刷新托管检出里 Git 缓存的文件时间戳。它们不暂存内容，也不改提交。用户自己管的检出保持索引不变。

沙箱中的项目会话用私有 Git 检出执行。托管工作树仍是已接受变更的规范主人。Docker 和 Podman 支持这种本地投影。主机仓库的共享 Git 元数据和被忽略文件的供给不挂进、也不拷进私有检出。

在 Btrfs、APFS 和 ReFS 上，带有已提交 `pnpm-lock.yaml` 的新私有检出可以复用装好的依赖。OpenClaw 在一次性沙箱里准备一次，再为每个会话克隆这份准备好的检出。Gateway 就绪后，在后台为配置的 agent 仓库准备默认会话基线。准备期间到达的会话等待同一次构建。之后的检出带着 `node_modules`。其它选中的提交仍在第一次使用时准备依赖。关停取消准备，并等待一次性安装器被移除。

私有检出的存储必须支持文件系统加速。`worktreeAcceleration: false` 也关掉这份准备。准备使用选中的沙箱镜像、网络限制和来宾工作目录，不带配置的凭据、自定义挂载或安装命令。安装期间 Git 元数据只读。额外保留的只有 `node_modules` 目录，不论 Git 忽略怎么拼写。生成的原生协议文件和其它安装产物不共享。仓库代码不会作为这次准备的一部分在主机上运行。网络设为 none 时，pnpm 用离线模式，缺包或元数据缓存时尽快回退，而不是把网络重试等完。

可复用的一代绑定源提交、冻结的锁文件和不可变镜像。换了提交就是另一代。

会话的 `sessionRoot` 是这棵检出。嵌套的当前目录只影响相对路径的起点，收纳覆盖整棵检出。创建工作树不选择权限模式。显式模式和已经写在会话上的模式保持不变。

热重载里，工作区根和加速开关归在 agent 与模型一类，默认不因此重启整个 Gateway。选中带退役安装状态的工作区会被拒绝，重载不迁移工作区状态。

## Hermes

项目上下文文件先于依赖当前工作区的 git 快照。同一项目的不同 worktree 因此共享一段更长的提示前缀。工作目录来自 CLI 的当前目录，或消息网关的 `terminal.cwd`。

换工作树不自动复制一份会话库，也不做 OpenClaw 那种删除前快照。文件工具和终端看到的是这个目录。沙箱后端若启用，困住的是 shell 和建立在 shell 上的文件工具。

## Claude Code

worktree 把一次任务放进隔离检出，计划模式在人接受计划前限制写。没有「删除前快照未跟踪文件、快照失败则容量驱逐可以清数据」的状态库合同。依赖安装就是在那个检出里发生的普通命令，受权限检查。仓库代码会在用户允许的前提下于该检出运行。
