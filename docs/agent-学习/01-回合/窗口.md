# 窗口

上下文是这一轮真正发给模型的全部：系统提示、这段会话的历史、工具调用和结果、附件。它有模型窗口的上限。磁盘上的记忆可以以后再加载，不自动等于已经在窗口里。控制界面的表用的是上一轮的提示预算，而且只在模型和有效上限还对得上的时候。换了模型或上限之后，表改显示上下文窗口，直到新的一轮给出匹配的估计。过时的 token 总数是近似的，不触发上下文警告。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 看占用 | `/status`、`/context list`、`/context detail`、`/context map` | 用量锚和压缩阈值 | 请求前的分层预算 |
| 表 | 上一轮提示预算，已留出压缩储备。标签写明是估计 | 网关卫生大约 85%，压缩器大约 50% | 自动压缩缓冲和工具结果预算 |
| 换模型 | 表回到上下文窗口，不拿旧总数去报警 | 换钥匙会让提供商侧前缀缓存作废。系统提示字节在对话内稳定 | 新请求按新模型的窗口 |
| 腾地方 | `/compact` 把旧历史收成一条 | 先裁旧工具结果，再摘要。压缩把旧行标成不活跃 | 分层裁剪，失败有断路器 |

## OpenClaw

系统提示由 OpenClaw 建：规则、工具、技能列表、时间和运行时，以及注入的工作区文件。历史是这条会话的用户和助手消息。工具结果和附件是命令输出、读文件、图像和音频。

`/status` 看窗口有多满，以及会话设置。`/context list` 看注入了什么和粗略大小。`/context detail` 拆到每个文件、每个工具 schema、每个技能条目、系统提示大小，以及可压缩的转录条数。`/context map` 是当前会话被跟踪的上下文贡献的树图。`/usage tokens` 在普通回复后附加用量脚注。`/compact` 把较旧的历史收成一条，腾出窗口。

工具 schema 的 JSON 计入上下文，列表视图里不把 schema 全文当文本展示。技能列表是系统提示里的文本，不是每份技能正文。

控制界面的上下文表：上一轮的提示预算若仍匹配选中的模型和有效上下文上限，就用那份预算。预算给运行时的压缩储备留了地方。标签是「上一轮的提示预算」。它是估计。越过它可以触发工具结果缩减或压缩。模型和上限一变，表显示上下文窗口，直到新的一轮提供匹配的估计。留下来的旧 token 总数保持近似，不触发上下文警告。

工作区文件有各自的注入预算。示例输出里的字符数随模型、工具政策和工作区变化，不是固定合同。

## Hermes

系统提示分稳定、上下文和易变三层。钉住的自动加载技能在稳定层。技能索引在易变层。日期行在当天内字节稳定。压缩是对话进行中唯一允许改已发送上下文的地方。网关在大约 85% 做会话卫生。agent 的压缩器默认大约 50%，可按模型覆盖。用量锚把报告钉在提供商返回的数字上。换模型不把上一轮的估计继续当成报警线。

## Claude Code

请求前按边界、工具结果预算、剪裁、微压缩和自动压缩缓冲分层处理。工具结果大约每条有上限、每一轮另有上限。连续失败有断路器。还原树里有的步骤是桩。没有「换模型后表改显示窗口、旧总数不报警」这块控制界面。
