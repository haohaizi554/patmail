# 终答

经 Codex 运行时的直接或来源聊天，对内部 WebChat 默认自动投递最终助手文字，和 Pi 运行时的合同一致。agent 正常回复，OpenClaw 把最终文字发到来源对话。`messages.visibleReplies` 设成 `message_tool` 时，最终助手文字保持私有，除非 agent 调用 `message` 的发送。解说跟随对话的进度设置，可以隐藏或临时。工作还在继续时来了问题，agent 被指示用 `message` 发送且 `final` 为假，然后继续任务。最终回复覆盖还没交付的答案和结果。这不打开解说，也不改流式设置。

## 对照

| | OpenClaw Codex | Hermes | Claude Code |
|---|---|---|---|
| 没有可见答案 | 可以在私人临时家目录里请求有界的终答回合。用完成线程的模型选择和原来的宿主认证 | 空回复有回合阶段。不另开一条无工具的终答去重放 | 查询循环要有最终文本 |
| 已完成的动作 | 是转录证据，不是重放指令。历史保持完整。已完成的动作从不重复 | 工具结果已落盘的不涂改 | 工具结果留在转录 |
| 监督聊天 | 不选宿主凭据，不复制原生凭据，不再开原生回合。交已有的回退句 | 无这道监督连接 | 无 |
| 远端附件 | 在释放 app-server 连接之前用有界的命令读取。工作区副本不作回退 | 媒体走适配器 | 客户端路径 |

## OpenClaw

显式标成异步投递的原生 Codex 消息有独立的投递意图。它们和可选的进度、以及最终答案分开投递，即使分块流关着。

心跳回合默认在可搜索的 OpenClaw 工具目录里有 `heartbeat_respond`，让 agent 记下这次唤醒该安静还是通知。心跳回合用和普通聊天相同的 Codex 默认协作模式。心跳监视器的 cron 草稿若存在，附加到排定的心跳用户消息上。

设了 `appServer.remoteWorkspaceRoot` 时，最终和异步回复可以用工作区内的相对或绝对路径。释放 app-server 连接之前，Codex 插件用有界的 `command/exec` 读取附件。宿主的回复媒体能力套读取政策并把字节暂存以便投递。原来的回复留在转录里。Gateway 工作区副本不用作回退。工作区外的文件产生带标签的附件失败。发送前先拷进工作区。HTTP 引用和托管的 `media://` 附件继续可用。

普通的、宿主认证的 Codex 回合，工具做完了却没有可见答案时，OpenClaw 可以在私人临时家目录里请求有界的终答回合。它用完成线程的模型选择，以及原来的宿主认证路线或已解析的 profile，不从外层请求元数据里另选模型。已有的环境、动态工具、MCP 和原生钩子限制仍在。已完成的动作是转录证据，不是重放指令。保住原生模型，本身不关掉宿主认证的收尾。

隐藏的后台任务完成消息，若在模型上下文里，仍有资格做这次恢复。宿主把它们的原生回合身份记在已准入的提示上，聊天里仍隐藏。原生转录镜像把那份提示当证据复用。它不能重新造出一份已经消失的已准入提示。明确排除在模型上下文之外的消息，留在原生提示标注之外。

恢复先为完整的当前回合保留已有限额，然后留下装得下的、最近的、完整的更早交换。更早的交换可以省略，包括一整段大到装不下的交换。空间允许时，通知标明缺了哪些历史。收尾者总是被指示对缺失的事实说明不确定。当前证据超过限额、工具配对无效，或不支持的内容，仍使恢复不可用。已有对话历史保持完整。已完成的动作从不重复。

经 Codex Sessions 创建的聊天不同。它的私人监督连接拥有原生认证。原装 Codex 不暴露一种通用的、无工具的摘要操作来保住那条连接的账户。OpenClaw 把这次收尾上下文标成不可用，而不是去选宿主凭据、复制原生凭据，或再开一轮原生回合。若必须有最终回复，宿主交付已有的回退：工具运行结束了，但没有产生最终摘要。它没有重复任何已完成的动作。原来的完成结局、原生绑定和工具回执保持完整。

## Hermes

最终回复来自回合结束。空回复和错误有自己的阶段。没有「工具做完却无可见答案时，在私人临时家目录用原认证再要一次有界终答，且已完成动作只当证据」。转向不涂进已落盘的工具行。

## Claude Code

查询循环在没有工具调用时返回内容。分层压缩在请求前。没有监督连接拒绝宿主凭据、改交固定回退句这一条。
