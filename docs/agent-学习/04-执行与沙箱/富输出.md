# 富输出

助手输出里的投递和渲染走专用通道。结构化的 `mediaUrl` 是附件。`[[audio_as_voice]]` 是语音呈现提示。`[[reply_to_current]]` 和 `[[reply_to:<id>]]` 是回复元数据。`[embed ...]` 只给控制界面的富渲染，不是媒体的别名。工具、插件、浏览器、消息动作和流式分块必须用结构化附件字段，不用正文里的文本命令。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 远端附件 | 必须是公开的 `https:`。`http:`、环回、链路本地、私网和内部主机名拒绝 | 媒体走适配器。出口代理另有守卫 | 客户端附件 |
| 本地 | 绝对路径、工作区相对路径或 `~/`。仍过文件读取政策和媒体类型 | 读文件受工作目录和后端约束 | 工作区路径 |
| 历史 | `media://inbound/<id>` 解析成存着的文件，再过同样的读取和沙箱检查 | 消息行里的媒体 | 转录旁的文件 |
| 缺文件 | 控制界面显示附件错误，不把字面的 `MEDIA:` 行留下来 | 工具错误 | 读失败即错误 |

## OpenClaw

远端附件指令被拒绝时，服务端的媒体拉取还有自己的网络守卫。本地附件在投递前过 agent 的文件读取政策和媒体类型检查。

控制界面里，相对的本地引用按会话工作目录解析，包括选中的项目或 worktree。走和绝对路径相同的已认证媒体路由。另一台执行主机上的文件要先变成托管附件。

`message` 发送时，一个附件用 `media`，多个用 `attachments`。自动模式里模型写在正文里的兼容写法，不是工具、插件或分块流的通用协议。

结构化字段和 `[[...]]` 标签是投递元数据。把它们写进给模型看的普通句子，不代替这些字段。

## Hermes

出站媒体由平台适配器发送。视觉嵌入进工具结果，受体积和重复次数预算。没有「远端附件只许公开 https、环回和私网在指令层拒绝」这一页富输出协议。铁代理的子进程环境是允许名单。文件权限收紧。

## Claude Code

附件是这次客户端的工具或用户消息。没有控制界面专用的 `[embed]` 和 `media://inbound` 解析。
