# 版本

运行时状态以数据库为准。一个全局 SQLite，每个 agent 再一个。运行时代码不把 JSON 旁路文件当成活动状态来读写。这条合同在 CI 里机器检查。模式带两位版本。构建拒绝打开比自己新的库。`openclaw update` 拒绝那些声明的模式支持比你磁盘上的库更旧的目标。没有模式元数据的旧目标包无法做预检。`openclaw doctor --fix` 是文件迁进 SQLite 的唯一主人，每一次都记回执。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 活动状态 | SQLite。JSON 旁路不是活动状态 | `state.db` 加配置 YAML。秘密在 `.env` | JSONL 和设置 |
| 更旧的目标 | 更新拒绝模式支持比磁盘库旧的包。缺元数据不能预检 | 更新有快照和回执。配置版本只在要迁移时加 | 客户端版本 |
| 迁移主人 | 只有 `doctor --fix` 做文件到 SQLite，并记回执 | 配置深合并。显式迁移才升版本 | 无这道 |
| 通道 | 稳定、扩展稳定、测试、开发。扩展稳定缺注册表数据是错误，不退回 `latest` | 发布按提交钉 | 客户端发布 |

## OpenClaw

备份里的 SQLite 快照用 SQLite 的在线备份 API，创建和发布时做完整性和哈希检查。整包校验不把普通文件载荷绑到内容哈希。恢复从不就地覆盖。重启恢复在有界的尝试预算里续被打断的回合。崩溃循环断路器让控制面仍可达，同时压住频道自动启动。

发布走四个通道：稳定、扩展稳定、测试、开发。日历版本，npm 发布不可变。扩展稳定是保守轨道，失败关闭。更新器重新拉取并核对选中的那一个包。注册表数据缺失或不一致是错误，绝不退回 `latest`。完整发布验证把不可变的执行计划封起来，覆盖跨操作系统的安装和升级、包验收、活频道分片和性能门。发布串行，来源经 Sigstore 证明和 npm 来源，挂在 OpenClaw 基金会身份下。

成熟度记分卡给各个面打分，每一行有长期支持状态。扩展稳定回答一个面支持多久。记分卡回答它被证明到什么程度。记分卡不是「TypeScript 已被形式验证」。

## Hermes

配置有版本，只在要主动迁移时加。新键深合并。状态库的模式损坏会隔离句柄。更新是计划、快照、应用、按种类重启、核对、回执。没有「构建拒绝打开比自己新的库」和「扩展稳定缺数据绝不退回 latest」写在同一份通道合同里。医生的修复和检测分开。Gateway 开着时不要跑会改状态的修复。

## Claude Code

设置和 JSONL 是客户端的文件。没有「运行时拒绝把 JSON 旁路当活动状态」这一条 SQLite 合同，也没有四个发布通道里扩展稳定失败关闭。
