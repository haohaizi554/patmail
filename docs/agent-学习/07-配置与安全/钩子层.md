# 钩子层

Codex 回合外面有三层钩子。OpenClaw 插件钩子管产品和插件在 OpenClaw 与 Codex 运行时之间的兼容。Codex app-server 的扩展中间件是捆绑插件，管每一回合围绕 OpenClaw 动态工具的适配。Codex 原生钩子归 Codex，管低层生命周期和来自 Codex 配置的原生工具策略。OpenClaw 不用项目或全局的 Codex `hooks.json` 来路由插件行为。原生工具和许可桥上，OpenClaw 为每条线程注入 `PreToolUse`、`PostToolUse`、`PermissionRequest` 和 `Stop` 的 Codex 配置。

## 对照

| | OpenClaw 对 Codex | Hermes | Claude Code |
|---|---|---|---|
| 策略替换 | `before_prompt_build` 里的 `systemPrompt` 替换整份通用开发者策略。显式空字符串撤回它 | 系统提示在对话内字节稳定。钩子不中途换掉已缓存的前缀 | 客户端钩子是事件总线 |
| 暖线程 | 没变且配置已证明的暖线程保持暖。插件策略等待之后再核对保留的订阅和宿主权威 | 压缩才改已发送上下文 | 无这道卸载证明 |
| 失败 | 订阅者或原生卸载失败挡住配置证明时，回合在推理前停止。不自动做认证 profile、模型备用或整轮重试 | 观察者钩子失败打开，除了工具前拦截 | 钩子失败按客户端 |
| 隐身 | 普通隐身对话保留活的短暂历史。策略变了或被显式清空，下一回合在推理前停止 | 无隐身线程配置 | 无 |

## OpenClaw

关闭或已归档的线程不能仅仅因为连接还开着就被复用。冷恢复和策略变了的恢复保留原生线程和历史，核对 Codex 已卸载上一份配置，然后在准入回合之前追加一条完整的、取代旧策略的消息。历史上的策略文字可以留在转录里。后来的策略明确取代它。

普通对话在本地 stdio、WebSocket、Unix 套接字和 stdio 代理上用同一套取消订阅再恢复的流。原生对话 id 和历史不变。OpenClaw 核对原来的 app-server 客户端仍是当前的、线程没有活动回合、Codex 已卸载上一份配置，然后才装上当前策略。

这次刷新要求 OpenClaw 是原生对话的唯一生命周期主人。Gateway 拥有的远程 app-server 在交接期间没有独立客户端能重载同一对话时，满足这道部署合同。连接和卸载检查不提供独立客户端之间的原子交接。竞争的恢复可以装回旧的原生配置。有竞争对话主人的共享 app-server 在这道刷新合同之外。

配置证明被挡住时，回合在推理前停止。写前的所有权拒绝保留健康的共享客户端和它的其它对话。策略拒绝，以及不确定或已确认的策略写入失败，保留对话，并停止自动的认证 profile、模型备用和整轮重试。

受监督的外部连接保留已有的共享连接租约语义。已有的原生家目录和工具目录限制仍适用。那些租约检查不建立对外部原生进程的独占所有权。加强那份保证是单独的限制，不是普通策略刷新的一部分。手动的普通收养仍要 agent 家目录和工具目录检查，以及原生进程证明。

普通隐身对话保留活的短暂历史。原装 Codex 不能更新它们的通用会话配置，也不能从磁盘恢复它们。所以改了或显式清空的通用策略会在推理前停掉下一回合。要继续，恢复上一份策略，或为新策略开一条新的隐身对话。策略没变的回合继续。这次检查不给隐身历史加空闲过期或持久化。

预检拒绝保持普通的外部聊天诊断隐私和群里的沉默政策。详细模式可以显示有界的恢复细节。外部关掉的短暂线程不能承诺可恢复。

启动或恢复线程之前，OpenClaw 准备原生中继存着的 MCP 批准快照和直接发布尝试，然后重新核对当前运行的权威。监听器或 SQLite 定位器不可用时，钩子命令可以用已有的 Gateway 回退。策略准备仍必须成功。Gateway 调用独立于发布，等待那份快照。

## Hermes

观察者钩子失败打开，除了工具调用前的拦截和修改，以及变换钩子。辅助调用有自己的前后事件，不触发主循环的请求事件。没有「系统提示替换整份开发者策略、暖线程要证明配置已卸载、隐身策略变化在推理前停」这一页 Codex 钩子边界。

## Claude Code

钩子是和消息流分开的事件总线。没有三层里「不用 Codex 的 hooks.json、只注入四类原生钩子」这一划分。
