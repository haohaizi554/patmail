# 内钩

内部钩子是 Gateway 进程里的 JavaScript 或 TypeScript。它们和插件的 `api.on`、也和 HTTP 入站不是一套。`hooks.internal` 管这些事件处理。`hooks.enabled` 管 HTTP。事件名用冒号，例如 `message:received`，不是插件那种下划线名字。它们是受信任代码，不在沙箱里，用的是 Gateway 进程的文件、网络和环境。启用前要审过，尤其是工作区里或下载来的包。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 进程内事件 | `HOOK.md` 加处理函数。工作区钩子要显式加入 | 观察钩子失败打开。`pre_tool_call` 能挡 | 独立事件总线，挂起上限 |
| 三态 | 条件满足、配置启用、Gateway 已加载。CLI 的 ready 不证明已加载 | 登记进执行范围才算活 | 钩子注册在客户端 |
| 重载 | 选中的处理函数先准备好再一起替换。加载失败则旧的继续 | 插件热加载有自己的激活摘要 | 无 Gateway 重载 |
| 远程 | `enable` / `disable` 只改本机配置，不经 RPC 改远端 | 配置写在该 profile 的家目录 | 无 |

## OpenClaw

适合在 `/new`、`/reset`、`/stop` 以及会话和消息生命周期上做短的副作用，例如记下会话上下文。改提示、拦截工具、控制回复、带优先级和返回值的生命周期，用插件钩子。让别的服务用 HTTP 开工，用 webhook。只导出遥测、不改行为，用诊断事件。

可以订阅精确键，或裸的家族名 `command`、`session`、`agent`、`gateway`、`message`。家族订阅收到该家族里的全部动作。同一处理函数不要既订 `command` 又订 `command:new`，否则一条新命令会调用它两次。`session:compact` 不是家族，也不是通配。要订压缩，订 `session:compact:before` 和 `session:compact:after` 这两个精确键。压缩前等待。压缩成功后等待。`session:patch` 是异步通知。`command:stop` 在中止请求之后等待，钩子回复不投递。`session:auto-reset` 在每日或空闲策略替换已有会话时发出，和后继回合分开分发。

捆绑的钩子不用为此写插件。默认混合重载可以不重启就应用钩子配置。重载模式 `off` 时要自己重启 Gateway。多个 agent 且没有隐含主人时，命令加上 `--agent`。

三个检查分开：

- 条件满足：钩子的操作系统、二进制、环境和配置要求在做检查的那台主机上通过。
- 配置启用：按钩子或来源的政策允许。工作区钩子要显式加入。广泛发现开着时，捆绑的和托管的钩子不需要逐个旗标。
- 已加载：正在跑的 Gateway 选中了它，导入了处理函数，登记了事件。还要总开关和配置的名字选择允许它。

CLI 的 `ready`、`eligible`、`loadable` 描述前两项，加上事件列表非空。它们不证明 Gateway 导入了处理函数，不证明全局选择包含它，也不证明事件已经发生过。改完之后看真实副作用或钩子自己的日志。`hooks check` 单独不能证明处理函数跑了。

配置重载先准备选中的处理函数，再一起替换。某一个加载失败，先前的处理函数保持活动。已经在跑的事件用原来的处理函数跑完。之后的事件用新的选择。重载不重放 `gateway:startup`。

`hooks list`、`info`、`check` 问的是选中的 Gateway 的清单。隐含的本机 Gateway 在不可用或没有报告方法时，可以退回本机发现。配置了的远端 Gateway 或显式的 `OPENCLAW_GATEWAY_URL` 失败时，不退回你笔记本上的钩子。

`enable` 和 `disable` 始终检查并修改本机配置。要改某台 Gateway 主机上的钩子，就在那台主机上跑。`--agent` 选择要检查的工作区，不是一份隔离的钩子登记处。保存的 `hooks.internal.entries` 是全局的。Gateway 从它选中的工作区把目录钩子载进进程范围的登记处。不会因为你检查了某个 agent，就把每个 agent 的 `hooks/` 都载进来。处理函数若只该对某一个 agent 行动，必须自己按事件里的 agent 或会话过滤。

命令日志里有会话和发送者标识。试完不想留这些记录，就把钩子关掉。

## Hermes

观察钩子抛错被接住，循环继续。`pre_tool_call` 可以挡住或修改。`transform_*` 可以替换文本。批准钩子只记录人的选择，不能预先答应。插件在宿主隔离模式下跑在每 profile 的宿主进程里。那是插件宿主，不是 OpenClaw 这种「工作区 JS 直接进 Gateway 进程、三态里只有已加载才算」。

## Claude Code

钩子在客户端的事件总线上，和消息流分开。挂起有上限。没有「CLI 说合格、Gateway 却没导入」这一档，因为没有这台 Gateway 进程内的钩子登记处。
