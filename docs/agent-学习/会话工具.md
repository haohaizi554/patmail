# 会话工具

跨会话的工具在多人一起推动这一轮时，必须带上请求者已经核实的 profile。这个人的权限决定能看哪些会话、孩子以谁的名义执行。不认识或已撤销的参与者被拒绝。一个人的回合可以省略。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 列举和历史 | `sessions_list`、`sessions_history`、`sessions_search` | `session_search` 在这个家里 | 打开项目 JSONL |
| 发送 | `sessions_send` 在同一台 Gateway 上跑另一条会话。`conversations_send` 发到一个精确的外部对话，不跑本地会话 | 消息工具和适配器投递 | 无跨会话发送 |
| 生成 | `sessions_spawn` | `delegate_task`。叶子没有再委派 | Agent 工具和侧链 |
| 多人 | 可选的 `user`。好几个人推动时必填 | 共享会话用发送者前缀。秘密按 profile | 本机一个用户 |

## OpenClaw

`sessions_list`、`sessions_history`、`sessions_search`、`session_status`、`sessions_send`、`sessions` 和 `sessions_spawn` 接受可选的 `user`，值是请求者已经核实的 `requester_profile.id`。好几个人推动了这一轮时，它必填。点名的那个人的权限决定会话访问和孩子怎么执行。未知或已撤销的参与者拒绝。单人回合可以省略。排程任务和没有回合参与者的 SDK 或插件运行，沿用它们已有的会话访问规则。

`sessions` 修补、重置、删除或指定可见会话的主人，并管理会话组。`sessions_list` 按种类、标签、agent、归档和预览过滤。`sessions_send` 在同一台 Gateway 上运行另一条会话，可选等待。`conversations_list` 列出稳定的外部对话地址。`conversations_send` 发到一个精确的外部对话，不因此在本地跑一条会话。

可见性和搜索笔记里的规则在这里仍然有效。默认 `all` 让未沙箱的调用方能搜到别的 agent。沙箱 agent 在相应开关下只看见自己生成的会话。隐身会话排除。摘录打红。

`user` 不是模型自己编的一个 id。它必须是这一轮里已经核实的请求者。会话主人、任务目录不能拿来冒充。这和 `personal_instructions` 只写请求者自己的文件是同一条身份原则：模型提供的 profile 不选择写谁的数据。

## Hermes

跨会话回忆用 `session_search`，范围是这个家目录的库。委派用 `delegate_task`。叶子角色拿不到再委派、澄清、记忆、发消息和 cron。编排者在配置允许时可以再委派，深度有上限。

共享的群会话把发送者加在用户消息上。系统提示不写死用户名。没有「多个已核实的人推动同一轮时，工具调用必须带 requester id」这一个参数。身份在入站时已经规范成路由身份。工具若再要一个人，用的是那份身份，不从模型正文里挑一个名字。

## Claude Code

子代理是 Agent 工具打开的侧链，转录在 `subagents/`。没有向同一台 Gateway 上的另一条会话发送并等待的工具。也没有外部对话地址列表。多人协作不是这棵客户端的会话模型。
