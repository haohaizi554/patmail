# 握手

Gateway 先发挑战，客户端再发 `connect`。挑战里的时间戳必须是非负整数。收到了挑战但时间戳缺失或畸形，这次握手无效。角色和范围决定这个连接能做什么。会话 id 不是租户授权。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 第一来回 | 服务端 `connect.challenge`，然后客户端 `connect` | 桌面和 TUI 的 JSON-RPC。客户端声明自己能回答服务端请求 | 无 Gateway。编辑器协议另计 |
| 协议 | `minProtocol` 和 `maxProtocol`。示例是 4 | 方法表在 Python 里生成 TypeScript。未知参数键拒绝 | stdio 或本地 |
| 身份 | `role` 加 `scopes`。设备认证用挑战的 `ts` 作为签名时间 | 会话令牌。WebSocket 不能带 Authorization 头时，令牌走查询参数 | 本机用户 |
| 旧客户端 | 明确支持挑战出现之前的 Gateway 时，没有挑战才可以用本地时间 | 没声明能回答服务端请求的旧客户端，提问会快速失败而不是干等 | 版本由安装器决定 |

## OpenClaw

连接建立后，Gateway 先发事件 `connect.challenge`，载荷是 nonce 和时间戳。设备认证的客户端把这个 `ts` 当作 `connect.params.device.signedAt`。WebSocket 挑战的 `ts` 必须是非负整数。只有客户端明确支持挑战机制出现之前的 Gateway，并且这次没有挑战到达，才可以用本地时间。已经收到挑战但 `ts` 缺失或畸形，无效。

客户端接着发请求 `connect`。参数里有它能接受的协议下界和上界、客户端 id、版本、平台、模式、角色、范围和能力。操作者角色带读和写一类范围。完全权限模式要求 `operator.admin`。其余权限模式要求 `operator.write`。范围不够的连接做不了那次操作，而不是做完再靠提示词约束。

事件不重放。断开之后要靠仍开着的请求和会话状态重新对齐，而不是把错过的事件再播一遍。预连接挑战不是会话事件，不进转录。

一个 Gateway 的默认安全模型是一个受信任的操作者边界。认证过的操作者在这台 Gateway 里有控制面角色。会话 id 选择路由，不授权一个租户去碰另一个租户。要把互不信任的用户隔开，得每人一台完整实例，而不是在同一条 WebSocket 上换会话 id。

## Hermes

桌面和仪表盘通过 WebSocket 上的 JSON-RPC 到达 `tui_gateway`。方法、服务端请求和事件的形状在 Python 里声明，再生成 TypeScript。调度拒绝未知的参数键。测试隔离下，结果和载荷对不上模型会当成合同违反。

客户端在连接上说一次自己能回答服务端请求。共享通道在网关就绪时送出。从未声明的 WebSocket 客户端被视为旧应用。向它提问会快速失败，而不是把 agent 线程堵到截止时间。重连用仍开着的请求把澄清、批准和秘密对话框再画出来。

REST 和 WebSocket 用同一枚会话令牌。浏览器不能在升级时设 Authorization，所以令牌放在查询参数里。不另起一套认证。

多 profile 时，每个方法在拥有该会话的家目录范围内读配置和秘密。只改家目录覆盖、不进入秘密范围和终端范围，会让凭据仍来自启动 profile。

## Claude Code

没有这套 Gateway 挑战。本地客户端直接进入查询循环。ACP 或编辑器集成若存在，是另一条 stdio 协议，不把 OpenClaw 的角色和范围搬过来。权限在每次工具调用前决定，不在握手的 scope 列表里。
