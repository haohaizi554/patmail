# 日志

控制台给人看。文件日志是一行一个 JSON，按天滚动。例行的 trace 到 warn 不附调用栈，避免每条都去解析堆栈。error 和 fatal 保留调用点。语音和实时路径不把转录正文、音频和通话 id 写进日志。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 文件 | 默认在临时目录按主机本地日切。Windows 始终用系统临时目录下的用户范围路径 | 家目录的 `logs/`。更新收据单独放 | 客户端日志。会话正文在项目 JSONL |
| 体积 | 默认 100 MB 一轮，保留五个编号归档 | 按家目录，不和别的 profile 混 | 无 Gateway 日切 |
| 热改 | 级别、路径和体积从下一条记录起生效。已排队的仍写原文件 | 配置里的日志键下次读取生效 | 设置下次启动或下一轮 |
| 敏感 | 密钥打红。Talk 的正文和音频不进记录 | 秘密不进配置。输出打红是启发式 | 转录里可能有用户贴进来的秘密 |

## OpenClaw

两面：终端上的控制台，以及 Gateway 记录器写的 JSON 行。启动时记下解析后的默认 agent 模型，以及影响新会话的模式默认，例如思考级别和快速模式。思考未设置时显示 medium。插件重载取代了启动时的插件加载之后，模型行、已加载插件摘要和渠道警告改用替换后的配置。

默认滚动文件在 `/tmp/openclaw/`，按 Gateway 主机的本地时区按天。默认 profile 是 `openclaw-YYYY-MM-DD.log`。命名 profile 把名字嵌进文件名。目录不安全或不可写时，包括主人不对、全局可写或是符号链接，改到用户范围的临时目录。Windows 始终走这条后备。

活动文件在 `logging.maxFileBytes` 轮转，默认 100 MB。最多五个编号归档，然后继续写一份新的活动文件。路径和级别在 `logging.file` 和 `logging.level`。热重载打开时，级别、路径和体积从下一条记录起生效，包括长寿的渠道记录器。已经排队的记录写完原来的文件。显式的记录器级别覆盖，例如某个库的啰嗦程度，仍然有效。

子系统文件日志对 trace、debug、info 和 warn 省略调用点元数据，包括 `raw()` 行，免得每条例行消息都捕获并解析堆栈。error 和 fatal 保留。诊断开着且有内部日志消费者订阅时，各级都保留调用点，以便 OTLP 有代码位置。这从下一条记录起跟随诊断开关，已有的子系统记录器也一样。调用方提供的消息、结构化字段和错误栈不改。

Talk、实时语音和托管房间用共享文件记录器记有界的生命周期，给运维和 OTLP。转录正文、音频载荷、回合 id、通话 id 和提供商条目 id 从不拷进日志记录。Discord 实时语音的会话生命周期转换在 info。音频块和转录增量在 debug。模型拉取开始和一秒内的成功响应在 debug。非 2xx 和至少一秒的响应在 info。传输失败是警告。

日志不是审计边界。打红挡不住有意把秘密写进消息的人。文件本身要按秘密对待，尤其是调试级别。

## Hermes

日志在 profile 的家目录下。多路复用时每个家目录自己的日志，不写进启动 profile 的那一份。更新每次运行写收据到 `logs/update_receipts/`。网关把代码 SHA 和版本写进 `gateway_state.json`，供更新核对，不是普通的调试行。

输出打红去掉看起来像秘密的模式。这是启发式。进程里的插件能读到的，不因为没打进日志就不存在。

铁代理有自己的审计日志，权限 0600。创建失败就抛出。代理日志同样 0600，并且不把宿主机的整份环境拷进代理进程。

## Claude Code

会话的权威记录是项目目录里的 JSONL，不是按天滚动的 Gateway 日志。调试输出和会话转录是两回事。转录里会有用户消息和工具结果，其中可能包含贴进来的秘密。日志级别不改变转录写什么。
