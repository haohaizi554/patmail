# 重置

`openclaw reset` 清本地配置或状态，CLI 还在。干跑只打印会做什么，不删文件。非交互必须同时有范围和 `--yes`。只清配置不停 Gateway。清凭据和会话，或全清，会先停 Gateway。全清去掉状态目录（含共享 SQLite）和工作区目录。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 只配置 | 不停 Gateway | 改 `config.yaml` 不删会话库 | 改设置文件 |
| 配置加凭据加会话 | 先停 Gateway。配置、OAuth 和凭据目录、规范 SQLite 历史及其归档 | 停网关再动 `state.db`、WAL 和 SHM | 删项目 JSONL |
| 全清 | 状态目录和工作区都去掉。先停 Gateway | 家目录是人的。没有一条命令同时删工作区和库还留着 CLI | 卸载客户端另计 |
| 预览 | `--dry-run` | 医生可以先检查。修复默认备份 | 无 |

## OpenClaw

范围三种。`config` 只删配置文件，不停 Gateway。`config+creds+sessions` 删配置、OAuth 和凭据目录、规范的 SQLite 会话历史和它的归档，并且先停 Gateway。`full` 删状态目录，包括共享 SQLite，再加上工作区目录，并且先停 Gateway。

`--yes` 跳过确认。`--non-interactive` 关掉提问，因此必须带范围和 `--yes`。干跑打印动作，不删除。

全清不是重启。重启留下转录并尝试续上被打断的回合。重置的后两档是把历史和凭据拿掉。工作区在全清里一起走，因为工作区是 agent 的家，里面有记忆文件。只清配置时，会话库和工作区还在，但行为回到没有这份配置的状态。Gateway 若仍开着，它内存里的快照要等重载或重启才跟磁盘一致。

凭据目录一旦删了，SecretRef 和 OAuth profile 都要重新登录。干跑用来在动手前看见路径。

## Hermes

要修库或换文件，先停网关。`state.db`、`-wal`、`-shm` 一起拷走再动。`doctor --fix` 在网关开着时不要跑。这不是一条按范围删掉家目录的重置命令。profile 删除有自己的墓碑和身份标记规则，不把没有身份标记的目录当成可清空的空壳乱删。

## Claude Code

清掉项目里的转录就是清掉会话。设置文件另算。没有「先停 Gateway 再删共享库和工作区、CLI 仍留着」的三档范围。
