# 会话工具

跨会话的列表、历史、搜索、发送和生成，仍受当前工具档案和允许拒绝策略约束。编码档案包含完整的会话编排。消息档案包含会话自助、发现、回忆、跨会话消息、外部对话，以及完整的生成生命周期。组和沙箱策略仍可以在档案之后拿掉这些工具。用受影响会话里的 `/tools` 看生效清单。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 多人 | 好几个人转向过这一轮时，必须带已核实的请求者 profile。未知或被撤销的参与者被拒绝。单人可以省略 | 会话按 profile 家目录。工具不按「这一轮里的人」选权威 | 本机一个用户 |
| 列表 | 元数据清单，不是转录搜索。默认 100 行，每次响应最多 200。`count` 是返回行数，不是库存总数 | `session.list` 是网关方法 | 无花名册工具 |
| 历史 | 默认不含工具结果。外部 CLI 转录并进来时是合并快照，终态不表示完整 | 历史按行 id。回绕后旧 id 作废 | 打开 JSONL |
| 成功 | 机制成功不会仅仅因此标成已执行。公开检查是未核实的决定记录 | 工具结果是 JSON | 权限结果在这一轮 |

## OpenClaw

这些工具可以带可选的 `user`，即请求者已核实的 profile id。好几个人转向过这一轮时它是必需的。点名的那个人的权威决定会话访问和孩子执行。定时任务，以及没有回合参与者的 SDK 或插件运行，保持已有的会话访问规则。

访问拒绝用执行边界同一份带类型的可见性决定来渲染。执行审计开着时，私有的排队事实保留求值过的政策输入，以及安装本地的不透明目标引用，不是原始的目标会话键。公开检查把那份通用事实画成未核实的决定记录。它不声称受信任的原因或目标显示。成功的会话操作不会仅仅因为机制成功就被标成已执行。

`sessions_list` 是元数据清单。行包括键、id、agent、种类、渠道、标题、侧栏组、当前主人和原始创建者、存储的项目或工作区关联、可见的父子链接、归档和置顶、状态版本、模型和 token 计数、运行状态。未知关联保持缺席。存着的工作树关联不证明检出还在。

关系过滤相对已认证的请求用户：拥有是当前责任，创建是原始出处，参与是当前所有权或保留的提示参与。这不是 agent 的主人，也不从会话标签推断身份。没有受信任的请求用户身份时，工具拒绝这个过滤。关系过滤收窄可见性，从不授予访问。按项目或工作目录列的是已持久化的关联。列表不检查文件系统，也不跑 Git。空的组选出未分组的会话。`activeOnly` 是 Gateway 支撑的清单上当前直接的排队或运行。嵌入模式没有活的 Gateway 投影时不可用。`activeMinutes` 是新近，不是存活。

`limit` 默认 100。更早版本接受的更大正数仍然有效，但每次响应最多应用 200 行，并在 `limitApplied` 里报告这个界。`count` 是返回的行数，不是库存总数。`hasMore` 为真时，用同一套过滤把 `nextOffset` 当 `offset`。空页仍可以有延续。每次调用最多五个内部页和 64 KiB 的序列化结果。截断原因标明是扫描上限还是字节上限。字节受限的延续从第一条被省略的行恢复。

页是活的视图，不是冻住的快照。并发更新、置顶、重新指派或归档可以让行在页之间移动。按 agent、键和会话 id 去重。要一份新的完整清单就从偏移零重来。每次调用重新做访问检查。延续不是访问授予。工具不暴露隐藏会话的全局计数。

从转录派生的字段是选择加入的。只读元数据的调用不读转录，也不启动会话。预览在会话可见性过滤之后才注水。行在充实期间变得不可访问或会话被替换时，从完成的清单里省略。第一条充实的行放不进结果预算时，调用返回元数据，不带内联消息或转录预览，并设 `enrichmentOmitted`。仍超过 64 KiB 的元数据行明确失败，而不是悄悄丢掉身份或关联。归档、恢复或删除时，用返回的 `sessionId` 当期望的会话 id，免得过期的键打到替换后的会话。

`sessions_history` 默认排除工具结果。`includeTools` 才看见它们。`limit` 取最新的有界尾巴。显式 `offset: 0` 才要分页元数据，再用返回的 `nextOffset` 向更老的窗口翻，不读原始转录文件。合格的、有界的外部 CLI 转录贡献了消息时，历史返回合并快照，而不是数字偏移页，即使显式给了偏移。Gateway 把这些当成终态快照，`hasMore` 为假。过大的快照仍受字节限制，所以终态不表示完整。没有存活的外部导入时，才用本地偏移分页。未锚定的读取保持当前的、相对重置的视图。仍在当前视图里的显式消息 id，包括重置后保留的重置前行，保持当前视图。保留的、在活动路径上但不在当前视图里的消息 id，打开原来的闭合区间，不混入重置之后的回合。缺失或离路径的消息 id 返回空历史，而不是最新的消息。

## Hermes

会话列表、历史和子代理快照是网关方法。回绕用确认过的行 id。没有「好几个人转向时必须点名请求者、列表最多 200 行且计数不是总数、外部转录的终态快照不表示完整」这一页工具合同。

## Claude Code

没有跨会话的列表和历史工具。子代理把摘要交回当前回合。恢复是打开一份转录，不按 64 KiB 和五个内部页截断一份活的清单。
