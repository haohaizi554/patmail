# 附着

Gateway 拥有会话行、转录、路由元数据和活动运行。控制界面、手机、ACP、`openclaw tui` 和 `openclaw attach` 投影这份状态，不各留一份会话副本。因此可以在几个客户端里打开同一会话，而不导出或拷贝转录。手机节点仍是连在 Gateway 上的外设，不会变成第二个会话主人。

## 对照

|---|---|---|---|
| 继续 | `tui` 在终端里继续对话。`attach` 在会话旁边挂编码运行时，并给一份临时的、限这个会话的 MCP 授权 | 桌面和 TUI 连同一套 JSON-RPC。重连再拉会话 | 打开同一份 JSONL |
| 短链 | 短 id 权威。显示名只是装饰。两个会话共享前缀时，一条精确的短名打破平局 | 会话按库里的 id | 路径就是文件 |
| 交接 | 「在终端继续」拷一份不含凭据的命令。键限 512 个用户感知字符。缺会话给恢复指引，不另造一条 | 重连不靠不透明交接参数 | 无 |

## OpenClaw

`openclaw tui` 用来在终端里继续对话。`openclaw attach` 用来在会话旁边挂编码运行时，并带一份临时的、限这个会话的 MCP 授权。嵌入的本地模式分开：`tui --local`、`chat` 和 `terminal` 用本地 agent 运行时，不能接受会话目标。

多数 agent 会话键是 `agent:<agentId>:<rest>`。配置成全局会话范围的 Gateway 用规范的 `global` 会话。只带 agent 的 URL 打到全局范围的 Gateway 时，CLI 先问范围，再把 URL 解到那条规范全局会话。

短形式对以 UUID 结尾的键，取 UUID 开头 8 到 32 个小写十六进制字符，去掉横线。短 id 是权威的。显示名短名是装饰，除非两个会话共享同一前缀，那时一条精确的短名打破平局。CLI 短链目标里，agent 段也是装饰。Gateway 解析短 id 时不把它约束到 URL 里的那个 agent。`sessions.resolve` 拥有精确键、原始会话 id、标签和短 id 的解析。发现选择器按调用客户端的会话可见性过滤。短 id 歧义的结果最多十条最近的候选人，让客户端可以请人给更长的前缀，而不是猜。短引用在会话存储主人处解析。更老的 Gateway 拒绝 `shortId` 时，升级它，或改用完整会话键。

会话 URL 不得含凭据。第一次和某个 Gateway 来源配对时，把令牌或口令分开传。控制界面「在终端继续」拷一份不含凭据的 `openclaw resume` 命令，带一个不透明的、带版本的交接参数。参数只编码精确的、带 agent 限定的会话键，和选中的 Gateway WebSocket URL。键限 512 个用户感知字符。字母表对 URL 安全，常见 POSIX shell、PowerShell 和 `cmd.exe` 粘贴时不需要额外引号。终端自己认证。Gateway 在 TUI 附着前把键规范化。缺会话给出恢复指引，不另造一条。会话 ACL 仍然适用。带查询的 Gateway URL 产不出这份不含凭据的命令，因为认证和存储的设备范围不看查询。控制界面不剥掉也不拷贝查询。

Gateway 先解析会话，再铸造一份限这个会话的临时授权，并用严格的 MCP 配置启动编码运行时。持有者令牌走孩子的环境，不走 argv。正常退出时撤销授权。`--print-config` 让授权活到 TTL 到期。

URL 或简写权威地选定一个规范化的 Gateway 来源。OpenClaw 从不为那个目标复用另一个来源上配置的凭据或存储的设备令牌。交接命令有更窄的规则：`resume` 只有在当前 CLI profile 的显式 WebSocket URL 逐字节匹配时，才复用这个 profile。本地和公共来源目标只在本地模式合格。远程模式只合格 `gateway.remote.url`。它不搜索其它 profile。主机、端口或路径任一不配，就回到显式凭据。精确的直接本地目标可以复用本地监听器的证书指纹。精确配置的远程目标可以复用配置的远程钉。公共来源目标不继承本地监听器的钉。载荷不含凭据。交接旁边显式给出的令牌、口令或指纹仍然优先。交接解析压住环境里的 Gateway 令牌和口令回退，同时保留那些显式值和精确目标上已配置的凭据。

第一次联系：带令牌或口令跑一次，在设备页批准，或在 Gateway 主机上预览最新请求再批准打印出的精确 id，然后重试。发出的操作者设备令牌按那个精确的规范化来源存在 SQLite 里。之后连同一来源可以用存储的设备令牌。显式令牌或口令在整条连接上始终优先。控制界面的继续命令不做这些第一次联系的步骤，也不携带它们的凭据。交接无效或被截断时，从控制界面重新拷一份，不要改那个不透明参数。命令拷出之后会话被删了，就回到控制界面从还在的会话再拷。令牌不跨来源。经 SSH 隧道的只读检查也压住存储的设备认证，因为环回传输认不出远程来源。显式凭据仍然有效。限流时不要仅仅因为 Gateway 在限流就去轮换凭据。等锁定期过去再试。

## Hermes

桌面、TUI 和仪表盘可以连同一套后端。会话在库里。重连再要列表和事件。没有「短 id 权威、显示名只是装饰、交接参数不含凭据且缺会话不另造、MCP 授权退出即撤销」这一页 Gateway 附着。

## Claude Code

继续就是打开同一份转录，或在工作树里另开。没有中心 Gateway 把控制界面、手机和终端投影到同一条会话键上。
