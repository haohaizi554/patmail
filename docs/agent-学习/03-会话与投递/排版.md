# 排版

出站 Markdown 先解析成共享的中间表示，再按渠道渲染。中间表示是纯文本加上样式跨度和链接跨度。一次解析喂给每个渠道。切块不会在跨度中间切开格式。偏移用 UTF-16 码元，好让 Signal 的样式范围和它的 API 对齐。表格只在渠道选了表格模式时才解析。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 切块 | 样式和链接随文本一起切。候选块在渠道转义和链接改写之后量渲染尺寸 | 流即消息的渠道要求草稿前缀稳定。块回复另有围栏规则 | 终端里按 Markdown 画 |
| 表格 | 默认代码块里的对齐 ASCII。子弹、原生块或关掉。单元格里的行内代码保留首尾空格 | 渠道适配器自己的标记 | 本地渲染 |
| HTML | 行内 HTML 词法保留原字节。属性值和认出的行内注释里的标记不当 Markdown。HTML 块解析保持关掉 | 无这道共享中间表示 | 无渠道 IR |
| 默认 | 没写插件默认的渠道退回 `code`。Matrix 和开了富消息的 Telegram 用块。Mattermost 关掉。Signal 和 WhatsApp 用子弹 | 按适配器 | 无 |

## OpenClaw

解析得到纯文本、样式跨度（粗体、斜体、删除线、代码、代码块、剧透、引用、一到六级标题）和链接跨度。切块把样式和链接随文本切开。按渲染尺寸的切块器在渠道转义和链接改写之后测量每个候选，并返回被接受的源切片和它的渲染载荷。渲染器用样式标记表把跨度变成该渠道的原生标记。

原始的行内 HTML 词法在解析期间保留原来的字节。属性值或认出的行内注释里的 Markdown 标记和实体，不解析成 Markdown 内容。未序列化的作者标签范围让懂 HTML 的渲染器解释那些标签。其它渲染器保持字面或转义。HTML 块解析保持关掉，这样容器里的 Markdown 仍然工作，正文里的裸 URL 仍做普通的链接化。

表格模式按渠道，也可以按账号。`code` 渲染成代码块里的对齐 ASCII 表，是回退默认。`bullets` 把每一行变成「标签: 值」的子弹。`block` 在传输支持时保留原生表，否则退回 `code`。`off` 关掉表格解析，原始表格文本原样通过。每种打开的表格模式里，单元格中的行内代码保留解析出的内容，包括首尾空格。Matrix 默认 `block`。Mattermost 默认关掉。Signal 和 WhatsApp 默认子弹。Telegram 默认 `block`，账号没开富消息时解析成 `code`。没有显式插件默认的渠道退回 `code`。

Slack 把链接写成 `<url|label>`，解析时关掉自动链接，避免链两次。Signal 在标签和 URL 不同时渲染成「标签 (url)」。Telegram 用 HTML 标签。Matrix 的自动回复、直接发送和媒体说明用同一套格式器。

## Hermes

流即消息的适配器要求草稿帧是前缀稳定的。终稿可以由消费方变换。没有「先变成带 UTF-16 偏移的中间表示、再按渠道量渲染后的块、表格四种模式」这一页出站管线。各平台适配器自己做标记转换。

## Claude Code

Markdown 在本地界面里画。没有按渠道的中间表示，也没有「切块不切开样式跨度、表格默认收成代码块」的出站合同。
