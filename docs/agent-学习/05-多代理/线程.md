# 线程

OpenClaw 会话附着到已有的 Codex 线程时，下一回合把当前选中的模型、批准政策、沙箱、批准审阅者和服务档重新发给 app-server。从 `openai/gpt-5.5` 换到 `openai/gpt-5.2` 保持线程绑定，并请 Codex 用新选的模型继续。受监督的绑定是例外。OpenClaw 的模型选择器锁住。恢复时省掉模型和提供商覆盖，让 Codex 恢复规范线程上持久化的那一对。另有原生 Codex 控制可以改那对持久化的模型。初始快照可以产生 Codex 平常的模型差异警告。外面的 OpenClaw 模型和备用链都不代替它们。

## 对照

| | OpenClaw 监督 | Hermes | Claude Code |
|---|---|---|---|
| 换模型 | 普通附着会重发所选模型。监督绑定锁住选择器 | 会话可以换模型。提供商不能服务的一对事先拒绝 | 客户端会话的模型 |
| 分支 | 继续为分支造一条模型锁定的聊天。来源线程不恢复。推理和工具结果不克隆 | 工作树或新会话 | 客户端分支 |
| 归档 | 活动来源不能新开分支，也不能归档。`notLoaded` 是活动未知，不是空闲 | 无这道原生线程租约 | 无 |
| 节点 | 配对节点上的后续消息恢复那条精确的原生线程，返回最终文本。不是 Gateway 本地分支，也不是流式 app-server 桥 | 远程终端是后端 | 无 |

## OpenClaw

监督是同一个 `codex` 插件的可选能力。它用另一条连接发现原生线程，只把未归档的会话投影进 Gateway 目录。没有显式的 `appServer` 连接设置时，那条连接用托管的用户家目录 stdio，普通运行时仍按 agent 范围。列表和元数据读取是被动的。它们不恢复线程，不订阅 OpenClaw 的活事件，也不回答它的批准。

在 Gateway 这台计算机上，已存储或空闲的会话用「继续为分支」造一条普通的、模型锁定的聊天，并把有界的用户和助手历史镜像到来源最后一条终态已持久化的回合。第一轮普通聊天装上真正的批准处理，并用一次短暂的原生分叉钉住快照，不带模型或提供商覆盖。Codex App Server 用它当前的原生配置，返回选中的那一对。若和来源最后记下的模型不同，发出平常的警告。OpenClaw 确认分叉的订阅已释放，然后在来源的工作目录和运行时政策下，用返回的那一对模型和提供商，启动规范的 `appServer` 来源 Codex 线程。然后注入有界的可见历史，并在同一条监督连接上提交绑定。这次检查从不持久化、也不归档。来源从不恢复。规范线程有完整的 OpenClaw 运行时工具面。来源的推理、工具调用和工具结果不克隆进去。私人连接范围在待定和已提交的绑定状态里都活着，所以后来的每一回合都留在那条连接上，带着原生认证和提供商配置。监督被关掉，或绑定和连接漂移，失败关闭，不切到普通的 agent 家目录运行时。

原来的 CLI、VS Code、Atlas 或 ChatGPT 来源仍可出现在两份目录里。规范分支是原生 Codex 线程，来源种类是 `appServer`。原生客户端可以过滤这个种类，所以它不一定出现在 Codex Desktop 里。

活动来源不能开始新分支，也不能被归档。已有的受监督聊天仍可打开。`notLoaded` 表示活动未知，不是空闲。OpenClaw 只在明确确认没有别的运行者、并且重新读了一次进程本地状态之后，才允许归档本地的 `idle` 或 `notLoaded` 行。Codex 在一个 App Server 进程里串行化线程变更，但不提供跨进程的独占运行者或批准主人租约。所以那次读取不能证明另一个进程没用这条线程。OpenClaw 挡住已知的、精确目标的活动绑定主人，以及 Codex 分页后代查询返回的任何未归档的生出后代。枚举错误、环和安全上限用尽都失败关闭。原生归档仍可能和另一个进程里的新回合赛跑。确认覆盖未知客户端，以及状态读取和归档之间的空隙。受监督的、模型锁定的聊天在保护原生绑定时不能删除。

配对节点的目录暴露有界的、分页的转录。合格的已存储或空闲行也可以创建或重新打开模型锁定的聊天，当连接的节点广告并允许目录列表、转录读取和 `codex.cli.session.resume`，并且操作者有 `operator.admin`。后来的消息经节点的 Codex CLI 恢复那条精确的原生线程，并返回它的最终文本。这不是 Gateway 本地的分支流，也不是流式的 App Server 运行时桥。没有这些能力的节点仍可只读，配对节点上的归档不可用。

## Hermes

换模型若提供商不能服务那一对，事先拒绝并最多给五个建议。回绕要确认截断。没有「监督绑定锁住选择器、分支不恢复来源、工具结果不克隆、`notLoaded` 不是空闲」这一页 Codex 线程合同。

## Claude Code

会话在客户端。换模型是下一次请求的参数。没有 Gateway 目录里的被动列表，也没有「读取不订阅活事件、不回答批准」。
