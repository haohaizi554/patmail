# 上手

引导式上手根据用户的应用偏好和观察到的能力建议结果。它不授予访问，也不实现第二套连接生命周期。功能留在已有的访客上手流程里。

## 对照

| | Hermes | OpenClaw | Claude Code |
|---|---|---|---|
| 优先级 | 新机器或认出的 RTX/DGX Spark 仍先做机器设置。新鲜度是已有的年龄启发式，不是操作系统安装日期的证明 | 工作区出生仪式种引导文件。最近证明过的工作区消失时拒绝悄悄重种 | 项目说明由人放进 `CLAUDE.md` |
| 发现 | 默认目录请求不做应用发现。可选扫描只在后端机器上，不启动应用、不装包、不读文档、不联网、不返回路径 | 技能和插件按目录发现 | 本机设置 |
| 权限 | 检测到应用不等于账户可用。缺连接就挡住那项任务，不造一份假收件箱 | 配对和批准另走 | 权限模式在工具调用前 |
| 提示 | 会话创建时给只读快照。交接为工作 profile 刷新。两条路都不改已有系统提示 | 引导文件进项目上下文 | 设置在新会话生效 |

## Hermes

机器设置决策对刚装好的机器，或认出的 RTX/DGX Spark，仍把机器设置放在前面，其它任务放在「别的」后面。年龄未知的 Spark 得到针对硬件的提示，不声称它的操作系统是新的。否则引导偏向有应用支撑的相关任务，并留一个不需要连接的替代。检测到一个应用最多赢得一个选项。其余选择来自用户目标和其它能力。同一个应用的好几个主意，只在明确要求时才合适。选了收件箱任务，就是在许可之后用真实收件箱数据。许可缺失时不造一份模拟收件箱。必需连接被跳过或不可用时，那项任务保持挡住。用户可以换任务，或自己提供数据。

运行时读真实目录。条目不必带新的推荐元数据。检测退回目录名，把短横当成空格，模型从描述推导任务。删掉条目就从以后的快照里消失。上手改动里不放某个产品的条目、包或安装配方。可选的 `applications` 最多 16 个安全标签，每个最多 80 字符，不含路径、shell 参数、正则或脚本。`examples` 最多六条可打印的单行结果，每条最多 240 字符。模型把它们收成已有选项芯片上更短的标签。`requires_app` 只在本地应用是前提时为真。桌面应用在场可以是云服务的相关信号，而不成为要求。目录条目不是账户访问、资格、附加组件就绪或活的工具连接的证明。

托管应用选择器保留策展过的前列，同时让活目录里其它已启用的行可搜索。新部署的托管连接器不会仅仅因为短名不在前列名单里就被丢掉。不需要新的门户元数据端点。

`detect_apps=true` 时，条目带匹配到的、由目录派生的应用名或可选的显式别名。发现范围是后端，状态是好或不可用，并带平台。默认的目录请求不做应用发现。可选扫描检查标准应用位置，以及后端机器上精确的、安全的 PATH 候选人。MCP 进程在那台机器上跑。扫描从不启动应用、启动 MCP、安装包、读应用文档或联系网络。它既不返回完整清单，也不返回文件系统路径。扫描有目录、条目和时间预算，不是穷尽的已安装软件清单。访问失败、预算用尽或不支持的宿主报告不可用。正面观察仍然有用。缺少观察不是不存在的证据。Windows 注册表枚举不在内。

桌面把目录请求钉在引导或交接的后端和 profile 上。它从不把桌面本地的应用观察和远程 MCP 宿主拼在一起。临时 profile 的 API 探测可以为只读的应用发现保留实际的操作系统家目录，而不读已安装 profile 的配置。

推荐先排明确的任务相关性和选中的应用，再排配置和应用在场信号。关掉的集成不会在没有明确兴趣时自动重新露出。必需的本地应用要有正面检测或已有配置才合格。每份种子是一小份候选人，不是整个目录。引导在会话创建时收到只读快照。交接为工作 profile 刷新这份快照，并带上选中候选人的完整安装说明。两条路都不改已有系统提示，不缓存连接权威，也不执行安装。旧的或不可用的目录退回已有的上手行为。

对 MCP 目标，`status` 不是 `manage_connections` 支持的动作。快照提供 `setupAction`：安装、启用，或空。只在真正需要时才请求授权。托管账户状态仍是分开的、受支持的动作。旧的作曲建议提供者只能完成托管的 HTTP OAuth。它排除本地应用和非 OAuth 条目，免得新元数据把本地编辑器引进那条无关流程。上手用共享的连接操作。实现消费公开的连接工具和已有目录 API。它不改连接操作的状态、生成的 RPC 合同、账户标识、OAuth 回调、重试所有权或已落定的结果处理。可选目录字段保住更老的客户端。缺字段保住更老的后端。

## OpenClaw

新工作区的出生仪式种下引导文件。设置状态在共享 SQLite 里证明过之后，工作区消失就不会悄悄重种。那是工作区文件，不是「检测到本机应用就建议一项任务、扫描不返回路径、目录条目不等于账户可用」。

## Claude Code

第一次运行读项目说明和用户设置。没有访客上手流程按后端机器扫描已安装应用，也不把缺权限的收件箱换成一份模拟数据。
