# 外借

MCP 是向另一个程序借工具。服务器暴露工具、资源和提示。OpenClaw 连上之后，这些工具仍走和内建工具一样的配置与策略。连上不等于绕过政策。把定义存下来不证明它可达。`mcp doctor --probe` 才检查。热重载开着时，改过或删掉的服务器立刻退役，下一轮的发现用新定义。没改的服务器保持连接和缓存的工具，包括已经在跑的运行。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 配置 | `mcp.servers`。stdio、SSE 或可流式 HTTP | 每 profile 的 MCP 配置。信任按家目录记 | 客户端的 MCP 配置 |
| 失败 | 起不来就退避：30 秒起，加倍，最多 10 分钟。失败状态熬过普通的会话清理 | 信任不从启动 profile 借给同名的次要 profile | 工具目录在回合之间刷新 |
| 谁重载 | 重载拥有连接的那个进程。CLI 重载不清掉另一台 Gateway 的退避 | `mcp.reload` 在发现之后 | 回合中途不换目录 |
| 会话 | 「仅此会话」和「到处」都保存全局定义。会话政策是另一层 | 会话的工具面由这次发现决定 | 子代理可以收窄工具 |

## OpenClaw

传输是可流式 HTTP、SSE 或 stdio。HTTP 要 `http://` 或 `https://`。stdio 是命令加参数。头、环境、OAuth、TLS、超时、并行工具提示和工具过滤，用范围更窄的配置编辑器。行上可以启用、禁用或删除定义。

已连接的服务器退出或连接必须替换时，它的工具、资源工具和提示工具从新的发现里消失，直到重连和目录加载成功。健康的服务器在失败的那台后台恢复时仍然可用。

内建 MCP 客户端起不来某个服务器时，新的运行时在指数退避里跳过它：30 秒，加倍，直到 10 分钟。碰到第一次失败的那个运行时，可以在正常的五秒目录节奏上再试一次，退役失败连接之后用新连接。这次恢复也失败，就同样进入指数退避。失败状态在普通会话清理之后还在，范围是服务器配置加上请求者。有效工具清单把该服务器标成不可用，并给出这个运行时的下次重试时间。下一步是可达性检查。每次失败的重试记一条日志。被跳过的运行不重复警告。成功连接、配置发布或显式的 MCP 重载清掉退避。重载的是拥有连接的进程。CLI 重载不重置另一台 Gateway。

作曲器里添加要管理员。选「仅此会话」或「到处」。两种都保存一份全局服务器定义。会话政策是按会话的那一层。从活动对话里可以检查或拒绝该会话的单个工具。视图跟会话实际的运行时主人：内建 OpenClaw 会话读进程内目录，原生运行时可以贡献线程自己的目录。会话级的服务器和工具拒绝，由任一运行时在下一轮开始前执行。

请求者的登录工具在运行时替换之后的下一条消息上刷新。

把 OpenClaw 的频道对话暴露给另一个 MCP 客户端，是 `openclaw mcp serve`，方向相反。

## Hermes

MCP 信任按家目录记。次要 profile 不收养启动 profile 对同名服务器的信任。信任门看的是调用会话的 profile。stdio 子进程的环境经统一的环境构建，按被服务的 profile 放秘密，不把启动 profile 的环境整份拷进去。发现缓存在进程里按家目录分键。没有把「存了配置」当成「已经连上」的探测，就还没证明可达。

## Claude Code

MCP 目录在回合之间刷新，不在一轮工具调用的中途换掉。连接失败是这一轮的工具错误或目录里缺了那一项。没有 Gateway 上按服务器加请求者记住的 30 秒到 10 分钟退避。
