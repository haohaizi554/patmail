# 思考

思考档位先看这一条消息里的指令，再看会话覆盖，再看 agent、模型和全局默认。提供商插件声明这个模型到底有哪些档。打进去的档位模型不支持时，直接拒绝，并给出该模型的合法选项。已经存着的、现在不支持的档位，按提供商的序重映射。`ultra` 是运行时的计划与核对，不是多出来的一档 API 努力，也不因此多给工具。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 指令 | 正文里的 `/think`。只含指令的消息写成会话覆盖 | 模型参数里的推理努力。辅助任务可以单独指定 | 客户端的思考档 |
| 解析 | 消息、会话、agent 默认、该 agent 的模型参数、共享模型参数、全局、再是提供商默认 | 配置里的模型和 `reasoning_effort` | 会话设置 |
| 不支持 | 打字的不支持档拒绝。存着的旧档重映射 | 提供商不认识的组合在建会话前拒绝 | 客户端过滤 |
| 缓存 | OpenAI 上改努力可以追加 `configuration_update`，请求级努力仍留着供前缀复用 | 提示前缀在对话期间字节稳定。压缩才是允许的上下文变更 | 分层压缩另计 |

## OpenClaw

档位有 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`adaptive`、`max`、`ultra`。菜单由提供商配置驱动，可以包括二元的开和关。`adaptive`、`xhigh` 和 `max` 只在该提供商和模型支持时出现。`ultra` 在 OpenClaw 和 Claude Code 运行时上对每个模型都可用，在 Codex 上用于支持原生推理的模型。它选择该模型最高的受支持原生努力，并加上这一轮范围的计划与核对。委派引导只在 `sessions_spawn` 可用时出现。`ultra` 不授予工具，也不绕过策略。没有推理的模型仍然没有推理。没有努力控制的模型保持提供商默认。

解析顺序：

1. 消息里的行内指令，只对这一条。
2. 会话覆盖，由只含指令的消息设置。
3. 该 agent 的 `thinkingDefault`。
4. 该 agent 在这个模型上的 `params.thinking`。
5. 共享默认里这个模型的 `params.thinking`。键必须是实际选中的 `提供商/模型`。
6. 全局 `thinkingDefault`。
7. 提供商声明的默认。没有的话，能推理的模型落到 `medium` 或该模型最近的非关闭档。不能推理的保持关闭。

已存储的不支持档：`adaptive` 不可选时，用提供商声明的非关闭默认；否则按序后退，通常仍开着思考，常常是 `medium`。`xhigh` 和 `max` 退到该模型最大的受支持非关闭档。

`/btw` 故意以关闭运行。在已缓存的 OpenAI 对话里改努力，可以追加一条 `configuration_update`，同时保留原来的请求级努力给前缀复用。最新的更新决定有效努力。顶层字段没变，不算降档。

自定义的 OpenAI 兼容目录可以用 `compat.supportedReasoningEfforts` 加入 `xhigh`。菜单、会话校验、CLI 和 `llm-task` 与传输用同一份兼容元数据。

若干具体映射会随模型改。值得留下的几条：Claude 4.6 在没显式设置时默认 `adaptive`。Opus 4.7 和 4.8 保持思考关闭，除非显式设置。Opus 4.7 及以后的 `/think xhigh` 走自适应思考加上 `output_config.effort: "xhigh"`。订阅路由若不支持 `none`，`/think off` 不保证零推理。MiniMax M2.x 在 Anthropic 兼容流上默认关掉思考，避免非原生流把 `reasoning_content` 漏出来。M3 发出正规思考块，关掉思考时内容为空，所以留在提供商省略或自适应的路径上。

## Hermes

主模型的推理努力在模型配置里。辅助任务（压缩、标题、策展、视觉）可以在 `auxiliary` 下单独指定提供商、模型和推理努力。辅助调用不发主循环的 `pre_api_request`。换表面不改系统提示字节。要改思考默认，是配置或下一会话，不是在一条已经缓存的前缀中间改系统提示。

建会话时，提供商显然不能服务的模型组合当场拒绝，并给出该提供商目录里最多五条建议。自定义端点、聚合器和目录还没跟上的同族名字仍接受。这是开工前的拒绝，不是思考档的重映射。

## Claude Code

思考是这次请求的参数。`ultra` 若由 OpenClaw 的 Claude Code 运行时暴露，仍是运行时加上的计划与核对，原生没有推理的模型不会因此变成有推理。客户端自己的思考档不经过 Gateway 的七级解析。
