# 卫生

发给模型之前，OpenClaw 按提供商在内存里修转录形状。SQLite 里的运行时转录不改成那一份提供商专用形态。助手预填的剥离只发生在构造出站载荷时。运行时加进提示的上下文不是用户写的正文，存下来的可见用户回合用转录正文，不用塞了运行时的那份提示。

## 对照

| | OpenClaw | Hermes | Claude Code |
|---|---|---|---|
| 修在哪 | 内存。库仍是原样 | 请求组装有自己的提供商路径。持久化是 `state.db` 的行 | 客户端在送出前整理 |
| 失败文本 | 纯文本的助手错误先缓冲。恢复成功就丢掉半截，因为恢复的回复取代它。终局失败留下最后一次的半截和错误 | 空回复和错误有回合阶段。不把半截涂进已落盘的工具行 | 工具结果要配对 |
| 工具调用 | 立刻持久化，赶在依赖它们的结果或恢复回复之前。事实行不带错误，停止原因可重放 | 工具调用和结果成对，否则下一请求失败 | 流式执行尽早配对 |
| 运行时上下文 | 自定义类型 `openclaw.runtime-context` 不进压缩和保存的 CLI 笔记 | 子目录提示附在工具结果上，不进系统提示 | 附件和预取不重建系统提示 |

## OpenClaw

内存里的修包括：工具调用 id、工具调用输入校验、工具结果配对、回合顺序、思考签名、图像载荷、提供商重放前的空白文本块、不完整的仅推理长度回合、会话之间路由来的用户输入出处，以及提供商重放时去掉空的助手错误回合。

纯文本的助手错误缓冲到逻辑运行落定。恢复丢掉半截文字。终局失败把最后一次尝试的半截文字和错误持久化。

工具调用、可显示的非文本内容和附件事实立刻持久化。混合了文字和事实的消息里，半截文字和错误仍分开缓冲。终局结算不把事实或用量再复制一份。用的是已有的助手行形状，不需要数据库迁移。

压缩和保存的 CLI 会话笔记排除保留的 `openclaw.runtime-context`，包括没有载体元数据的旧条目，以及选择不参与提供商重放的条目。

可见的 Gateway 回复、排队的后续、ACP、CLI 和嵌入式运行，各有一份面向转录的提示正文。用户在界面里看到的那一轮，不是模型提示里临时加上的运行时块。

## Hermes

持久化是追加。转向不涂进已经落盘的工具行，否则只追加的存储会和活的请求分叉。压缩把旧行标成不活跃，不删。提供商专用的修若只存在于这一次请求的内存里，库里仍是规范行。FTS 是派生物。正文坏了先隔离句柄，不在坏页上继续写。

## Claude Code

工具调用要有配对结果。分层压缩在请求前改送出去的视图。还原树里有的步骤是桩。没有「运行时上下文用单独的自定义消息类型，压缩时排除」这一条 SQLite 合同。
